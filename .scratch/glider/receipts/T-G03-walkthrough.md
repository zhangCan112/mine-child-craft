## 运行方式

```
npm install --ignore-scripts   # 首次即可（运行时不依赖 node_modules）
node server.js                 # 本地起服务，端口默认 8080
```

浏览器打开 <http://localhost:8080> → 进可装备界面（探险/创造）→ 装备滑翔翼
（合成或创造拿取）→ 对照下列各条目视。桌面 + 触屏各过一遍（HUD 重叠项
涉及触控热区）。

### 2. 收拢态侧面观感（A1 裁决已落地——过线门待 PO 异步判）

> **裁决原文要点（2026-11-15 scrum 回流，notes.md §5）**：
> (a) **文字修订+收拢外张预角增补**——v1.1 §6.2 承认弦向竖板凸出 ≈12px
> （绕 z 单轴+弦向 10px 刚体膜+展开水平膜面的约束组下，z 分量守恒，
> 凸出 ≈弦深是物理必然；原「≤2.5px」是定稿内部矛盾）；预角=每侧翼绕 y
> 静态基偏 ≈±18°（MC idle 鞘翅 yRot 同款手法），「两块平行竖板」→
> 「两片斜靠背角的收拢翼」，非动画轴（§6.5 单轴匀速契约不破）；
> (b) **几何回炉否决**——三条压凸出路（膜分段折收/ry 45° 预旋/缩弦 10→6px）
> 全不划算且仍不达标；MC 正典：原版鞘翅收拢本身就是弦深级薄板斜挂背后，
> 「收拢翼有可观厚度」是品类正典观感；**错在定稿不在实现（实现无责，
> 不回炉）**；(c) 走查吸收为过线门（顺序=修订定稿→补预角常量→走查）。

- **自动已覆盖（T-G03 有界返工，预角落地）**：js/mob-look/player.js
  wingL/wingR 三盒各 `ry: ±Math.PI/10`（≈±18°）烘焙——kit 现成 ry 通道
  （盒中心绕枢轴 y 转+自转同参=刚体旋转，蜘蛛腿同款），纯档案数据零代码；
  mob-look.test.js「翼骨甲案」追加 v1.1 断言（三盒同角/外张外偏/凸出带
  [10,13]px/翼尖不外甩）；定向 15/15 绿。落地哈希=本次返工提交（自引，
  以 git log 为准）。
- **必须真机（待 PO 异步判——截图采集协调归 scrum，施工环境无浏览器
  截屏能力）**：**过线门四条判据**（一次走查收口）——
  1. 收拢态读作「收起的翅膀」而非「背木板」；
  2. 正面轮廓几乎不可见（展向 1px 红线）；
  3. 翼板不遮盔甲 overlay 与背包件（背包画在体表 z≤3，翼板 z≥4 无重叠）；
  4. 展翼照 §6.7 原三项（展开对称/三背景可辨/动效匀速平滑）。
  **四张截图**：收拢态背面全身、侧面全身、正面全身三张 + 滑翔第三人称
