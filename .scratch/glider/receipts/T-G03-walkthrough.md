## 运行方式

```
npm install --ignore-scripts   # 首次即可（运行时不依赖 node_modules）
node server.js                 # 本地起服务，端口默认 8080
```

浏览器打开 <http://localhost:8080> → 探险模式 → 装备滑翔翼 → 高台/悬崖
起滑对照「滑翔态主线」；站立/行走/跳跃/落地后对照「非滑翔态零翼」。
桌面 + 触屏各过一遍。

## 门一：滑翔态主线（R1-19 验收锚，v1.1 走查项继续有效）

### 1. 第三人称滑翔展开观感

> 双翼展开对称、暖红棕膜+金骨辐条清晰、翼展完整入画不裁尖。

- **自动已覆盖（T-G03）**：mob-look.test.js「玩家翼骨甲案」（:385，三盒
  规格+官方 pivot+零 ry 过渡姿态）·「玩家翼贴图」（:410，五色色族+金
  辐条+暗折线+翼尖粒）· avatar.test.js「setWings(spread) 0.25s 匀速展开
  ·端点水平带·双翼反号」（过渡首帧=收拢姿态可见）。
- **必须真机（待 PO 异步判）**：滑翔中双翼完整可见不裁尖、暖红棕膜在
  天空背景下清晰可辨。

### 2. 三背景对比

- **自动已覆盖**：贴图五色断言（A2）照 §5.1/§6.3 色板钉死。
- **必须真机（待 PO 异步判）**：草原/沙漠/雪原三背景下翼色均可辨
  （暖红对蓝天/黄土/白雪）。

### 3. 展/收动效与消失瞬间（v1.2 衔接语义）

> 出现=收拢姿态可见瞬间起 0.25s 展开（「跳下去→翅膀砰地张开」）；
> 消失=水平收拢 0.25s，收拢到位瞬间消失、无残影帧。

- **自动已覆盖（T-G03 v1.2）**：avatar.test.js「setWings(spread)」（首帧
  可见+四点匀速采样+端点带）·「setWings(hidden)」（播完前可见+半程≈半+
  **到位瞬间 visible=false**）·「非滑翔零翼红线」（spreading 中途反向
  续收不跳变/spread 幂等）。
- **必须真机（待 PO 异步判）**：动画平滑无抖帧；落地瞬间翼「收起来不见」
  的读感成立。

### 4. 滑翔微动

- **自动已覆盖**：avatar.test.js「spread 滑翔微动」（±2.5~3° 正弦、双翼
  反相 95%+ 采样、主周期 1.4s 带）。
- **必须真机（待 PO 异步判）**：微动可感知但不晃眼（呼吸感）。

## 门二：非滑翔态零翼可见（v1.2 新过线门，替代 v1.1 A1 收拢态判据）

### 5. 装备未滑翔=完全隐藏

> 装备滑翔翼未滑翔：站立/行走/跳跃上升段（离地 ≤2 格未触发滑翔），
> 第三人称正面/背面/侧面均无翼。

- **自动已覆盖（T-G03 v1.2）**：avatar.test.js「缺省 hidden」（装备未滑翔
  =完全隐藏——setArmor 不消费 worn.glider）·「setArmor 与翼解耦」（任意
  worn 不展不收不扰动）。
- **必须真机（待 PO 异步判）**：三视角目视无翼（含行走/跳跃上升段）。

### 6. 四触发收翼后无残影

> 落地收翼后、入水软着陆后、滑翔中卸翼后、主动取消后：翼消失无残影。

- **自动已覆盖**：avatar.test.js「setWings(hidden) 到位瞬间隐藏+静置无
  复活」·「forceWingsHidden 立断+角恰 0」（触发接线归 T-G04 装配层）。
- **必须真机（待 PO 异步判，候 T-G04 合入后走）**：四触发场景逐一
  目视无残影。

### 7. 切模式/读档/死亡重生无翼

- **自动已覆盖**：avatar.test.js「forceWingsHidden」（兜底出口, 切模式/
  读档/死亡重生由模式层调用——接线归 T-G04）。
- **必须真机（待 PO 异步判，候 T-G04 合入后走）**：切建造/竞技场/坦克、
  读档、死亡重生后无翼（含曾装备滑翔翼的档）。

### 8. 装备页纸娃娃逐像素一致

> 装备滑翔翼前后逐像素一致（无翼）；构图恒出厂参数。

- **自动已覆盖（T-G03 v1.2）**：paper-doll.test.js「无翼常驻」（任意
  worn 翼恒 hidden, 装备前后逐像素一致）·「paint 不操纵翼骨不碰相机
  （rotation 恒 0, z 恒 3.55, lookAt 恒 (0,0.9,0)）」·「幂等+往复构图恒定」。
- **必须真机**：无（数据边界全量在单测口径内）。

### 9. 「装备着」信号不丢（信息补偿）

- **自动已覆盖**：mode-kit.test.js 第五槽/HUD 断言（图标常驻, v1.1 已落
  地零改动——身上看不到翼后信息职责加重）。
- **必须真机（待 PO 异步判）**：HUD 第五槽图标常驻可见、装备页槽位
  图标照常（ItemHint 话术归 T-G04 验证）。

### 10. 6 岁审美复查（快乐链）

- **必须真机（待 PO 异步判，候 T-G04 合入后走）**：不惊悚、不可怕；
  「跳下去→翅膀砰地张开→缓缓飘→落地翅膀收起来不见」的完整快乐链
  成立（R1-19 验收锚）。
