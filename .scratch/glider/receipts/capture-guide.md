## ① 前置条件

1. **版本节点**：分支 `glider` 上「预角提交」之后（提交哈希见 GP03 预角合入回执，落地后补记于此：

   滑翔/摔落与探险同口径（spec §3.8）。

## ② 最快合法获得并穿上滑翔翼

已核查：**无开发捷径**（体验馆试玩工位奖励箱为固定掉落表，无滑翔翼；无调试给予通道）。
最快合成路线（探险模式内）：

| 材料 | 数量 | 哪里来 |
|---|---|---|
| 工作台 | 1 台 | 随身 2×2：4 块木板（砍树）合成工作台，放地上 |
| 金锭 | 4 | 铁镐挖「金矿」（地下金色斑点矿石）→ 放熔炉烧炼（燃料：煤或木板） |
| 线 | 2 | 打蜘蛛，每只掉 1 根线 |
| 皮革 | 2 | 打劫掠兽掉皮革（血厚 150 的强怪，副本/远征遭遇；**全程最贵一环**） |

合成：走近工作台（4 格内）打开 3×3，配方卡里「滑翔翼」常显，**照卡摆**即可
（金锭摆十字、左右各 1 皮革、上下各 1 线）；合成得滑翔翼 ×1（任务卡 q27「合成滑翔翼」同时亮）。
若存档已有材料可直接跳到合成。

穿上（二选一）：手持滑翔翼做使用动作＝直接穿上第五槽；或开装备页点第五槽格穿上。

## ③ 四张图对位与四条判据（看什么）

视角切换：**V 或 C 键**切第三人称/第一人称。

| 图 | 怎么摆 | 白话判据 |
|---|---|---|
| 图1 收拢·背面 | 穿上翼、站在平地不动，镜头从角色背后拍全身 | 读作「收起的翅膀」，不是「背两块木板」 |
| 图2 收拢·侧面 | 原地侧身 90°，镜头拍侧面全身 | 侧面是斜靠的翼尖轮廓，不是平行竖板凸出一块 |
| 图3 收拢·正面 | 面对镜头站直 | 正面轮廓**几乎看不见**翼；不遮脸、不遮胸甲 |
| 图4 滑翔·第三人称 | 找 ≥4 格高的台/崖，直接走下去或跳下（翼自动展开），空中切第三人称拍 | 双翼展开完整入画不裁尖、缓降姿态自然、像背上长出纸风筝翅膀的快乐感 |

**过线四条**（当场判，逐条记结论）：
1. 收拢态读作「收起的翅膀」而非「背木板」；
2. 正面轮廓几乎不可见；
3. 翼板不遮盔甲 overlay 与背包件；
4. 展翼照 UI spec v1.1 §6.7 原三项（展开对称暖色可辨 / 翼展完整入画不裁尖 / 0.25s 动效平滑、微动可感知不晃眼）。
