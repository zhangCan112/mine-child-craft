## 3. 结构语义分解

| 部位 | 像素 | 语义 |

## 4. 设计注记

- **剪影层次（远读优先级）**：暗褐塔身（最大暗质量）→ 陶橙两笔顶带（身之上的宽橙带）→ 金点（最亮单点）。三段明度阶梯各自分离，「塔=竖高体量+阶梯顶+顶上金点」在 16×16 内一眼成立；门洞仅近读细节，远读融于塔身不破剪影。
- **比例锚定实塔**：实塔身 yb+1..8（8 格）对顶 yb+9..11（3 格）≈ 8:3——牌面塔身 8 行 + 瓦顶 4 行 + 金点 1 行同一比例语感，「牌上画的就是门后那座塔」。
- **金点位置理由**：S2 锁定「顶上一粒」，故置屋脊正上而非钟面高度；夜间壁灯暖光环境下金点为全牌最亮元素=「塔顶点灯」的夜读法；2 px 横对取中，两格牌并贴时双徽各自轴对称。
- **对称双徽**：单格自含居中构图（塔身 x6..9、瓦顶 x4..11 均以 x=7.5 为轴），z74/75 各贴同图即成对称双徽，无需镜像变体。
- **瓦顶 vs 木底的远距分离**：陶橙与牌木明度接近，分离靠色相（G 通道 122 vs 152 的红移）+ 暗身在其下的轮廓承接；降采样验证见 §7。
- **风格红线**：平色块、零抗锯齿（色板外像素 0）、零渐变、每像素归属唯一语义部位。

## 5. 工程转译注（实现线施工口径）

**目标**：`js/texture-atlas.js` PAINTERS 新条目，setP 逐像素直译。以下伪码与本规格 §2 网格**逐像素一致**（工具断言 diff=0，直译零漂移）：

```js
const T_GATE_SIGN = 60; // 建议格位: 59(T_PINK_WOOL) 后第一顺位(见下注)
// 门额牌(80): 牌木底+镇徽钟塔小图 — 全固定坐标, 零噪声零 rng
PAINTERS[T_GATE_SIGN] = (px) => {
  const W = [200, 152, 88], D = [146, 109, 60]; // 牌木底 / 深木缝线
  const B = [139, 90, 60], R = [217, 122, 74], G = [227, 178, 60]; // 塔身/瓦顶/金点
  // 1) 木底满铺
  for (let y = 0; y < 16; y++) for (let x = 0; x < 16; x++) setP(px, x, y, W);
  // 2) 木作线(planksBase 族语言, 全固定坐标)
  for (const y of [3, 7, 11, 15]) for (let x = 0; x < 16; x++) setP(px, x, y, D); // 横缝满行
  for (const [sx, y0] of [[2, 0], [13, 4], [2, 8], [13, 12]])                     // 竖缝逐板错位
    for (let y = y0; y < y0 + 3; y++) setP(px, sx, y, D);
  for (const [nx, ny] of [[14, 1], [1, 5], [14, 9], [1, 13]]) setP(px, nx, ny, D); // 钉点
  // 3) 镇徽 over-paint(漆在木作线之上)
  for (const y of [2, 3]) for (let x = 5; x <= 10; x++) setP(px, x, y, R);  // 瓦顶上笔
  for (const y of [4, 5]) for (let x = 4; x <= 11; x++) setP(px, x, y, R);  // 瓦顶下笔
  setP(px, 7, 1, G); setP(px, 8, 1, G);                                     // 顶钟金点
  for (let y = 6; y <= 13; y++) for (let x = 6; x <= 9; x++) setP(px, x, y, B); // 塔身
  for (const y of [12, 13]) { setP(px, 7, y, W); setP(px, 8, y, W); }       // 塔门(木底透出)
};
```

- **确定性口径（工程红线）**：本条目**零 noiseFill、零 rng**——比种子化更硬：不依赖 mulberry32 派生序，PAINTERS 数组内邻居条目增删不改变本格输出，两次建场逐字节一致天然成立（`test/texture-atlas.test.js` 同 seed 同图口径自动覆盖）。**不要**给本格补噪声微调。
- **格位与 layout**：PAINTERS 为稀疏数组且 `count = PAINTERS.length`，新格位须**顺号**落在现最高 59 之后（建议 60）；layout 加一行 `80: T_GATE_SIGN`（整格同图）。落位前实现线核对格位占用无撞。
- **mipmap 邻格串色提示**：60 号邻格 59 = 樱粉羊毛（#F2C2D9 系），木棕×樱粉色相分离清晰、串色低风险；但图集惯例「相邻格刻意同色系」（:50-52），若实现线另有空闲格能与既有木色系格相邻则优先，非阻塞项。
- **五面木底依赖（实现线裁定项，非本规格范围）**：S2 规定图案仅西面、其余五面木底色 #C89858。单格位契约下五面走 faceColor（config 方块行同色）或 mesh-core 专用小盒路径分面（火把/床双先例），由实现线按 S2 渲染路径评估落定；**若需追加第二个纯木色格位属规格外项，请打回设计线确认**。
- **UV 朝向**：y=0 行=牌面顶缘。竖版薄板西面按标准盒面映射（v=0 朝上）塔即直立；专用小盒路径若旋转 UV，以床头顶「mesh 旋转 UV」先例（:778-780）校准。
- **透明度**：全像素 alpha=255，走 glass 之外的不透明通道（S2 已定），makeCanvas 直读无 alpha 依赖。
