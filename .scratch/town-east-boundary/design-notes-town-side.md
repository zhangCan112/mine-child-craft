## 一、关键设计决策（含理由）

1. **②③在回程轴上汇合成一件设计**。
   实读发现镇维度 core 外全域无实底（虚空），回程缓冲带 z128..131 与触发线 z132 正在虚空段——③防坠若只圈 core 界不给回程开口铺桥，回程判据物理不可达；②门楼落缓冲带 z129 自带基座桥=「门楼即回程桥」。两需求一石二鸟，且门楼开口顺带把回程误触面从南缘全带宽收窄为一点（行为面红利，判据零改动）。

2. **门楼「一样的门」的兑现颗粒度**。
   PO 要「一样的门」——语言全同（石砌城楼+门额镇徽牌+白檐陶瓦+壁灯双嵌+总高 9 格），数字随地形合法变化：门洞 2→3 格（5 宽主路对齐动线，§6.3.5「无需找门」）、门额牌 2→1 格居中（中轴对称+S2 同图最简复用）。S2（T_GATE_SIGN）跨维度复用按可复用出案，工程判型留型（texture-atlas/mesh-core 全局单例）。

3. **朝向裁定=牌面朝北**。
   回程玩家自北南下先见牌再穿门再白闪；镇内南望=正面入镜；进镇者落 spawn 面北不经过门楼（镇侧到达点实读=spawn (79,112)，每次进镇都落这）——门楼是「出镇的门」不是「进镇的门」，PO 的对称感由镇内观瞻+回程穿门两读法兑现，不硬造假动线。

4. **TIDEA-06 升级吞并**（非撤销）。
   原案三职能（告示牌/门内灯/预留栅栏开间两桩）全由门楼接棒——门本身=最大指路件且更合零文字依赖；signpost-home 退役建议给出，lamp-end-south 保留（服务小坪照明非门楼专属）。ADR-0011 决策 6c 预授权语义=「回程仪式件」，门楼是其形态升格。

5. **③形制分级裁定的功能逻辑**。
   防坠的硬数字：本游戏跳跃约 1 格（north-spec 走查定稿口径）——**1 格墙=可翻=失效**，2 格=跳不过=成立。home 侧 1 高矮墙动机是「欢迎翻进」，镇侧动机相反=「不许翻出」——同一语言服务相反语义时高度必须分化，这就是方案 A 被弃、B（2 格强化简化形制）当选的根因。墙头花用固定交替零盐（比新开盐档更干净，G2 作废后 84xx 档位不添新占用）。

6. **防坠圈几何收在 core 界圈**（不沿世界缘）。
   坠的是 core 外虚空不是世界外（世界缘有物理钳制）；北 core 界不开墙（裙板缓坡=PO 亲需可达线，z32↔z31 仅 1 格高差零坠落面）；山体域内满填无虚空。当时判「防坠缺口只剩裙板东西端头=两个 3 格小墩」——**终检推翻**（缺口还有墙圈本体浮空、墙脊登攀与 rim 翼南缘，见决策 7）。远景层内部（山北缘 z8/山后 z0..7）不在本轮范围，U5 留档。

7. **终检三补（坐标自查第二轮的产物，全部进 §3.3 主案）**。
   交付自查按「脚下有没有实底」+「每个立脚点能不能被 1 跳登上」两问重审墙圈全部坐标，修了四处：
   - **墙圈本体浮空**：南 z128/东 x128/西 x31 都在 core 外，墙块 y25..26 无地基、草缘与墙基间现 1 格暗缝穿帮——补 1 层墙基垫层（y24，顶面被墙身覆压不可行走），同桥体「剖面不悬空」纪律；
   - **南角对角缺口+悬空柱帽**：东西墙原止于 z127，(31,128)/(128,128) 空格且柱帽 ×4 中北角两枚立在无墙格上——东西墙各延 1 格到 z128 闭角；柱帽改 ×2 只留南角，北端改 z32..33 两格 3 高接头柱且**故意无帽**（帽顶会成登脊踏板）；
   - **登墙漏口**：墙脊顶 y27 级可被裙板顶（y26 级）1 跳登上（唯一登点=接头格相邻裙板格），沿脊南行 96 格至尽端跳外=绕过整个墙圈坠虚空——接头加高至顶 y28 级（2 跳不可达）封死；余段脊顶对 core 草地（y25 级）恒 2 格高差不可登；
   - **rim 高台漏口**：裙板比 core 多出的东西两翼（x16..31/x128..143）南缘 z32 是虚空、rim 可步行至翼区踏空——补裙板翼墙 ×2（z31 行 x16..30/x129..143，顶 y28 级 2 跳不可达，与端头墩合角），rim 收成 z29..30 两行安全走道，登北山动线零改动。
   另修墙头花规则两处：x=80 落开口段（x76..80）不布；交替色 x+z 奇偶在定 z 墙线上恒同值（南/东墙全偶、西墙全奇=每墙恒一色，根本不交替）——改 ⌊(x+z)/8⌋ 偶=61 奇=62，相邻簇必异色且零盐。
   体量随之重算：+775 → **+1125 格**（垫层 285+翼墙 60 为大头），面数 ~4500 仍 <1%。
   残留走查项（登记不扩案）：若山体南缘存在高于裙板顶（y26 级）的可站立面且与接头柱/翼墙/端头墩相邻，登高者可自山缘踏上护件顶部再跳外——归 U5 同族远景巡检，走查触发再补缘墩。

## 二、被放弃的备选（防复议重开）

- **门楼落 z124..127（core 界内）**：挤小坪南缘与告示牌；穿门后 5 格才白闪=仪式松散；虚空裂缝照样要另补——落缓冲带一石二鸟。
- **门洞 2 格完全同款**：「找门」摩擦违反 §6.3.5 口径。
- **门额牌 3 格/双格**：单格居中是对称+复用的最简解；3 格同图重复像贴错图。
- **牌面朝南**：正面无人看（观众全在北侧）。
- **方案 A 1 格墙/方案 C 隐形护栏/方案 D 补满过渡带**：功能失效/行为面大改+撞墙出戏/误触面放大+7 万格体量——详见 spec §3.2。
- **墙圈沿世界缘布防**：防坠面在 core 界不在世界缘；体量翻倍。
- **门楼双门洞（进/出各一）**：进镇不经南门，双洞是死形制。
