## 一、关键设计决策（含理由）

1. **过场遮罩=原样复用白闪变体 kind='edge'，零新造。**
   白闪现成参数（`css/style.css:1115-1124` 暖白径向渐变、0.4s×2 双段、满格瞬间同步切）一步不碰；调参唯一落点=满格停留窗延长（hold 0~0.6s），且写明硬顶 2s（map-transition-research「遮罩必须快」教训取下段）。理由：GLOSSARY 白闪变体 _Avoid_ 禁把白闪叫第二套转场系统、禁 rite 重建异步化——同步重建是满格遮蔽窗内的体验契约，任何「更华丽的过场」都会破坏这个契约。

2. **过场语言必须白闪、禁紫。**
   词条语义「紫=地图门语义、白=大地让开语义」。本缝叙事是「扒着栅栏缝看了很久的小镇，在白光里让开一条路」——大地让开语言与东向叙事天然互文（三向先例 open 词：雪/沙/雾「就会让开的」，东向=栅栏让开）。紫调在本缝是语义错误不是风格选项，已写进禁焦虑清单作实现侧防呆点。

3. **触发/到达双播报，兜底只保留到达。**
   T-UI-00 雏形「我们去小镇啦」迁入触发语境（派令明确要求两句分开）；到达句对齐现网「到沙漠啦！」式口径（advVeilArrive `'到'+row.name+'啦！'`）。风险点：两句自然间隔 ≈0.8s，可能叠话——建议 TTS 通道排队（dialog-spec §2.2 先例）；兜底方案只保留到达播报（到达回答「我在哪」，优先级更高）。播报位的壳层接线归 BA/工程，我只定文案。

4. **镇维度行 `hud.banner` 槽=镇名牌载体，到达演出零新增 UI 组件。**
   先例格式 `emoji + 地名 · 气氛短语`（`'🌌 下界 · 黑漆漆亮晶晶'`）。主案「🏘️ 米德波特小镇 · 广场真热闹」——副语同时承接两个退役遗存：旧卡副标题「逛广场·找朋友·轻松玩」的轻松语义 + east-spec 旧话术「会很热闹」的期待词。钟塔演出与朝向全部用世界语言（spawn 锚 face:'north' + 钟塔走廊避让是 town-map-core 现成事实）——「剪影显影成真钟塔」叙事零成本闭环。

5. **告示牌改读：图标为体（钟塔+小径图案），文案为辅（「小镇在这边！」）。**
   实现现状「拼块形制无字」（T7 登记偏差）顺势转正为零文字依赖正案；牌上画的=缝里看见的（钟楼剪影 z74 与主径同轴，图案与剪影互文）。旧「小镇建造中」读法与「随时可去」语义直接矛盾，必须退役；旧主话术「还在建造中！等盖好了…」同步退役，拒绝话术保护理由改稿为指路（「从小路走过去就是小镇啦！」）。

6. **近前话术主案=直达单级，预案 B=任务链两级。**
   推荐直达（无任务门槛）：城镇气质「轻松玩」、主路是长期可见的实体引导（不同于三向的屏障远引），无锁则无「路在睡觉」话术需求。预案 B 句式完全对齐三向先例（拟人+指回任务+给期待、不引用门、分级不剧透），`st.open` 词取「栅栏就会让开的」与雪/沙/雾同族——BA 若裁任务链，话术直接可用。30s 节流是机制归 BA，我只出文案与视觉态分级。

7. **回程预案按「双向边缘白闪」倾向出，显著标注返工条件。**
   视觉语言：镇南主路铺装渐稀（home 东带递进节奏的镜像）+ 路标色块/灯柱花盆轻提示（town-map §4.3 交叉口语言）+ 尽头开阔无墙（禁可见墙）。home 侧落点意图：栅栏内侧主径可站立带、面西朝家、转身回望剪影。整节标注「依赖 BA 缝规格定稿，若裁回程门则返工」，并预登记返工时的门面观感方向（远征图回程门先例）。

8. **U1-U3 迁移而非删除。**
   U1「小镇漫步」→ 镇名牌备选副语/文档友好别名（播报用短名「小镇」，维度行 name 建议='小镇' 使到达句式自然——字段决策归 BA）；U2 🏘️ → banner emoji 占位延续 + 告示牌图案语境（专属图标可复用 UI-01 belltower marker 语义）；U3 → 「无二次确认」强化为「踩线即白闪直进零弹窗」（越线机制下无驻点可确认，旧「可选二次确认分支」废弃）。

## 二、被放弃的备选（防复议重开）

- **过场加中央占位图标/钟塔剪影插画**（旧 tokens §2.2 语言）：放弃——白闪是同一元素换 class 的纯遮罩，叠图标=发明新遮罩机制（派令红线「不发明新遮罩机制」）；到达演出已由 banner+世界语言承担，信息不缺。
- **过场时长拉长到 2s 做「仪式感」**：放弃——切界本体帧级完成，长遮罩=纯等待（Metroid「门=加载本体」成立的条件是门后真在加载）；0.8s 直用，hold 只留给同步重建体感兜底。
- **home 侧给东带加 HUD 方位指引**：放弃——冒险模式无方位指引器（Landmark Pointer 是镇内 UI hud-spec §5）；主路铺装/花田/告示牌的世界语言已够，加 HUD 反而打破「世界内语言优先」。
- **回程门先出设计等 BA 选**：放弃——按派令只出倾向方案的预案+返工条件，门面观感只登记方向不展开（避免与 BA 终裁对冲造成双权威）。
- **镇名牌做成独立全屏演出层**：放弃——hud.banner 槽是维度行现成字段，新造全屏演出=新机制+打断「一闪即到」体感。
