## 2. 拆分论证结论：**不拆，一张票**

派令问「动画与行为是否必须拆两票」——判定**并为一票**，论证三轴（票面 §3.1 全文）：

1. **依赖方向**：PO 病灶是「移动没有走动/idle 表现」，动画与移动互为表里且**接口互锁**——动画路径拍板（骨骼 vs UV）直接决定推进者输出面（骨骼走摆需腿内进度 0..1 相位，纯 legIndex 整数不够）。拆两票迫使行为票预猜动画接口，blocking edge 横竖存在，拆分=把一次拍板撕成两次。
2. **产线成本**：同缝簇（advTownPuppets* + 推进者 + bones 驱动）、同测试装具（adventure-mode.test.js 镇民链）、adventure.js 是工程线案卷修复的热文件——一票一轮红绿，两票两轮装具+两轮热文件接缝翻动。
3. **验收面**：终验是实屏观感单一验收面；拆分中间态（行为无动画=仍木头）使首票无法凭自身条款收口。

**唯一拆分条件（预登记，非前置）**：若拍板 b2（UV 姿态帧），贴图重产是设计工产线（gen 重画+导出器再生成 14 look+golden 重出），可**后置**拆出资产票沿 T-NPC-01/02 谱系走；本票仍含推进者+位姿跟随+已拍板路径接线。

## 5. GLOSSARY 处置：**不加词条，零改动**

理由三条（回执备档）：

1. **词条按 interface 收词**：本票核心新词（「行为层」「legIndex 推进者」「本体位姿跟随」）所指标的模块 interface 恰是票内 PO 拍板点（§5.2 随拍板定形）——拍板前不存在定形 interface，现在写词条=预拍接口形状，违反「拍板前零施工」。
2. **现有词条已覆盖部分**：「到站跳变」在「镇民锚点表（TownNpcAnchorCore）」词条（"锚点只在到站（legIndex 变化）时跳变"）；「傀儡/bones 透传」在「造型档案（MobLook）」「镇民适配器（TownNpc）」词条在案。
3. **回写义务已随票下达**：票面 §4.4 明示——实现票收尾时按收录判据（≥2 文件引用）评估新词条、同步一览 declared 计数、跑 `node --test test/conventions.test.js` 验平（T-NPC-12 §6.1.7「GLOSSARY 回写授权（绿方随实现落）」先例）。

因零改动，本回执**未跑** GLOSSARY 断言单测（无验平对象）。

## 7. 遗留风险（如实登记）

1. **拍板交互复杂度**：a×b 有耦合（a1 时 b1 走摆面收窄），PO 若分开拍可能拍出低效组合——票面 §7 尾注已给交互说明与组合示例，供拍板参考（非预拍）。
2. **案卷③与本票的边界**：案卷③（「像木头」）由工程线先修，其缓解内容未知（本岗未读其案卷）；若工程线已做轻量动效（如临时摆动），本票动画驱动落地时须对账去重——票面 §8 边 2 的施工排序已覆盖冲突面，去重对账建议在拍板回填时由派令方带上。
3. **热文件时序**：adventure.js 同时是案卷②④与本票的改面，硬边 2 已把施工排在案卷修复后；若案卷修复延期，本票 frontier 随之顺延（已在 README frontier 补充行注明双硬边）。
4. **a2 的观测缝契约**：逐帧位姿更新会动 advTownPuppets 快照的时效语义（进镇初值→逐帧实位），T-SEAM-04 观测缝既有断言口径可能需随拍板扩写——已作票面 §10.2 注意事项。
5. README 依赖图 ASCII 竖线有一格装饰性偏差（编辑工具空白匹配失灵所致，图可读性无损）——后续票面维护时顺手对齐即可，不构成工件缺陷。
