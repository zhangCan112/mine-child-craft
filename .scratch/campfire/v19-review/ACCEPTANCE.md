## 诚实边界（施工实机关注点，修正票验收时逐项过）

1. **噪声笔触未移植**（noiseFill amp 0.06/rng 散斑）——本验证是构图读感闸；施工后真图集
   （paintAll 含噪声）焰色计数应仍=94（噪声只抖 C 地 ±6%，不产生焰色、不碰固定焰像素）。
2. **侧脸透明区 alpha**：成像用场景绿演示看穿；实机读感依赖图集管线 alpha 位——若无 alpha
   回退=铺 C 暗底+登记读感损失【实现自由度】，PO 复验实机关注。
3. **thin 0.4375 引擎可吃性**：倾向值，0.5 兜底；实机高度核实（PO 报「全尺寸实心」与
   spec §3.4 半格相悖，两情况均被新口径覆盖）。
