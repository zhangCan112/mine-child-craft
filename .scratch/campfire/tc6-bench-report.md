## 0. 结论速览

**判定：不超标。** spec §3.9 侧账上限行维持「不设」，已按票文要求 2 回填收档注记（见 §7）。依据三条互相独立的证据线：

1. **帧时面零退化**（§3）：50 火全量特效态下 p50/p95/p99/max 与空景基线逐位钉在同一软渲节拍（41.5~41.8ms），**尾部分毫无增长**（p99=max=41.8ms 恒定，两景两档皆然）；
2. **CPU 侧成本微小**（§4）：50 火 CPU 面每帧合计 ≈0.35ms ≈ 16.7ms 帧预算的 2%；放置链（含增量光 BFS）p50 0.4~0.5ms/次，一次性成本；
3. **结构计数逐位吻合设计**（§6）：三档预算（full/near/far × 低核减半）实测计数与 UI 定稿 §5.2–5.4/§5.9 参数数学完全一致，远火仍有烟，拆清零残留。

## 2. 场景与负载构造（确定性，禁随机）

- **摆位**：7×7 网格去四角 + 补 5 = **50 火**，相对玩家格心偏移。
  - 场景 A 密集（step 5）：全部 ≤40 格 → 分档 **3 full + 47 near + 0 far**；
  - 场景 B 疏散（step 18）：**3 full + 12 near + 35 far**（远火只留烟柱档混入）。
- **放置链 = 生产同缝**：`editBlock`（写格+增量光 BFS+网格收口）→ `advCampfires.plant`（台账+气柱注册）→ `advCampfireFx.open`（特效句柄）；绕过放置合法性 UI（基准直驱，非产品改动）。拆除链对偶（`editBlock 0`/`drop`/`dig`）。
- 采样：每景先 6.5s 稳态等待（渐起 0.5s + 烟寿 4.5s + 余量），再采 10s rAF 帧间隔；基线为放火前空景 6s。

## 3. 帧时实测（主口径，headless Chrome）

单位 ms；n=275~291/景。

| 变体 | 场景 | p50 | mean | p95 | p99 | max |
|---|---|---|---|---|---|---|
| desktop | 空景基线 | 41.6 | 35.2 | 41.7 | 41.7 | 41.8 |
| desktop | A 密集 50（900 粒） | 41.6 | 34.9 | 41.7 | 41.8 | 41.8 |
| desktop | B 疏散 50（580 粒） | 41.5 | 34.4 | 41.7 | 41.8 | 41.8 |
| lowcore | 空景基线 | 33.4 | 33.1 | 41.7 | 41.8 | 41.8 |
| lowcore | A 密集 50（462 粒） | 41.6 | 35.0 | 41.7 | 41.8 | 41.8 |
| lowcore | B 疏散 50（289 粒） | 41.6 | 36.3 | 41.7 | 41.8 | 41.8 |

**判读**（如实申报口径）：

- SwiftShader 软渲的呈现节拍把帧时**量化钉死**在固定槽位（≈33.3ms / 41.7ms 两档），该地板掩蔽绝对 GPU 毫秒数——这是装具声明的口径边界。
- 在该地板下，**50 火全量态没有把任何分位数推过下一槽位**：p95/p99/max 在两景两档与基线完全同位（41.7/41.8/41.8），即负载增量 < 一个节拍量子且**零尾增长**。软渲是保守下界：连它都不增长的负载，真机 GPU 更无压力。
- 帧时阈值判定**不在测试里自断**（派令纪律），本报告即为判定落点：不超标。

## 4. CPU 侧计时（辅助口径，node 真实源码微测）

| 面 | 指标 | 实测 |
|---|---|---|
| 粒子 tick（campfire-fx-core，20tps） | p50 / p95 / max | **0.067 / 0.099 / 0.249 ms/刻**（912 粒存活，18.24/火） |
| 粒子 tick 低核档 | p50 | **0.038 ms/刻**（461 粒，9.22/火） |
| 字段同步（2550 mesh/帧口径） | p50 / p95 / max | **0.32 / 0.48 / 1.10 ms/帧** |
| 增量光 BFS（每火一次，含写格不含网格重建） | p50 / p95 / max（n=50） | **0.47 / 1.42 / 2.07 ms/次** |
| 柱查询（50 源注册表） | 均值 柱内 / 柱外 | **0.28 / 0.15 μs/次**（p95≈1μs） |
| 放置链全程（Chrome 内生产链直测） | p50（A/B 两景） | **0.4~0.5 ms/火**；拆除 p50 0.5~0.6 ms |

**折算**：50 火的每帧 CPU 面合计 ≈ fieldsSync 0.32 + fxTick 摊帧 ≈0.02 ≈ **0.35ms/帧**，占 16.7ms（60fps）预算 **2%**；放置是一次性动作（每火一次 BFS，火把同款先例的承受量级），50 火连置总 BFS 成本 ≈27ms 摊在放置过程而非帧内。
