## 1. 入口卡 Token 清单（对齐 §3.1、§3.2、§3.4）

### 1.1 卡片结构与层级语言（对齐 §3.1、§3.4）

沿用既有模式卡结构语义与层级，**差异化仅通过主题色、主图标、文案表达**（不新增特殊动效、不做“营销 hero”样式、不破坏主菜单网格秩序）。

| 项目 | Token / 约定 | 落地说明（与既有实现一致性） |
|---|---|---|
| 结构 | `mode-card town` + `.big` + `h2` + `small` | 同 `index.html` 既有卡片（如 `cardAdventure`）同构；整体为单一鼠标点选热区 |
| 识别色变量 | `--card-color`（主题色）/ `--card-color-bright`（高亮描边色） | 同 `css/style.css` `.mode-card.{mode}` 设色方式；hover/active 复用基类 `border-color: var(--card-color-bright)`、`box-shadow: 0 0 22px var(--card-color)` 语言 |
| 外框与表面 | 圆角 14px、2px 边框、内高光/内阴影 + 外投影 | **复用基类** `.mode-card`（不单独另造一套圆角/阴影体系） |
| 尺寸与排版 | 卡片宽 190px、图标区 62×62、`h2` 21px/letter-spacing 2px、`small` 12.5px | 与既有卡片同尺寸/字号层级（§3.4） |
| 可发现性 | hover 轻微抬升/描边提亮；active/pressed 明确按下反馈；禁用态本阶段不预设 | 复用基类 `:hover`（`translateY(-5px) scale(1.04)` + 亮边/柔光）与 `:active`（`translateY(2px) scale(0.97)` + 阴影收紧）；柔和、不闪烁 |
| 热区前瞻 | 热区 ≥ 卡片可视面；触控友好可点目标余量 | 与 §3.4“可点区域保持现有卡片”一致，后续实现校准 |

## 2. 进出过渡规格（对齐 §3.3）

### 2.1 进入流程默认（对齐 U3）

- **默认：无二次确认，点击卡片直接进入加载过渡。**【待 PO 确认】U3 默认值（误触成本低、符合低压探索）。
- **可选分支（若 PO 要求）**：单键大按钮“出发去小镇”（图标为主）+“返回”图标按钮；无文字说明负担；**仍不引入风险提示**（§3.3 末段）。

### 2.2 复用 `#fade` / splash 语言的轻量过渡参数（对齐 §3.3）

| 参数 | 建议值 / 方案 | 说明 |
|---|---|---|
| 复用机制 | `#fade` 淡入淡出语言（与模式切换一致）；必要时叠加 splash 风格占位元素 | 轻量过渡，不新造独立全屏“营销过场” |
| 体感时长 | **0.8s–2.0s** 区间（实现校准） | 可感知但不拖沓；不绑定固定“加载百分比” |
| 色彩/氛围 | **暖色渐显**（暖石/奶油/樱粉暖调倾向，与城镇暖亮基调一致） | 取色呼应 §1.2 暖底与樱粉系（`#D9CDBE` / `#F4D9A6` 奶油暖感可由实现在现有淡层上表达）；避免冷黑/危险红压场 |
| 中央占位意象 | **小镇图标**（🏘️ emoji 或同语义像素）+ **钟塔剪影占位** | 与“去小镇/钟塔地标”母题一致；占位期可仅图标+剪影轮廓，不要求成品插画 |
| 可选 TTS | “**我们去小镇啦**” | 进入过渡可播报一次（可被全局静音设置约束）；友好短句 |
| 出口/落点意图 | 进入后镜头/落点面向广场或可回望钟塔的友好方位 | 体验意图对齐 `town-map-design.md` 回望原则；具体落点实现归后续票 |

### 2.3 禁止项清单（对齐 §3.3、§4.5、MISSION）

| 禁止项 | 原因 / 对齐 |
|---|---|
| **进度条焦虑**（精确百分比、长条“加载中”制造等待压力） | 6 岁低压；§3.3 明确禁止 |
| **倒计时**（沙漏、读秒、耗尽条） | 零倒计时压迫；§4.5、MISSION |
| **风险提示弹窗**（“确定进入吗？可能…”类警告/二次恐吓确认） | 零惩罚、低挫败；U3 默认不二次确认且不引入风险提示 |
| **失败/错误/惩罚暗示 UI**（红叉、警报红常态、扣分） | 祥和无威胁；§4.5 |
| **营销 hero 样式**（超大独立转场海报、破坏卡片/页面节奏的夸张动效） | §3.1/§3.4 一致性原则 |
