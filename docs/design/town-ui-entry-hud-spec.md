## 2. 设计原则（分区 A 总则）

1. **祥和无威胁、热闹温暖**：UI 服务 Midport Village 的明亮午后、友好市集气质；**禁止**危险/警报语义（红色警示闪烁、骷髅/感叹号惊吓、倒计时压迫、失败惩罚提示、血量/伤害暗示）。【建议为游戏性调整】
2. **6 岁可读、图标优先**：信息以大图标/色块/形状承载，文字仅作辅助短标签（供中文 TTS 同步朗读）；避免长句与密集文本。【对齐 MISSION】
3. **纯鼠标点选可发现性**：所有可交互目标必须有“静态可辨 + 悬停/可点选强化”两级视觉；不依赖键盘快捷键、指针锁定、拖拽精细操作或右键作为唯一入口。【对齐 MISSION】
4. **过程性表扬、零惩罚、零倒计时**：反馈强调“参与/发现/完成一步”的正向鼓励；无失败态、无扣分、无时间耗尽；任务可跳过/可重来/可随时离开（玩法策略由后续 spec 定，UI 不呈现压力）。【对齐 MISSION】
5. **低认知负荷（注意力训练友好）**：HUD 常驻元素极少且位置稳定；一次只突出一个主提示/主目标；动效舒缓（≥1s 周期感知，不弹跳惊吓）。【建议为游戏性调整】
6. **与城镇视觉一体**：色彩与材质感呼应 `town-buildings-visual-spec.md` 暖木/浅石/樱粉/天蓝/暖金与“柔和暖光”语言；避免与广场樱花、招牌、道路主色混淆导致指引不可读。
7. **响应式与安全区**：锚点布局、`clamp`/相对尺寸与固定宽数字槽（若有计数）避免抖动；预留屏幕边缘安全区，UI 不遮挡钟塔视线通廊与玩家前方主要可玩路径（对齐 map 回望原则）。

## 4. 城镇内 HUD 与任务提示

### 4.1 HUD 信息层级（从高到低）
| 层级 | 元素 | 默认显隐 | 目的 |
|---|---|---|---|
| L1（主提示） | 当前轻任务/导览提示卡（图标 + 超短词组 + 可选 TTS 重播入口） | 情境显示；无任务时隐藏或收起为“探索中”轻状态 | 一次只给一个可理解目标，支持注意力聚焦 |
| L2（方位/地标） | 方位指引（见 §5） | 常驻或在有目标/迷路风险时显示 | 帮助定位钟塔/广场/当前目标，不强迫看复杂地图 |
| L3（正向反馈） | 过程性表扬反馈（图标/小动画/音效+TTS，见 §4.4） | 事件触发，短暂出现后淡出 | 即时鼓励，零惩罚 |
| L4（系统轻入口） | 暂停/设置/返回等（若需要） | 角落小图标按钮，低干扰 | 可达但不抢注意力；具体入口由实现/全局 UI 约定 |
| —（禁止） | 倒计时、分数惩罚、失败红叉、血条/危险警告 | **永不出现** | 对齐 MISSION 与祥和基调 |

> 【2026-11-13 PO 变更·核对】L4「返回主菜单」属模式 chrome 层，与入口缝正交。注记一项依赖：镇的宿主形态（独立模式壳 vs 冒险维度行）归 business-analyst 终裁——若并入冒险壳，L4 具体挂点随宿主 chrome 走，本行视觉规格不变。

### 4.2 屏幕布局与锚点（建议）
- **整体原则**：四角与边缘锚点 + 中央上方窄横幅用于主提示；**屏幕中央主视野与下半部前进路径保持尽量干净**（不遮挡可交互对象与道路）。
- **建议分区（桌面/常见宽高比基线，响应式收缩）**：
  - **左上（安全区内）**：L1 主任务/导览提示卡（横向圆角卡片，图标在左、短标签在右；最大宽度受限，超长转为图标序列/省略但 TTS 完整）。
  - **上中或右上（与左上不重叠）**：L2 方位指引（罗盘/箭头，见 §5）。
  - **中上偏上（非遮挡准星/视线焦点）**：L3 过程性表扬反馈浮现位（短暂、居中偏上，出现后自动淡出，不堆叠多条）。
  - **右上角边缘**：L4 系统轻入口（如有），图标按钮，触控友好尺寸预留（≥44×44 CSS px 等效热区，后续实现校准）。
- **安全区**：四边预留内边距（建议基线 16px，随视口 `clamp` 放大），关键 HUD 不贴边；与 `game-ui-ux` 安全区原则一致。
- **回望与可读性**：HUD 不遮挡“回望可见钟塔/广场开阔面”的关键视线区域（尤其屏幕上半部中央偏上）；方位指引辅助而非替代世界内地标。【对齐 `town-map-design.md` §4.3 回望原则】

### 4.3 任务/导览提示位规格
- **提示卡内容结构（A 负责容器与信息形态）**：
  1. **主图标**：对应目标类型（观察地标/寻找物品/回应 NPC/集合/探索发现等），来自 UI-01 语义方向，自建/自绘。
  2. **辅助图标/数量暗示（可选）**：如“找到 1 个”用单个物品图标而非数字强调（6 岁友好）；若必须显示数字，使用固定宽度数字槽避免布局抖动。
  3. **短标签**：1-6 字中文短语（如“找面包”“去钟塔”），仅辅助；TTS 朗读完整友好句。
  4. **TTS 重播**：卡片上提供小喇叭图标按钮（鼠标可点）重复朗读当前提示。【建议为游戏性调整】
- **状态**：`未开始/进行中`（柔和高亮）、`已完成一步`（切换为正向完成图标并短暂表扬后自动收起或切下一条）；**无失败状态**。
- **出现/切换动效**：淡入+轻微位移（8-12px）或缩放自 0.98→1，时长 150-250ms，`ease-out`；退出同理淡出。尊重“减少动态”偏好时降级为纯淡入淡出。【对齐 emil-design-eng 节制动效】
- **与对话的衔接**：当目标为“回应/对话”时，A 侧提示仅显示“可对话”标记与指引，点选 NPC 后进入 B 侧会话 UI；会话期间 A 侧主提示可弱化或暂隐，避免双重信息轰炸（具体状态机归后续 spec）。

### 4.4 图标 + TTS 配合与过程性表扬反馈
- **TTS 原则**：每个新主提示出现时可自动朗读一次（可被设置静音，音量/静音遵循全局约定）；语气友好、短句、鼓励式（如“我们去广场看看吧”“你找到了，真棒”）。
- **过程性表扬反馈（L3）**：
  - **视觉**：自绘正向符号（星星/花朵/笑脸/小徽章，对齐 UI-04），暖色柔光背景气泡，可带轻微粒子/光晕点缀但不闪烁。
  - **文案/语音方向**：夸努力与参与（“你找得很认真”“发现啦”“谢谢你帮忙”），不夸天赋、不比较、不评级压力。
  - **节奏**：单次反馈出现 1.2s–2.0s 后淡出；同屏不超过 1 条；不阻挡操作。
  - **禁止**：红叉、灰暗失败蒙层、扣分动画、催促语（“快点”“还剩…”）。

### 4.5 无倒计时/无惩罚 UI 原则（硬约束清单）
- 不显示倒计时、沙漏、进度耗尽条。
- 不显示“失败/错误/再试一次（带惩罚暗示）”；若需重试语义，用“再玩一次/再找找”中性友好表达且无代价。
- 不使用高饱和警示红作为常态 UI 色；错误预防通过可发现性与柔和提示完成。
- 任务提示可关闭/收起（图标按钮），但不因关闭产生负面后果。

### 4.6 鼠标点选可发现性
- **光标反馈（建议）**：默认箭头；悬停可交互对象时切换为“指向/放大镜/手形”语义的友好光标（自绘，与世界风格一致），同时对象触发高亮（见 §6）。
- **点击反馈**：按下即时轻微缩放/亮度变化（100-160ms），确认“系统听到了”；对齐 emil-design-eng 按压响应原则。
- **不可交互区域**：不产生误导性高亮；装饰物保持静态。

## 5. 小地图 / 方位指引（推荐方案）

### 5.1 方案比较
| 方案 | 优点 | 风险（6 岁/注意力训练） | 结论 |
|---|---|---|---|
| A. 详细小地图（俯视缩略图+实时位置点） | 空间信息全 | 信息密度高、读图负担大、视线在地图与世界间频繁切换，分散注意力；小图标难辨认 | **不推荐首版默认** |
| B. 简化罗盘/地标指引（推荐） | 单一焦点、低认知负荷、与“回望钟塔”空间叙事一致；指哪走哪 | 复杂多目标时需策略（首版默认单目标/单地标） | **推荐默认** |
| C. 世界内路标强化（地面箭头/光柱）+ 无 HUD 指引 | 沉浸 | 在遮挡/远距时可发现性不足；需更多场景资产配合 | 可作为 B 的辅助手段，非 HUD 主方案 |

### 5.2 推荐默认：**简化地标方位指引（Landmark Pointer）**【建议为游戏性调整】
- **形态**：
  - 一个紧凑的圆形/盾形指引器（位于上中或右上安全区），中心为“当前目标地标/任务锚点”图标（如钟塔、Lava Chicken 招牌意象图标、面包/花束任务图标），外围一个**柔和箭头或扇形指针**指示目标在玩家视野前方/左/右/后方的大致方位。
  - 当目标在视野内且接近时，可切换为“已在附近”状态（指针弱化为光点或对勾提示），鼓励观察世界而非盯 HUD。
- **目标对齐 map design**：
  - 核心地标：**钟塔/广场（P0-01）**作为全局回望锚点；指引逻辑与“主路回望可见钟塔”一致（`town-map-design.md` §4.3）。【电影原样】钟塔为视觉焦点母题。
  - 任务锚点：优先指向 `town-map-design.md` §6.2 建议的轻任务位置（广场导览、Lava Chicken、市集/农田/Secret Stash 等），一次一个主目标。
- **距离表达（儿童化）**：不用米/数字距离；用 3 档定性（远/近/就在附近）通过指针大小/填充/环数变化表达，避免精确计数压力。
- **可见性策略**：无活动目标时可收起或仅显示“钟塔”回家/集合锚点（可选）；避免常驻闪烁。收起/展开需可由系统策略控制（本 spec 不定规则，仅定视觉态）。
- **可选扩展（非首版必须）**：设置中提供“显示/隐藏方位指引”；**不提供**详细小地图切换，除非 PO 明确要求。【待 PO 确认】
- **无障碍/舒适**：指针运动平滑（低频插值），无剧烈旋转跳变；色彩与钟塔暖金/天蓝等区分但保持暖亮和谐。

### 5.3 若未来启用简化小地图（备选约束，PO 决策后适用）
- 仅显示：玩家朝向箭头、当前目标大图标、钟塔固定图标、简化主路轮廓；不显示复杂建筑细节与 NPC 实时密集点。
- 尺寸小而边缘锚定（如右上），半透明暖色底板；可一键开关（大图标按钮）。

## 6. 交互提示与点选高亮视觉规格

### 6.1 可交互对象分类（A 侧提示范围）
| 类型 | 示例 | 标记/高亮需求 |
|---|---|---|
| NPC（可回应/可对话） | 阿面、朵朵等在场村民 | 头顶或脚边柔和光环/图标标记 + 悬停描边；点选后交 B 侧对话 |
| 任务物品/观察点 | 面包篮、花束、招牌、农田目标物 | 物体轮廓高亮或底座光圈 + 浮动小图标（UI-01 语义） |
| 地标导览点 | 钟塔基座、樱花树、告示/导览锚点 | 轻量“可看看”图标，非强制 |
| 出口/返回入口（如有） | 离开小镇的柔和指引点 | 明确但不突兀的门/箭头图标，与危险出口区分 |

> 【2026-11-13 PO 变更·核对】「出口/返回入口」行语义更新：回程倾向=**镇内侧边缘回程线（双向边缘白闪，白闪回 home 主路尽头）**，柔和指引点=主路渐稀铺装 + 灯柱花坛收尾（预案见 [`town-entry-transition-visual-spec.md`](town-entry-transition-visual-spec.md) §B.5；**依赖 BA 缝规格终裁，若裁回程门则本预案返工、另补门面观感**）。本行视觉原则（明确但不突兀、与危险出口区分）保留。

### 6.2 高亮与标记状态机（视觉）
| 状态 | 视觉表现（建议） | 色值/尺寸建议（基线，对齐 UI-03） | 备注 |
|---|---|---|---|
| 默认（可交互，未聚焦） | 低存在感提示：对象上方/旁侧小图标或微弱底座光点；可选轻微呼吸感（周期 ≥2s，幅度极小） | 光点/描边主色建议 **暖金 `#E3B23C`** 或 **天蓝 `#7EC8E3`**（择一与背景对比更佳者）；图标 20-28 px（视口自适应） | 不闪烁、不抢主视线 |
| 悬停/可点选（Hover） | 对象轮廓柔和描边或外发光增强 + 光标变为可点选态；图标放大 1.05-1.1 倍 | 描边/光圈使用 **暖金高亮 `#FFD89A`** 或天蓝提亮；描边 2-3 px（屏幕空间）；过渡 120-160ms | 鼠标是唯一发现通道，必须清晰 |
| 按下（Pressed） | 轻微缩暗或缩放 0.97-0.99，确认点击 | 同 hover 色系，亮度 -8%~ -12% 瞬时 | 100-120ms 回弹 |
| 选中/会话中（Active，A→B 交接） | 保持柔和选中环，世界其余可交互提示可降噪 | 选中环 **天蓝 `#7EC8E3`**（冷静聚焦） | 具体会话态以 B 为准 |
| 完成/已回应（Done） | 标记切换为完成图标（如小花/星点/对勾的友好化变体，避免考试对勾生硬感）并淡化或消失 | 完成色 **草绿 `#7FB069`** + 暖金点缀；图标同尺寸体系 | 仅正向；不出现“未完成”惩罚标记 |
| 不可用/未到时机（如需） | 默认不显示或显示为普通装饰（无交互） | — | 避免“锁头/禁止”负面符号；若必须提示，用中性“稍后再来”由 TTS 表达（策略归 spec） |

### 6.3 色彩与可读性对齐
- 高亮色需与建筑/环境高频色区分：避开樱花大面 `#F7C6D9` 作为唯一轮廓色、避开道路浅石 `#D9CDBE` 作为描边；优先 **暖金/天蓝** 在暖木与石面上均可读（参照 `town-buildings-visual-spec.md` §4）。
- 色弱友好：状态不只靠颜色，配合**形状/图标变化**（如默认圆点→悬停光环→完成花朵）区分。【建议为游戏性调整】

### 6.4 触控与热区前瞻（虽当前为桌面鼠标）
- 可点选对象热区建议不小于 44×44 CSS px 等效（或世界空间投影后屏幕等效尺寸充足），相邻热点留间距防误点；实现阶段按相机距离校准。【对齐 `game-ui-ux` 触控目标原则，作为稳健性余量】

### 6.5 与资产清单（UI-01~05）对齐
| 资产 ID（assets-requirements） | 本 spec 细化建议 |
|---|---|
| UI-01 地标/任务标记图标集 | 增补：钟塔/广场/Lava Chicken/农田/Secret Stash/寻找/回应/集合 语义；状态变体至少 默认/高亮/完成 |
| UI-02 对话/提示气泡底板 | **B 侧会话气泡细节归 dialog spec**；A 侧仅复用同风格底板用于 HUD 主提示卡（奶油暖底、柔和描边、高可读） |
| UI-03 鼠标点选高亮/可交互提示 | 采用 §6.2 状态色与柔和发光；禁止闪烁 |
| UI-04 过程性表扬反馈图标 | 星星/花朵/笑脸/徽章自绘，1-2 级强度即可；与 L3 浮现位配套 |
| UI-05 手持/交互小道具图标 | 任务提示中引用面包/花束/卷轴等图标时与角色/场景道具语义一致 |

## 7. 口径对照（【电影原样】与【建议为游戏性调整】）

| 条目 | 【电影原样】 | 【建议为游戏性调整】（本 spec 采用） | 理由 |
|---|---|---|---|
| 地点气质 | Midport Village 和平友善、集市热闹、钟塔/广场为母题 | 入口与 HUD 采用暖亮、欢迎、低压迫视觉；钟塔/广场作为指引与导览核心锚点 | 传达可识别气质且服务 6 岁体验 |
