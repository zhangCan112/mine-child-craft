## 1. 依据与口径

### 1.1 拍板引用（不得改）
- 生命周期（ADR 0018 / R1-04~08）：放置即燃 → 燃烧约 5 分钟量级（灯笼 300s 同档）→
  燃尽=干净消失**无掉落无残渣**；水浇=立即转熄灭态方块（不发光不冒烟无气流不烫），
  点击重燃重置满时长；任意态挖掘=回收篝火道具。
- 气流（ADR 0017 / R1-09/10）：燃烧中篝火产生 3×3 截面×约 20 格高向上热气流；
  观感按此量级；柱内数值参数归 spec，观感跟随。
- 烫伤（ADR 0019 / R2-1）：踩燃烧中篝火每满 1 秒 1 血、起飞豁免、熄灭态不烫——
  反馈走既有 hurt 通道，**本稿零新增恐吓/警示观感**。
- 音频（R1-15 / A15）：点燃 1 声（噗地点着）+ 燃尽 1 声（轻轻熄灭）；无循环燃烧声；
  无事件 TTS；ItemHint 介绍照常（点到物品读名称+说明是全物品统一通道）。
- 配方（R1-12 / A12）：木棍×3 + 原木×3 + 煤或木炭×1 → 产出 ×2，工作台 3×3；
  **摆放图案归 spec**，本稿 §3.5 只给意象锚。
- 发现通道（R2-3）：ItemHint 只写基础说明，**不剧透乘流玩法**（PO 知悉「可能没人发现」
  风险并自担）——文案零「风/上升/飞天/气流/翼/滑翔」暗示、零任务暗示（R1-13）。
- 适用面（R1-01）：探险+体验馆同口径，建造不接入——两模式同观感（验收走查注明；
  体验馆 dev 降噪对话术/音效的既有消费差异是既有机制，不在本稿设计面）。

## 2. 设计原则（篝火 UI 总则）

1. **火是暖的朋友，不是吓人的怪物**：快乐暖色、圆软音效、零警示红闪零惊悚元素；
   「火会烫」的安全意识由既有 hurt 通道承担（ADR 0019），观感不叠加恐吓。
2. **远近双通道可读性**（可读性三条的落点）：近看有细节（焰芯/柴堆/余烬），
   远看有信号——灰白烟柱=「远处有篝火」（BotW 远距信号语言），冷白旋涡柱=
   「这里有风可乘」（BotW 气流语言）；两态方块 3 格外一眼可辨。
3. **烟风分色**：烟=暖灰白（慢飘），风=冷亮白（快转上升）——色温差让 6 岁孩子
   不靠形状也能分「烟」与「可乘的风」。
4. **全走既有语言，零新管线**：图标走像素图标工坊正典（glider 单条目先例）、贴图走
   PAINTERS 自绘纪律（种子化噪声）、特效挂 Fx 句柄制（portalBeam 同形态）、话术走
   ItemHint 儿童口径、音效走 AudioRegistry 一行数据——不发明新通道。
5. **零文字零数值零倒计时**：观感与文案不念数值（不读「5 分钟」「light 15」）；
   燃尽临近靠火苗渐弱表达，不做任何 UI 计时（MISSION 零倒计时压迫）。
6. **动效克制**：粒子是「提示」不是「瀑布」，速率有分档上限；特效只在燃烧中存在，
   熄灭即静（安静表达）。

## 3. A 区 · 道具像素图标 + 配方卡观感【设计定稿】

### 3.1 意象与色板
- **意象：火坑柴堆**——侧视构图：上半是四档色阶的火苗（白芯→亮黄→橙），下半是
  原木床（受光/主色/背光三档横梁）+两端对角短棍+余烬炭点。取舍：16px 尺度下 X 交叉
  柴堆的两条斜线互缠成模糊团，侧视柴堆分层清晰，且与 B 区方块贴图同构
  （图标=贴图的微缩，孩子从物品到方块读到同一形象）。
- **色板（焰四档/原木三档同源既有权威，新色仅四档且各给来源档位）**：

## 5. C 区 · 世界内特效观感【设计定稿】

### 5.1 效果清单与挂靠

- 挂靠：全部走 `Fx`（js/effects.js）既有语言——常驻件走**句柄制新入口**（portalBeam/

- 纯表现层声明：全部粒子可非确定、可按帧率分档（research §7-4 口径），零玩法判定。
- 触发接线（谁在何时调 Fx）归 spec/装配票，本稿只锁观感参数。

### 5.4 热气流柱可视化【设计定稿】（BotW 白色旋涡语言，research §5:122）
- **形态：旋涡粒子为主 + 极淡柔柱轮廓**。否决 portalBeam 式实体双层柱：实体亮柱读成
  「传送门/激光」，且 20 格实心柱视觉过重；柔柱只提供远距柱体轮廓。
- **柔柱**：直径 2.6 格（3×3 截面内切观感，spec §3.5 判定 Chebyshev 半径 1），高=
  **柱满高**（火面向上，缺省 20 格——spec §3.9 参数表唯一权威），MeshBasic
  `#f5f7f3`，opacity 基线 0.10+正弦脉动 ±0.05（周期 3.7s，portalBeam 脉动
  手法同源）。低核档：opacity 降 0.06 常值（脉动砍）。
  **遮挡边界登记**：spec §3.5 的遮挡截断（遇实体列无升力）是**查询时按玩家列扫描的
  判定语义**；观感柱恒显满高、不逐玩家逐列跟随截断——顶上有遮挡时视觉柱穿模为
  **已知边界**（spec §3.5「贴顶接受边界」同款登记口径，评审不得当 bug 报）。
- **旋涡粒子**：

| 参数 | 桌面/高核档 | 低核触屏档 |
|---|---|---|
| 活跃粒数 | 16 粒/柱 | 8 粒/柱 |
| 公转 | 角速度 1.3 rad/s，半径 0.5~1.1 格（3×3 内缘）随机 | 同 |
| 上升 | 3.0±0.5 格/s（观感预告 spec §3.9 乘流升速 +3.0 格/s 初值） | 同 |
| 高度域 | y+0.5 → 判定柱顶，到顶回卷取模循环（portalBeam motes 同款） | 同 |
| 尺寸/色/透明度 | 0.08~0.13 格 · `#f5f7f3` 冷亮白 · opacity 0.75 | 同 |
| 旋向 | 全部篝火统一逆时针（俯视）——多柱同向不打架 | 同 |

- 色值出处：`#f5f7f3` 新色——偏冷灰白，与烟暖灰白 `#d6d2c8` 构成色温差分色
  （设计原则 3：暖白慢飘=烟，冷白快转=风）。
- 生命周期红线：气柱可视化**只在燃烧中存在**（research §3.1「只有燃烧中才有气流」）；
  浇熄/燃尽即刻撤柱（过渡见 §5.5/§5.6）；**燃尽临近渐弱期气柱观感与判定都不衰减**
  （乘流可预期到最后一秒，ADR 0017 相容）。
- 多柱重叠：每柱各自画、粒子自然穿插（spec §3.5 裁定「重叠区取最强一柱不叠加」是
  判定侧语义，观感不合并）。

### 5.5 点燃过渡【设计定稿】（放置即燃 & 熄灭态点击重燃共用）
1. pop 膨胀淡出球：色 `#ff8f00`，r0 0.3 → r1 1.6 格，dur 0.35 s，opacity 0.9（pop 现行默认）。
2. 三发射器渐起：火苗/烟/气柱速率 0 → 满额，0.5 s 线性爬坡（火「噗」地起来，不是瞬满）。
3. 音：`campfire_lit` 同拍（§7）。
4. **禁用**：kick 震屏、debrisBurst（零惊吓）。

### 5.6 燃尽过渡【设计定稿】（ADR 0018：干净消失，无掉落无残渣）
1. 三发射器渐熄：火苗速率 0.4 s 降到 0；柔柱 opacity 0.3 s 降 0；旋涡粒子停止补充、
   存量自然消散（**≤2 s 全清**，无残影帧）。
2. 轻灰 pop：色 `#d6d2c8`，r0 0.4 → r1 1.2 格，dur 0.5 s，opacity 0.5——「轻轻散掉」。
3. 尾烟一撮：3 粒灰白烟（§5.3 参数一次性），1.5 s 散尽。
4. **禁用**：debrisBurst 碎块、灰烬/残渣观感（方块消失=地面干净，ADR 0018 拍板）。
5. 音：`campfire_out` 同拍（§7）。

### 5.7 浇熄过渡【设计定稿】（ADR 0018：水灭火的自然因果）
1. 白汽 pop：色 `#f5f7f3`，r0 0.3 → r1 1.4 格，dur 0.4 s，opacity 0.6。
2. 白汽粒：4 粒，寿命 0.8 s，上升 1 格/s（一缕白汽）。
3. 三发射器**即刻摘除**（句柄 remove 同款，无火苗残帧）；方块切熄灭态贴图。
4. 音：**不配新声**（PO 拍板只有点燃/燃尽两声）；「是否复用既有 lava_hiss」列未决项
   §9.2-1（缺省=不配声）。

### 5.8 燃尽临近渐弱【设计定稿，时钟语义对齐位】
- **触发（相对参数，双写口径）**：剩余时长比例 ≤10%（=300 刻=30 秒 @6000 刻档），
  等价表述「燃尽前最后 30 秒」——**整数刻游戏钟拍板下两表述数值等价，实现任取其一**
  （U-1 已拍板 2026-11-16，campfire-spec §4=20tps 独立累积器、6000 刻=300s 档）；
  双写口径保留（两写法拍板下恒等价），规格参数零改动。
- 表现：火苗发射速率线性降至满额的 40%，粒子焰色向 `#e05a1a` 整体插值（火「小」了）；
  烟量不变（火小烟浓的生活直觉可留实现自由度）；**气柱观感与判定完全不衰减**（§5.4）。
- **禁止**：任何 UI 倒计时/进度条/血条式表达（MISSION 零倒计时压迫）——渐弱只发生在
  世界内火焰本身。
- 燃尽瞬间无缝衔接 §5.6。

### 5.9 性能分档与多篝火预算【设计定稿】（ipad5 低核分档口径）
- 分档：低核触屏（config IS_LOWCORE_TOUCH）速率减半（§5.2/§5.3/§5.4 表第二列），
  柔柱降档——判据在减半档下全部仍成立。
- 多篝火（R1-11 不限数量）：同屏活跃 >3 座时按距玩家距离排序，第 4 座起降为
  「烟柱全额+火苗半速+旋涡半数」；距玩家 >40 格：只留烟柱（远距信号本分，
  与 §5.10 判据一致）。**【实现自由度】**阈值微调，验收=四座以上不掉帧且远火仍有烟。

## 6. D 区 · 文案话术【设计定稿】

### 6.1 ItemHint 全文（ITEM_HINTS.campfire，逐字定稿）
> **「放在地上，烧好久好久，又亮又暖」**（15 字，≤16 达标）

- 逐段对账：`放在地上`=放置型可用性提示；`烧好久好久`=PO A15 方向原话保留；
  `又亮又暖`=基础用途（照明+暖）双点。**不复述名字**（注册表纪律：名字权威在 ITEMS，
  「篝火」二字由 tts 拼装自动带出）。
- 备选（已否决存档）：「能烧好久好久的暖和篝火」——PO 方向原话直译，因含名字二字
  违反注册表「不复述名字」纪律而否决（过程笔记 §2-D1）。

### 6.2 放置失败话术（全文+语气定稿；触发时机归 spec）
> **「篝火要放在结实的东西上面哦」**（14 字）

  篝火**（campfire-spec §3.3 技术裁定「防火塔叠罗汉」，明示复用同一温和话术通道）——

## 7. E 区 · 音效参数【设计定稿】

### 7.1 新键两枚（SFX_KINDS 各一行，清单注册表惯例）

| 键 | 触发 | synth（合成定义） | g | gTouch | prio | coolMs |
|---|---|---|---|---|---|---|
| `campfire_lit` | 放置即燃成功 / 熄灭态点击重燃成功（同键共用） | `{noise:{type:'lowpass', freq:480, dur:0.18}, g:0.10}` | 1 | 1 | 2 | 300 |
| `campfire_out` | 自然燃尽瞬间 | `{noise:{type:'lowpass', freq:320, dur:0.45}, g:0.08}` | 1 | 1 | 2 | 300 |

- **synth-only 登记**（无 file 字段）：wing_open/wing_close 同款「合成即可，不强制找
  样本」纪律——「永不哑」互锁天然成立；后续音频批若入 CC0 点燃/熄灭软样本，升级为
  file+synth 双轨（一行数据，不阻塞，列 §9.2-5）。
- 声音性格转写：`campfire_lit`=PO A15「噗地点着」的声学直译——低通 480 Hz 白噪短噗
  （snow_throw 低通闷噗家族放长；比 fuse 高通 1600 急嘶柔两个档次，儿童零惊吓）；
  `campfire_out`=「轻轻熄灭」——更低（320 Hz）、更轻（g 0.08）、更长（0.45 s）的
  安顿音（wing_close「收=安顿感，比展开安静」口径）。
- 参数依据：prio 2=状态音档（wing 先例；仪式档 4 留给升级/胜利/穿门）；coolMs 300=
  防连放多座/浇熄秒重燃的同声叠爆（wing 同款）；g/gTouch 1/1=注册表「中性 1 起步、
  响度由 synth 内 g 配平」现行纪律。
- 命名定稿：`campfire_lit` / `campfire_out`（否决 `campfire_light`——动词歧义；
  `campfire_burnout`——过长且「燃尽」语义偏机制）。
