## 2. 总体风格定位

### 2.1 气质与基调
- **【电影原样参考】** Midport Village 村民群像：和平、友善、热爱面包与交易、铁傀儡是直观守护符号；整体“热闹但友好”的聚落感（见调研 S1/S2）。
- **【建议为游戏性调整】** 本项目角色视觉目标：**温暖、明亮、低威胁、易读**。所有角色表情与姿态以欢迎/忙碌/放松为主，不出现恐惧、攻击挑衅、血腥或损毁夸张表现（铁傀儡裂纹仅作“需要关心”的轻度状态提示）。

### 2.2 体素/方块语言（与 MC 模型语言对齐的自建方向）
- 造型以**大块面、清晰轮廓、少而稳的部件**为主，避免细碎装饰淹没轮廓。
- 比例采用 MC 村民/傀儡的可读特征（大头/长鼻/长臂/袍体等）做**自建简化转译**，不追求电影写实比例。
- 材质分区在贴图/体素面上用**大色块+少量边缘描边感对比**表达（边缘可用 1px 深一阶色带暗示缝线/折边），保证 6 岁儿童在小屏/远景也能分辨职业与身份。
- **【建议为游戏性调整】** 默认使用 `1 体素像素 = 0.0625 格` 的像素单位思维描述规格（与 `docs/mc-mob-models-research.md` 同口径），便于实现侧直填；本文三视图同时给出相对比例，避免绑定单一实现尺寸。

### 2.3 6 岁可读性原则
- **职业一眼可认**：每个职业至少有 1 个强识别符号（帽子/围裙/工具/背包/袖章色）。
- **情绪一眼可认**：默认微笑/眯眼笑，眼睛与眉区对比清楚；避免复杂阴影。
- **危险感归零**：无武器指向玩家、无红色怒目常态、无尖牙利爪强调（铁傀儡亦圆润化关节观感）。
- **色彩分层**：肤色/眼睛/服装三层对比明确（见 §4.2），防止“糊成一块”。

### 3.2 皮肤-眼-服装对比规则（强制）
- **村民主层级**：`皮肤(中明度暖棕)` + `眼睛(深绿小面积高对比)` + `服装(职业主色大面积)`，三层亮度至少跨 2 档。
- **眼睛可读性**：瞳/眼缝与眼白或脸部必须有明确明暗差；最小可读单元建议 ≥ 2×2 贴图像素（远景可退化为 2×1 但仍保对比）。
- **服装与皮肤分离**：袖口/领口/围裙边至少有一条辅色或深边线，避免手臂与上衣同色糊连。
- **铁傀儡对比**：主体铁灰 + 眼缝暗红点光 + 藤蔓绿点缀，三者分属不同色相，保证守护者轮廓与“非敌对”识别。

## 5. 详细角色规格

### 5.1 村民通用规格（Villager Base）
- **结构语言（【建议为游戏性调整】自建方向，参考 `villager_v2`）**：大头 + 长鼻前突 + 粗眉区 + 袍体（身体与腿视觉连成袍摆）+ 交叉/自然垂臂两种手臂姿态切换。
- **基准比例（像素单位，参考 mc-mob-models-research 村民/灾厄基座语感）**：头约 `8×10×8 px`，鼻约 `2×4×2 px`，身袍约 `8×12×6 px`（可含下摆延伸至腿区视觉），手臂单侧约 `4×12×4 px`。整体高度约 **2.0 格**（视觉可略矮胖以显亲切）。
- **皮肤与面部默认**：肤色 Villager Skin A/B；眼睛 Eye Deep + Eye Highlight；眉线 Outline Brown；默认表情微笑（嘴角上扬 1~2px 弧线）。
- **行为总则**：慢步走、偶停驻、转头注视玩家、挥手/点头；无奔跑惊慌、无躲避恐惧动画常态。
- **日程总则（文字）**：`清晨` 到岗/整理 → `白天` 工作与社交 → `傍晚` 向广场/钟塔聚集 → `夜间(柔和)` 回屋休息姿态（**【建议为游戏性调整】** 默认不展示真实黑夜危险）。

```text
        └─┬────┬─┘
          │腿  │
          └────┘
```

**特征点清单**：长臂过膝｜小头大躯干｜眼缝暗红但温和｜藤蔓绿点缀｜裂纹按四档叠加（不改变轮廓）。

## 7. 互动/状态视觉

### 7.1 村民表情与手持道具

| 类别 | 视觉规格 | 触发/日程语境 | 备注 |
|---|---|---|---|
| 默认表情 | 微笑：嘴角上扬弧线 1~2px；眼睛眯笑可选（眼高减半） | 常态/交互待机 | **【建议为游戏性调整】** 统一友好基线 |
| 打招呼表情 | 眉线微抬 + 嘴张小开口 1px + 眼高亮点保留 | 玩家靠近/被点击问候 | 配合挥手姿态 |
| 专注/工作表情 | 嘴线平直、眉线轻压（不皱怒） | 农作/修缮/查看卷轴 | 仍保持温和 |
| 开心表情 | 眼睛弯月形、嘴巴更宽笑弧 | 收到帮助/完成轻任务反馈 | 可配合小跳（V10） |
| 手持-面包 | 面包块 3×2×2，主色 #D9A441，高光 #F7E3B5 | V01/V07/通用交易氛围 | **【电影原样参考】** 爱面包 |
| 手持-工具 | 锤/锄/钳等圆角简化体素，金属 #9AA0A6+木柄 #B57A4A | 对应职业 | 工具不指向玩家 |
| 手持-花束/卷轴/托盘 | 见各角色规格 | 对应职业与场景 | 识别符号优先 |

**表情实现建议（不绑定代码）**：优先用贴图帧/UV 区域切换或面部子块替换；同一角色表情集 ≤ 4 种，避免资源膨胀。

### 7.2 铁傀儡裂纹与修复状态（四档）
**【建议为游戏性调整】** 采用 `docs/iron-golem-research.md` 的 4 档裂纹语义做儿童友好化表达：裂纹是“需要照顾”的提示，不是恐怖损伤。

| 状态档 | 血量语义（参考） | 视觉表现 | 色值/材质建议 |
|---|---|---|---|
| 完好 | ≥75% | 无裂纹；铁面干净；藤蔓完整 | 主体 #BFC5CB/#9AA0A6 |
| 轻裂 | 50%~75% | 躯干或手臂出现 1~2 条细裂纹线（1px） | 裂纹线 #7A8086 + 内侧微暗 #5A4636 |
| 中裂 | 25%~50% | 裂纹增至 3~4 条，分布在胸/背/臂大面；边缘轻微缺口感（仍圆润） | 同上，局部补 #8D9399 磨损块 |
| 重裂 | <25% | 裂纹网络明显但不破洞穿透；姿态略显疲惫（行走慢、停驻多）——姿态归行为层，视觉仅加纹理 | 裂纹线加密，仍避免“碎裂/掉零件”惊吓感 |

- **修复视觉**：使用铁锭修复时可叠加短暂高光闪烁（#D7D2C8 0.3s 渐隐）+ 裂纹层级回退一档；音效/反馈由实现层决定，本文仅规定视觉语义。
- **裂纹叠加规则**：裂纹为贴图/材质叠加层，不改变基础轮廓与碰撞；各视图优先在可见大面展示，保证玩家一眼可读。

### 7.3 铁傀儡献花互动
- **【电影原样参考】** 献花是铁傀儡温柔守护的标志性意象（调研与 MC 机制均支持友好表现）。
- **视觉规格**：
  - 花朵：小型虞美人意象转译（圆瓣团块）4×4×4px，花瓣 #F4A7C1，花心 #F7E3B5，茎 #7FB069。
  - 持花姿态：右臂从下垂抬至胸前偏前，高度约躯干中线 y=26~28；上半身前倾 5~8°；头微低。
  - 接收对象氛围：面向孩童气质村民 V10 或附近村民时触发；花朵可短暂出现在傀儡手中（1.5~3s 循环姿态），不要求物理递交判定由本文定义。
- **情绪约束**：眼缝发光不变色、不增强；整体仍为安静守护感。

### 7.4 群体热闹与祥和表现（角色层）
- **【电影原样参考】** 市集/广场人群的热闹与友善。
- **【建议为游戏性调整】** 通过“姿态错落 + 手持物多样 + 2~3 人小簇组站位”表达热闹，不依赖快速移动或高密度碰撞：
  - 广场簇组示例：V01 挥手 + V06 展示花束 + V10 小跳 → 视觉丰富但路径清晰。
  - 互动优先级：注视玩家 > 挥手/点头 > 回到工作姿态；所有反馈节奏舒缓（≥1s 周期）。
