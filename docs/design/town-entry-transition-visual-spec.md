### A.2 白闪观感规格（复用 Veil Edge Variant 暖白径向渐变语言）

**复用现成遮罩机制（`#portalVeil` 挂 `.edge` class，`js/modes/adventure.js:2635-2640`），不发明新遮罩。**观感参数照抄现网（`css/style.css:1115-1124`）：

| 参数 | 现值（复用） | 说明 |
|---|---|---|
| 径向形态 | 中心暖白 `rgb(255 250 240 / 88%)` → 中段 `rgb(255 244 214 / 92%)` → 边缘 `#ffefd0` 的径向渐变 | 同一元素换装（摘自基段紫调 `css/style.css:1103-1113`），透明度逐帧直驱仍归基段 |
| 色语言 | 暖白系（`#ffefd0` 与城镇盘「布幔-奶油 `#F3E6C8`」「暖光-灯火 `#FFD89A`」同族相邻） | 白闪色是转场域色，不在城镇盘 §4.1 内——**不改色值**；暖白与城镇暖亮基调天然互文，核对通过 |
| 硬口径 | 「忌纯白刺眼忌纯黑」（css 注释原文，调研 D3 幼儿口径） | 与本文 A.6 禁焦虑清单承接 |

**时长体感校准建议（0.8–2s 区间）**：现网 `ADV_VEIL_T=0.4s` 单段、淡入+淡出双段共 **0.8s**（`js/modes/adventure.js:2621,2699-2714`），满格瞬间执行到达。校准建议：

- **首版直用 0.8s**（现网参数原样，白闪段零改动）；
- **调参落点 = 满格停留窗延长**（0.4s 淡入 + hold 0~0.6s + 0.4s 淡出），仅当走查发现镇维度 `loadScene` 同步重建体感不足（露中间态/掉帧）时启用；**不改渐变形状、不异步化**——GLOSSARY 白闪变体 _Avoid_ 明文：「满格遮蔽窗内的同步重建是体验契约，异步会露重建中间态」；
- **硬顶 2s**：遮罩必须快（`docs/map-transition-research.md` §0.3 Mass Effect 教训；幼儿遮罩上限 2–5s 取其下段——本缝切界是同步操作，取更紧的 ≤2s）。

### A.3 过场时序体感

| 时刻 | 阶段 | 孩子看到 / 听到 | 载体（现成机制） |
|---|---|---|---|
| t0 | 越线触发 | 主路尽头走近栅栏，触发线命中（几何归 BA）；TTS 触发播报「我们去小镇啦！」起播 | 触发线词条 + A.4 |
| t0 → t0+0.4s | 白闪淡入 | 暖白径向渐变满屏（A.2） | `#portalVeil` `.edge` class |
| t0+0.4s（满格瞬间） | 同步切换 | `portal_travel` 音；镇维度同步重建（满格遮蔽窗内，体验契约）；HUD 横幅槽换挂镇名牌 | 边缘传送词条 + 维度规格 `advSetDim` |
| t0+0.4s → +0.8s（或 hold 后） | 白闪退 | 镇世界显影：南主路落点、正前方钟塔走廊与广场开阔面 | spawn 锚 `face:'north'`（现成） |
| 落地 | 到达演出 | TTS 到达播报「到小镇啦！」+ toast 🏘️；镇名牌横幅常驻（维度 HUD） | A.4 / A.7 |

全程体感目标：**一闪即到**——0.8s 转场窗内完成「草原尽头 → 小镇主路」，无加载感、无等待感（切界本体同步成本仅帧级，遮罩是到达仪式不是性能遮羞布；对齐传送门阵词条 _Avoid_ 与 `docs/map-transition-research.md` §2.1 Metroid Prime 门=仪式先例）。

### A.4 TTS 话术表（触发播报与到达播报分开）

| 环节 | 时机 | TTS 主案 | toast | 对齐先例 / 口径 |
|---|---|---|---|---|
| **触发播报** | 白闪淡入窗（t0 起） | **「我们去小镇啦！」** | `🏘️ 我们去小镇啦！` | T-UI-00 雏形「我们去小镇啦」迁入触发语境（旧语境=点卡后过渡；新语境=踩线越线瞬间）；拟人+短句+期待，零机制词 |
| **到达播报** | 白闪退+落地 | **「到小镇啦！」** | `🏘️ 到小镇啦！` | 对齐现网「到沙漠啦！」式口径（advVeilArrive map·edge 分支 `'到'+row.name+'啦！'`，`js/modes/adventure.js:2696-2697`）；维度行 `name` 建议=**'小镇'**（字段决策归 BA，取短名使到达句式自然） |

- **双播报叠加防护**：两句自然间隔 ≈0.8s（一个转场窗），建议 TTS 通道排队（会话 UI 已有通道仲裁先例，`town-ui-dialog-spec.md` §2.2「TTS 通道」行）；**兜底方案：只保留到达播报**——到达语义优先（回答「我在哪」），触发播报是锦上添花。播报位（触发时机挂点）归 BA/工程线接线。
- **零压迫口径**：不出现「传送 / 维度 / 加载」等机制词；无倒计时、无催促；称谓沿用现网拟人「我们」先例（「我们去广场看看吧」「灯笼用完了，我们再做一个吧」）。
- **旧话术退役**：east-spec 旧主话术「小镇还在建造中！等盖好了，这里会很热闹哦～」随新缝退役（与新缝「随时可去」语义矛盾）；其「很热闹」期待词已迁入镇名牌副语（A.7）。改稿建议见 B.4。

### A.7 到达演出（镇名牌 / 钟塔 / 落点朝向）

到达演出三拍，全部走现成载体，**零新增 UI 组件**：

1. **镇名牌**：维度行 `hud.banner` 槽（现成机制，nether/den 先例同槽）。
   - 主案文案：**「🏘️ 米德波特小镇 · 广场真热闹」**（格式对齐先例 `emoji + 地名 + ' · ' + 气氛短语`）；旧入口卡副标题「逛广场 · 找朋友 · 轻松玩」的轻松语义由副语「广场真热闹」承担（期待词亦承接 east-spec 旧话术「会很热闹」的退役遗存）。

## §B 路径引导视觉

### B.1 引导语言总则

- **世界内语言优先**：铺装 / 花田 / 告示牌 / 栅栏缝 / 剪影灯点就是全部引导；**零新增 HUD**（冒险模式无方位指引器——Landmark Pointer 是镇内 UI，hud-spec §5）；**禁可见墙**（触发线 _Avoid_：「把触发线画成可见墙」）；**禁否定语**（不写「禁止通行 / 此路不通」类）。
- **对齐路网先例**：镇内路网语言以 `town-map-design.md` §4.3 为权威（主路浅石铺装/中石路缘/交叉口灯柱花盆路标色块轻提示）；home 侧对应语言=土路主径 `#B9975B`（east-spec 定稿速览）+ 圆石小径（门口段先例，2 宽走廊间断铺）。两图坐标系独立（research §六.4），**不做跨图铺装延续**——白闪承担衔接（「大地让开」让开的是世界，不是铺一条跨世界的路）。
- **色彩权威**：主路尽头既有件色值沿用 east-spec 定稿（告示牌板 `#C89858` / 字 `#4A2E14` / 柱 `#8B5A2B`；栅栏桩 `#8B5A2B` / 横杆 `#9C6B35`；花田黄 `#F2C14E` / 红 `#E25C4A` / 白 `#F5F5F0`）；新增读法件（告示牌图案、路标点缀）取色对齐 `town-buildings-visual-spec.md` §4.1（暖金 `#E3B23C`、樱粉 `#F7C6D9` 可作点缀）。

### B.2 主路引导阶梯（home 图东向，世界内语言零 HUD）

既有东向动线自身已是完整引导阶梯（research §1.2 事实），新缝下**逐段读法升级**、件零改动：

| 段 | 位置 | 既有视觉件（零改动） | 新缝下孩子的读法 |
|---|---|---|---|
| 小屋 → 广场 | x62~77 + 广场 x78~92 | 圆石小径 + q16 任务指路（既有） | 任务语境（不变） |
| 广场东缘 → 望塔 | x93~108 东段小径 | 圆石小径（既有） | 「广场外面还有路」 |
| 东带①入口 | x128~139 | 土斑涌现（既有） | 「路好像有了」 |
| 东带②渐密 | x140~151 | 土斑 2 patch + 花田 2 处（既有，**东向独有件**） | 「有人耕作——快到了」 |
| 东带③主径 | x152~156 | 主径连续 `#B9975B`（既有） | 「一直走」 |
| 尽头 | x156~157 | 告示牌 + 栅栏缝 + 剪影 | → B.3 演出 |

- 增强项（非必需，登记不阻塞）：若走查体感「广场→东带」中段指引不足，可在东段小径中点（望塔基座一带 x≈110）加一枚路标色块 / 箭头拼块（对齐 town-map §4.3 交叉口轻提示语言），归地图侧票。

### B.3 尽头地标演出（告示牌改读 / 栅栏缝 / 剪影灯点）

**告示牌 x156 文案读法建议**（现状语义「小镇建造中」+ 板面拼块形制无字=T7 登记偏差，正好顺势收编）：

- **改读理由**：「建造中」与白闪可进的「随时可去」语义直接矛盾；新读法=「这就是去小镇的路」类**期待指向**。
- **主案（图标为体，零文字依赖）**：板面拼块改读 **「钟塔 + 小径向东」图案**——牌上画的 = 缝里看见的（与栅栏缝外剪影互文：钟楼剪影 z74 与主径同轴，牌上钟塔图案 = 剪影的预告）；对齐 6 岁零文字依赖（MISSION 图标+TTS）；实现现状拼块形制顺势转正，专属像素图案归 UI-01 资产票（16×16/32×32 暖亮高对比先例，语义可复用 belltower marker）。
- **辅案（文案，若走查需要字）**：**「小镇在这边！」**（5 字形制对齐原牌「小镇建造中」5 字；字朝图内（西）6 岁可自读——方向肯定语，非许可否定语）。
- **色**：板/字/柱先例色不动；图案点缀可用暖金 `#E3B23C`（钟/灯意象）。

**栅栏线 x157 读法升级**：桩间留缝是设计本体（「看得见、过不去、但不堵心」），新缝下读法升级为 **「看得见、马上就能过去」**——缝 = 剪影显影的预告窗；白闪在近栅栏处让开大地，孩子「扒缝看」的期待动作直接兑现为「走进去」。

**剪影灯点读法升级**：窗灯 3 + 塔灯 1（夜间发光火把），旧读法「还没建好但已经有灯亮着」→ 新读法 **「小镇亮着灯等你来」**。
- 解锁链预案登记（若 BA 走任务档解锁，对齐三向先例）：锁定态灯点不亮 → 解锁 rite 白闪让开瞬间点亮（建场读键先例：GLOSSARY 传送门阵解锁段「白闪让开=建场读键的新地貌」）——**预案归 BA 终裁**，本文只登记观感候选。

### B.4 近前引导话术与视觉态分级

机制背景（引用）：近前引导区 `advEdgeHintAt` + 30s 节流（`ADV_EDGE_HINT_CD`）= **机制归 BA**；三向先例语言规范=拟人 + 指回任务 + 给期待、**一律不引用门**、分级不剧透未来步（`js/modes/adventure.js:2777-2812` 句式先例）。本文定**话术文案与视觉态分级**：

**主案：城镇直达（无任务门槛）**——推荐。理由：城镇气质是「逛广场 · 找朋友 · 轻松玩」（零压迫），主路本身就是长期可见的实体引导（不同于三向的屏障远引），无锁则无「路在睡觉」话术需求，认知负荷最低：

| 态 | 近前语境（示意，几何归 BA） | TTS 话术 | toast |
|---|---|---|---|
| 开放 · 近前带 | 东带近前引导区 | 「前面就是小镇啦！沿着小路一直走！」 | `🏘️ 前面就是小镇` |

**预案 B：任务链解锁（若 BA 裁走三向同构解锁）**——两级话术（句式对齐三向先例，`st.open` 词取「栅栏就会让开的」，与雪/沙/雾让开同族）：

| 分级 | 语境 | TTS 话术 | toast |
|---|---|---|---|
| 链没走到 | 前置任务未到当前步 | 「东边小镇那边还在睡大觉！先做完任务卡上的任务，栅栏就会让开的，就能去小镇啦！」 | `🔒 先做完任务卡的任务，通往小镇的路就会打开` |
| 前置任务=当前步 | 点名具体做什么 | 「先○○，栅栏就会让开的，就能去小镇啦！」 | `🔒 先○○，通往小镇的路就打开啦` |

**拒绝话术（挖/拆旗标保护件，保护语义仍成立，理由改稿）**：
- 旧（退役）：「栅栏和牌子还不能拆哦～小镇还没盖好呢！」
- 新（本文建议）：**「栅栏和牌子不能拆哦～从小路走过去就是小镇啦！」**——保护理由换成指路，零否定收尾。

**触发/到达播报**见 A.4；**旧 east-spec 话术(主)退役**说明见 A.4 末条。视觉态分级与话术分级联动：开放态=灯点亮+剪影清晰（现状即满足，零改动）；解锁态（预案 B）=灯点暗→rite 点亮（B.3 预案）。

### B.5 镇内回程引导视觉预案

> **依赖 BA 缝规格定稿（`docs/town-map-design.md` §6 入口缝章，BA 并行产出）；按「双向边缘白闪」倾向出预案——若裁回程门（站桩门体）则本小节返工，门面观感另补（见本节末）。**

- **镇内侧回程线视觉预案**（倾向=镇内侧南主路尽头的回程边缘线，白闪回 home）：
  1. **铺装渐稀镜像渐变**：南主路向镇南缘延伸段，浅石主路 → 碎石 → 草——home 东带「草→土斑→主径」递进节奏的镜像（「离家越来越近」读成「离家越来越远」的反向：离开镇心，路慢慢变回草原）；
  2. **收尾两拍**：路口路标色块 / 灯柱花盆轻提示（town-map §4.3 交叉口语言）→ 尽头开阔无墙（**不画可见墙**，触发线 _Avoid_）——「回家的小路」读法；
  3. **近前话术预案**：「沿这条路走回去，就回到家啦！」（拟人+方向+期待，不引用门）。
- **白闪**：同 kind='edge' 暖白语言，A.2 全套复用；无站桩无二次确认（U3 同口径）。
- **home 侧回程落点意图**：主路尽头栅栏内侧主径可站立带（x≤156），**面西朝家**——落地转身即再赏告示牌 + 栅栏缝 + 剪影（「从哪缘越线出去回哪缘」来向锚语义，GLOSSARY 边缘传送/传送门阵先例）；零摔落、零悬空、不落触发线口袋。落点几何归 BA。
- **回程到达播报**：「回到家啦！」+ toast `🏡`（advVeilArrive home 分支同构先例，`js/modes/adventure.js:2696-2697`）。
- **若 BA 裁回程门（返工预案登记）**：门面观感另补——对齐远征图回程门先例（GLOSSARY 回程门挪边词条：门框体 + to=home 恒亮语言），门口轻提示 + 「回家」图标；届时本文补「回程门面观感」小节，B.5 其余（镇内渐稀铺装/近前话术方向）仍适用。
