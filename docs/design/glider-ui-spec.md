## 2. 设计原则（滑翔翼 UI 总则）

1. **快乐第一，安静表达**（R1-19 + A9）：翼是滑翔画面的主角，暖色、对称、灵动；
   零 TTS、零警示红闪、零惊悚元素；反馈靠形态与音效，不靠文字。
2. **图标语义自明，零文字依赖**：6 岁孩子不看字也能读出「翅膀=会飞」
   （图标/槽位/纸娃娃三处同一意象同一色板）。
3. **观感语言与既有装备系统同族**：槽位样式沿用装备页槽语言（虚位虚线、黑底圆角），
   图标走像素图标工坊正典手法（暗底/主色+亮纹），翼走 MobLook 官方平面盒手法。
4. **屏幕零新增常驻件**：滑翔状态指示复用既有装备条槽位，不开新 HUD 面积——
   把画面留给风景。
5. **动效克制**：展收单段匀速（SpinnerCore 简洁哲学），微动小幅呼吸；
   时长与换手装备动画（≈0.28s）同家族，快而不拖。

## 3. HUD 装备条第五槽【设计定稿】

### 3.1 槽序：尾部追加（右端）
- `EQUIP_SLOTS` 尾部追加 `glider` → HUD 条上第五槽自然落位**四槽右端**。
- 理由：①数组序即 UI 序，尾部追加零特判零漂移；②盔甲四联（头→胸→腿→靴的身体序）
  保持连续，孩子已建立的「盔甲四件套」群组阅读不破坏；③「专属槽=盔甲之外的
  附加装备」，收尾一位比插队最前更贴语义。

### 3.2 空槽/装备态呈现
- **空槽**：虚线边框虚位（与四槽 `.off` 同款），无图标。
- **装备态**：`iconOf('glider')` 像素图标（§5 的展开双翼图），与四槽同规格渲染。
- **装备后常驻显示**（不只滑翔时才显示）：滑翔翼是无消耗永久装备（ADR 0012），
  HUD 应答「我现在戴着什么」；且槽位是脱下意图的点击入口，须常驻可点。
- 点槽=脱下意图 `onUnequip('glider')`，与四槽同管线（回包政策归模式层惯例不变）。
- **【UI 建议】滑翔中抑制第五槽脱下意图**：滑翔进行中该槽点击无效（不报意图、
  不弹话术——安静口径）；「随时可卸」（A6/R1-06）的全语义由**装备页面板口**
  承担（开面板即暂停态，无滑翔中误触面）。理由：HUD 槽是一击即发的快捷口，
  滑翔中误触=立即转入无翼坠落，对 6 岁过于惩罚（「高→摔」因果教学交给
  主动取消=再点跳跃的明确操作，不交给误触）。**此条为儿童安全调整，PO 可覆盖**；
  若 PO 维持「HUD 槽滑翔中也可卸」，则 A6 语义原样生效，无 UI 阻碍。
  **→ PO 已确认采纳（2026-11-15，记录见 glider-spec.md §8②）：滑翔中锁槽防误脱、
  落地解锁；本条由【UI 建议】升格为已确认口径，实现照此施工。**

### 3.3 滑翔中状态指示（推荐方案+取舍）
- **方案（定稿推荐）：槽位激活描边**——滑翔进行中，第五槽边框由常态白 22%
  切换为**金描边**（`#e9b115`，与图标金骨同源），带柔和呼吸：描边不透明度
  1.0↔0.55 循环，周期约 1.6s，ease-in-out；落地收翼即回常态。收翼/展翼状态沿
  触发 class 切换，**无逐帧重画**（不进 mkArmorBar 的 id 签名；滑翔态是独立
  状态位，实现形式归【实现自由度】，验收=描边与滑翔状态严格一致、零闪烁抖动）。
- **取舍标注**：
  - 否决「独立翼形徽章浮标」：新增屏幕常驻件、与装备条信息重复，违背原则 4
    （屏幕留给风景）。
  - 退化预案兜底价值：R2-07 第一人称退化下，孩子看不到自己的翼，金边呼吸槽
    是唯一可见滑翔状态信号。
  - 6 岁口径：呼吸动画限一个 58px 小槽，不动准星、不闪屏、无声音伴随——灵动不惊悚。
- 触屏适配：装备条在屏幕左上角（§3.4 定位），不在摇杆/跳跃键/顶部小键任何
  触控热区内；滑翔中该槽又已抑制点击（§3.2）——双保险。

### 3.4 装备条样式补齐建议【UI 建议，附带队列】
- **现状**：`.armorbar` 零 CSS，四槽裸默认按钮，静态流落屏左上 (0,0)，与 `#hud`
  调试文字区（top:10 left:12）重叠——存量 wart（装备 T5 直上无样式）。
- **建议最小样式**（观感对齐既有 HUD 家族，非新设计语言）：
  - 条容器：`position: fixed; top: 44px; left: 12px; display: flex; gap: 6px;
    padding: 6px;` 黑底 `rgb(0 0 0 / 35%)` 圆角 8（#hotbar 同族，css/style.css:61-72）；
    z-index 10（与 #hud 同层，低于 hotbar 16）。
  - 槽格：**54×54px**（hotbar `.slot` 同尺寸家族），内图标 img 40×40 居中
    pixelated；空槽虚线边框（装备页 `.off` 语言）；圆角 6。
  - 定位依据：左上角让开 #hud 文字行（top 44 > #hud 行高），且不在触控热区
    （摇杆左下、跳跃右下、顶部小键上缘），桌面/触屏双端都不抢操作面。
- **范围标注**：此补齐会同时改到既有四槽的观感（从裸按钮升到槽语言）——
  是「与四槽风格一致」命题的另一半。可随本票顺带做（改动小、纯 CSS+kit 类名），
  也可拆独立小票；**归派令方裁**。若不纳入本票，则 §3.1–3.3 的槽序/呈现/指示
  语义不受影响，第五槽沿用四槽现状裸样式仍成立。

### 3.5 验收走查项（HUD 条）

## 4. 背包装备页第五槽 + 纸娃娃翼【设计定稿】

### 4.1 槽格布局：四槽正下方居中独立行
- 现状：`mkp-eslots` 2 列 grid（58px 槽 + gap 10），四盔甲槽 2×2。
- **第五槽落位**：仍在本 grid 内、第三行，`grid-column: span 2` + `justify-self:
  center`——**58×58 槽格尺寸不变**（边框/虚位/耐久条样式与四槽完全一致），
  水平居中独立于盔甲 2×2 之下。
- 布局语义：「盔甲一组（2×2）+ 滑翔翼专属一位（居中独立）」——与 ADR 0013
  「专属槽与盔甲互不排斥但语义独立」同构；孩子读作「下面这格是另一种装备」。
- 否决备选：①直接进循环（2-2-1 折行，末行左格悬空=读作「缺一个」）；
  ②跨两列宽槽（126px 槽装 64px 图标显空）。
- 装备页高度：equiprow 高度由 176px（dollbox）变为 ≈176px（dollbox 仍是最高件：
  槽区 58×3+gap×2=194px 略高——**【实现自由度】**若超出面板舒适高度，可把槽格
  降到 54px 或减 gap；验收=五槽完整可见+面板无滚动条）。

### 4.2 纸娃娃翼显隐口径（v1.2：覆盖 R1-13）
- **【2026-11-16 PO 实机试玩拍板】翼只在滑翔时可见、完全隐藏，第三人称与纸娃娃
  统一口径**——纸娃娃**任何状态都不显示翼**：`paint(worn)` 不再消费 `worn.glider`
  操纵翼骨（v1.1 的「装备即展翼」条款作废），装备与非装备在纸娃娃上逐像素一致。
- 拍板演进记录：R1-13（2026-11-15，纸娃娃显示展开的翼）→ PO 试玩后改判
  「一直在身上背着」不符合预期（原话见 notes.md §6），知情有效，以 2026-11-16
  为准。
- 装备信息补偿：纸娃娃不显翼后，「已装备滑翔翼」的可见信号=第五槽图标
  （HUD 条常驻+装备页槽位）+ ItemHint 话术——信息不丢，只是不挂在人物身上。
- 备选「纸娃娃仍画收拢翼鞘」否决理由：与 PO「不背着」诉求直接相抵；
  「点状暗示」否决理由：48px 娃娃上加暗示点=噪声不是信息。

### 4.3 构图（v1.2：相机微调作废）
- **【A1/拍板演进连带处置】** v1.1 的「装备时相机后移 3.55→4.3 保展翼入框」
  **作废**——纸娃娃不再展翼（§4.2 v1.2），无翼尖入框需求；纸娃娃相机恒维持
  出厂构图（FOV 38，cam z=3.55，lookAt (0,0.9,0)），人物更大更亲切。

### 4.4 交互与数据边界
- 点第五槽=`onSlot('glider')` 一律报意图（空槽也报，现纪律不变），话术归模式层。
- **盔甲点行不计滑翔翼**：armorPoints 只算四盔甲槽；滑翔翼无耐久无盔甲点贡献
  （ADR 0012 无消耗）——防实现误把第五槽纳入 pts 求和或画耐久条
  （第五槽永不渲染 `.dur`）。
- paint 幂等签名自动扩五槽（EQUIP_SLOTS 序，机械改）。

### 4.5 验收走查项（装备页）

## 5. 物品像素图标【设计定稿，可直接进 ITEM_PIX】

### 5.1 意象与色板（PO 工单 7cd34ace 拍板）

## 6. 第三人称背部翼观感【设计定稿】

### 6.1 挂接方案：造型档案玩家档加翼骨（推荐）—— ArmorOverlay 扩翼（不推荐）
- **推荐：甲案**——js/mob-look/player.js 增加 `wingL`/`wingR` 两骨（语义翼槽，
  axis:'z'，与 dragon/phantom/vex/chicken 四怪同款）。理由：
  1. **先例正典**：翼=L/R 语义骨槽是仓库既有翼语汇（4 怪在用）；翼几何官方手法
     =骨杆+膜平面盒（dragon：骨杆+膜 56×0×56 平面盒+翼尖）；MobLook paint
     区域画笔（噪底/辐条）观感上限高——正是「蓝天下一对好看的翼」需要的管线。
  2. **双端免费**：`puppet('player')` 全仓仅 Avatar 与纸娃娃两个消费者——
     档案加骨=第三人称与纸娃娃双端共享同一份翼几何（零双份；R1-13 时代的
     「双端展翼」自 v1.2 收敛为滑翔态专用，纸娃娃不展翼，见 §4.2/§6.4）。
  3. **动画语义干净**：玩家不走 mobs.js 通用扇翅路径（:365-370 只作用怪物渲染批）
     ——翼动效由形象层自驱（§6.5），不会意外拍翅。
  4. **回归风险可控**：玩家皮肤画笔全走区域引用（R.head.front 等），新增翼区
     不触碰既有区域；双翼**镜像共一 UV 区**（dragon wingR 共区先例），经典 64×64
     布局的留白带（右上帽层区等）可容纳（【实现自由度】布局落位；mob-look.test
     布局合法性断言=不出界+无重叠，现成守门）。若布局放不下升 128 档（五档先例），
     设计验收不绑档位。
- **不推荐：乙案（ArmorOverlay 扩翼）**——overlay 是「四槽盔甲骨挂几何唯一权威」，
  翼非盔甲属词汇拉伸；其程序贴图画笔为盒六面设计，膜面辐条观感上限低；
  动画 posing 还得给 apply 之外另开翼组出口——接口新增量与甲案持平而观感更差。

### 6.4 显隐状态机（v1.2：完全隐藏口径，防漏管纪律）

**【2026-11-16 PO 实机试玩拍板】翼只在滑翔时可见：装备未滑翔=完全看不见翼，
滑翔时出现，落地消失；第三人称与纸娃娃统一此口径。**

| 状态 | 触发 | 翼表现 |
|---|---|---|
| hidden（缺省+装备未滑翔） | worn 无 glider **或** 有 glider 但未滑翔（含切模式/读档/死亡重生对账） | 翼骨 visible=false，人物与现状逐像素一致 |
| spreading（滑翔开始，0.25s） | 滑翔状态沿升起（离地>2 格自动展翼，含跃崖走落） | visible=true，姿态=收拢→水平匀速展开（§6.5），到位入 spread |
| spread（滑翔中） | 滑翔持续 | 展平+滑翔微动（§6.5） |
| folding（滑翔结束，0.25s） | 落地自动收翼/入水软着陆/滑翔中卸翼/主动取消 | 水平→收拢匀速收拢，**收拢到位瞬间 visible=false**（无残影帧） |

- **folded 不是状态**：收拢仅是 spreading/folding 两过渡的起止姿态（§6.2
  过渡姿态烘焙），「装备未滑翔=收拢翼鞘常驻」的 folded 静止态随 v1.2 删除。
- **驱动与对账**：翼可见性唯一驱动=模式层滑翔状态沿（意图接口建议形
  `Avatar.setWings('hidden'|'spread')`——目标态声明，0.25s 过渡插值是形象层
  内部动作，参照 `Avatar.flash` 意图先例；滑翔是玩法状态，形象层零玩法知识，
  状态判断归探险模式层）。**装备态不再操纵翼**：Avatar.setArmor 不消费
  worn.glider（v1.1 的装备态对账 hidden↔folded 路径作废）。**对账兜底**：
  进场/读档/死亡重生/切模式时翼强制 hidden（滑翔态不可能跨切模式存活，
  无条件 hidden 安全），残影修复同款纪律。
- 切模式清场：switchMode 复位 Avatar 手持物已有先例——翼 hidden 同拍复位
  （建造/竞技场/坦克无滑翔语义→恒 hidden）。
- **验收红线（v1.2 扩写）**：任意模式、任意读档顺序、任意装备状态下，**非滑翔
  时刻的人物身上永不出现翼**（含装备未滑翔、跳跃上升段、落地之后、死亡重生、
  其他模式）。装备与滑翔两信号各自独立分流：装备→HUD/装备页槽位图标，
  滑翔→翼+HUD 金边（§3.3）。

### 6.5 动效规格（匀速口径，SpinnerCore 简洁哲学）
> **【v1.2 注记】** v1.1 的外张预角（每侧翼绕 y ≈±18°）**撤销**（GP03 返工令
> 撤销）：收拢姿态仅存在于 0.25s 过渡首末帧，静止不可见，预角无观感收益。
> **【A1 2026-11-15 结论沿用】** 展/收动效仍绕肩枢轴单轴（axis:'z'）匀速，
> 契约不变。**【衔接语义 v1.2】** 过渡由 setWings 目标态切换触发自动播放：
> 出现=翼以收拢姿态可见的瞬间起 0.25s 展开至水平（「跳下去→翅膀砰地张开」
> 的爽点保留）；消失=水平收拢 0.25s，收拢到位瞬间隐藏——收拢动画播完前翼
> 保持可见，不做淡出/缩放。

- **展开**：收拢→水平展平，绕肩枢轴单轴旋转，**时长 0.25s、线性匀速、无回弹
  无过冲**（与换手装备动画 ≈0.28s 同拍长家族，js/held-item.js:37 HELD_EQUIP_HALF
  =0.14×2）；起止边界即停。触发=滑翔开始（离地>2 格自动展翼，含跃崖走落）。
- **收起**：反向同参数 0.25s 匀速。触发=落地自动收翼 / 水面软着陆 / 装备页卸下 /

- **滑翔微动**：展平后绕展轴 ±2.5°~3° 正弦缓摆，周期 ≈1.4s，**双翼反相**

- **【UI 建议·可选增强】转向侧倾**：左右转向时双翼随转向侧内侧倾 ≤4°

- 第三人称相机（R1-15 实现侧）：UI 侧要求=滑翔中相机距离须使**双翼完整可见**

## 7. 音效建议【UI 建议，咨询性】

### 7.1 新键两枚（SFX_KINDS 各一行，清单注册表惯例）
- **`wing_open`（展开）**：布面抖开的「扑 Jin」上行短音。合成口径：正弦/方波上滑
  f0 220→f1 520、fT≈0.18、dur≈0.22、g≈0.10，可混带通白噪 ~800Hz dur 0.15
  增布抖质感（splash 带通白噪手法同源）；**合成即可，不强制找样本**（清单
  「永不哑」互锁，无样本也能出声）。`prio: 2`（状态音，可压环境声）、
  `coolMs: 300`（R2-04 空中可连点再展，防快速连开叠爆）。
- **`wing_close`（收起）**：反向下滑 520→200、dur≈0.18、更轻 g≈0.07——
  收=安顿感，比展开安静。
- 声音性格：轻快、软、圆——**零金属撞击、零呼啸风噪、零低频轰鸣**（6 岁零惊吓，
  chip_pop 家族口径）。
- 守门：sfx('wing_open'/'wing_close') 字面量经 audio-registry.test.js 扫描自动罩住，
  漏登记即红。

  口径）；且「滑翔安静，风景与 BGM 说话」更贴验收锚。若未来做，走 amb_ 一次性
  微风声键，不引循环系统。
- **TTS 零条目**（R1-09/A9）：着地安抚、高处预警、滑翔播报一律不配。
