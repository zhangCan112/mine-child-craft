### 2.2 落点与朝向

- **落点**：墙身平面 z129（缓冲带 z128..131 中线偏北），footprint x76..80（跨主路全宽）——门楼在触发线 z132 **内侧 3 格**：穿门（z129）→**跨线桥面南行（z130..135，G3 补丁后桥延至触发线外 4 格）**→白闪（z132，脚踏实地触发）——预告（z126）→见门→穿门→白闪四拍时序成立（穿门后 0.5~1 秒白光起，v2 同构已走查）。
- **基座桥**（门楼自带，兼回程桥面）：x76..80 × z128..**133** × y20..24 fill——桥面 y24 顶与 core 草地 y24 同高无缝衔接，桥体剖面实心（防侧面看「1 格薄板悬空」穿帮）；材质 13 石砖（石板桥=「进镇/回家的正式路面」，与 G1 石面同语言）。
  **G3 桥延伸补丁（2026-11-16 PO 走查修正，尾批施工；同日物理复验后深化为 4 格纵深案）**：原案桥只铺 z128..131，触发线 z132 格无实底——玩家中心过线触发白闪同帧失支撑坠落（白闪 0.4s 推进窗内掉 ~2-3 格），PO 体感「像掉下去一样的传送」。补丁=桥延伸 **z132..135 × x76..80 × y20..24**（同构 fill 材质 13），白闪全程脚踏实地——与 home 东带同构（东带触发线 x157 在实底地面，「穿门走过开间被光接走」）。
  **纵深裁量为四格（物理复验修正，裁决档 design-lead）**：初案两格（z132..133）的推演前提「疾跑 0.4s 可行 ~2.2 格」被 engmgr 物理复验修正——实测疾跑 3.4 格（+55%），两格纵深下疾跑者满格传送前冲出 z133 末端残余坠 0.33 格（物证档 .scratch/town-east-boundary/g3-fall-physics-verification.md，trunk 3d49101）。四格案 z132..135 反事实模拟实证**疾跑零残余**。裁量理由：①疾跑是主场景非边缘——用户为 6 岁孩子，「走过门楼回家」的兴奋时刻狂奔是预期行为（MISSION 画像）；②PO 抱怨本体=坠落感而非坠落伤害，残余 0.33 格=同款体验缩量保留，四格案全动作（步行/疾跑）零残余=诉求 100% 兑现；③白闪全屏遮蔽「接近无感」系成人视角推定，不据此裁；④桥观感「堤道伸向光来的方向」八格不劣于六格，触发点/白闪位置两案相同（仪式四拍不变）。端头 z135 齐头收不加端帽（白闪中零可见性）。延伸段语义=「回程路地面」延伸（:122 定稿语义「不设玩法内容≠可以没有安全地面」同引用），判据零触碰。
- **朝向裁定：门额牌面朝北**（面向镇内/回程来向）：
  1. 回程玩家自北南下 approaching，先见门额（镇徽=「这就是回家的门」）再穿门再白闪——牌面必须面向来向；
  2. 镇内南望（广场/主路上回望南天际）=门楼正面+牌面入镜——「镇的正南门」立面归镇内景观（进镇者落 spawn 面北不经过门楼，门楼正面观众=镇内的人与回程者，两者都在北侧）；
  3. **双门呼应构图**：home 东带门楼牌面朝西（迎西行的去镇者）、镇门楼牌面朝北（迎南行的回家者）——两张同款镇徽各自面向行者，白光在两门之间接力：「一扇门在家的边界，一扇门在镇的边界，白光在两门之间」。
- 门楼背面（z130 侧/南侧）=石砖素面+壁灯透两面光（灯块实心嵌柱两面可见）——门外过渡带无可观景，背面素面成立。

## 3. ③节 · 镇缘防坠墙圈

### 3.1 边缘现状事实链（实读钉死——③的必要性论证）

1. `loadScene = clearWorld() → buildFn()`（`js/world.js:576-582`）——**每个维度建场在清零的世界格上跑**；
2. town 建场唯一写入=townAssemblyOps(townBuildSteps())（`js/adventure-dims-core.js:668-686`）；
3. 基底三层（石 0..20 / 泥 21..23 / 草 24）**只铺 core 域** x32..127 × z32..127（`js/town-assembly-core.js:142-149`）；
4. backdrop 山体只占北远景带（mountain-arch z8..28 × x16..143 满填至 y0 + 裙板 z29..31）——**裙板比 core 北缘多出东西两翼（x16..31 / x128..143）**：翼面顶 y25 块（可行走=rim 高台），而翼的南缘（z32 行）与东西外端之外皆是虚空——rim 是「三面临空的悬空高台」，只圈 core 不护翼=防坠漏口（翼墙/端头墩的必要性所在）；
5. **结论**：镇维度 core 外全域无实底=虚空——南过渡带 z128..159、东西两侧 x0..31/x128..159（core 南段外）、山体东西端外与山后 z0..7。**回程缓冲带 z128..131 与触发线 z132 正处于虚空段**——玩家南行越过 core 南界即临坠落，PO 的③诉求（「防坠落」）与此事实吻合；town-map-design §6.3.5「镇外过渡带无内容物」的定稿语义=过渡带不设玩法内容，**不等于可以没有安全地面**。
6. 顺带结论（②的桥面理由）：防坠墙圈若只圈 core 界而不给回程开口铺桥，回程判据（z≥132，无 x 依赖）将**物理不可达**——回程必经段必须补实底，由②门楼基座桥承担（§2.2）。

### 3.2 方案分级（利弊给全）

### 3.4 行为面红利（不改判据的顺带收益）

- **回程误触面收窄**：现状 z≥132 无 x 依赖=南缘全带宽都是理论触发面；墙圈（2 格跳不过）+唯一开口（门楼桥）把可达过线点收窄为门楼一处——孩子在墙圈内的任何位置都不可能意外触发回程，回程只发生在「穿门」之后（仪式完整性）。
- **远景层内零连累**：北 core 界不开墙（裙板缓坡=PO 亲需可达线），攀登走廊/山顶游览不受影响——墙圈只拦「出镇坠虚空」，不拦「登北山游览」。
- **登北山走廊本身也封口**：rim 高台收成 z29..30 两行安全走道（南缘翼墙+东西外端墩），「登顶游览」动线零改动——所有既可达的去处都仍然可达，只是不再有可达的坠落口。
