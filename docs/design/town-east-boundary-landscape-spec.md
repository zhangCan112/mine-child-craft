## 0. 一页速览

- **语义翻转**：旧「小镇建造中」观感收尾 → 「随时可去的家门外大门」。旧件的任务从「解释为什么过不去」变成「把人送过去」。
- **设计叙事**：**「路 → 门 → 镇」三拍**——路（走：x128~156 ①②③维持）→ 门（穿：亮灯门坊+开间+门墩）→ 镇（到：门后剪影+钟塔同轴）。白闪在「穿门」一拍发生：雾最浓处、双灯之间、门额图案之下，大地让开。
- **改动物理面只有两件**（都在到达段 x152~159，PO 已授权重排）：
  1. **件 A 镇门牌坊**（原告示牌 x156 重建）：双柱加高 3→4、门楣一线、悬牌 2×2 拼块图案（上=石=钟塔 / 下=原木=小径）、柱顶双火把门灯；
  2. **件 D 门前小径**（新增 2×2 土面 x158~159 × z74/75）：路穿过开间一直铺到钟楼塔脚。
  其余全部**维持 + 读法升级**（开间/门墩/剪影/主径/①②段/天雾/四角楔）。
- **零突破声明**：图集零新贴图（只用块 id 2/3/5/6/48）；机制判据零改动；话术零改动（代码已收口）；确定性红线不破（新增件全为建场常量，零新盐）。

## 1. 设计叙事与读法翻转总纲

### 1.1 基调承接

缝变更线基调（ui-seam-notes）：**「扒着栅栏缝看的小镇，在白光里让开一条路。」** 路让开后，孩子站在路上——东带的风景任务就是把这条路画完：路的尽头有一扇开着的、亮着灯的门，门后就是他扒缝看了很久的小镇。

### 1.2 三拍构成

| 拍 | 格位 | 风景件 | 孩子的动词与读法 |
|---|---|---|---|
| ① 路 | x128~156 | 草原→土斑→花田→主径（①②③段维持） | **走**：「沿着路一直走就到」 |
| ② 门 | x156~157 | 亮灯门坊（x156）+ 开间（x157 z74/75）+ 门墩（x154） | **穿**：「门开着、灯亮着」——穿过门额图案牌，白闪在开间处发生 |
| ③ 镇 | 门后视线 x158~159 | 石色剪影（房×4+钟楼 z74 同轴+灯 4 粒）+ 门前小径 | **到**：「门后就是镇」——白闪退场即身在镇中（A.7「剪影显影成真钟塔」闭环） |

### 1.3 旧→新读法对照表

| 边界件 | 旧读法（2026-11-06 建造中收尾，east-spec 原版） | 新读法（2026-11-15 已开放，本定稿） |
|---|---|---|
| 栅栏 x157 | 「看得见、过不去、但不堵心」（缝=偷看窗） | **镇的院墙**；开间=敞开的院门（「看得见、马上就能过去」——B.3 锁定读法） |
| 告示牌 x156 | 「小镇建造中」解释牌（板面拼块形制无字=登记偏差） | **亮灯的门坊**：门额图案牌=「门后是钟塔和小径」的预告（偏差顺势转正为图案正案——B.3 锁定方向，本文落块级拼法 §3.1） |
| 剪影 x158~159 | 雾中不可达远景（「近看不穿帮」约束移交 T7） | **镇前院的真房子**（灯点=「小镇亮着灯等你来」——B.3 锁定；翻越=「翻墙进院」彩蛋维持） |
| ①②段土斑/花田 | 「路好像有了 / 有人耕作（村落暗示）」 | 维持，读法微调=「去镇上的路本身 / 镇郊农家的花」 |
| 天/雾 east 三锚 | 栅栏前雾起（走查校准档） | 数值维持；读法=「门前晨雾」+ 白闪在雾最浓处发生=「走进光里」（§4） |
| 话术 | 「小镇还在建造中！…」主话术 + 旧拒绝话术 | 代码已收口三句（附录 B）；旧两句随缝退役（east-spec §7 注记） |

### 1.4 焦虑面自查（禁焦虑清单 A.6 沿用）

门坊**无门扇、无闸、无锁**——「门开着」就是零压迫的形态表达；门灯是暖光（火把同款）不是警示；全带无否定语义件、无「封条」读法；白闪过场维持 A.2/A.6 全套（暖白、0.8s、零弹窗零确认）。

## 3. 到达段逐件规格（块级，可施工粒度）

建场总装序维持：`advEdgeEast = Dress → ArrivePad → Sign → Fence → Skyline`（`js/adventure-core.js:1543-1549`）。件 D 建议挂 Skyline 头部（§3.4）。

### 3.1 件 A · 镇门牌坊（原告示牌，x156）——主案

**形制总览**：两柱一楣一双灯 + 悬牌图案，总高 yb+6（地面以上 7 格）——高于栅栏（2 格）、低于钟楼剪影（9 格，塔=镇地标最高原则不破）。牌下净空 z74/75 y+1..+2 恒空气（与现制一致的穿行契约）。

**块级拼法**（改稿后 `advEdgeEastSign` 全量）：

| 部位 | 坐标（x, y, z） | 块 id | 色彩 / 语义 |
|---|---|---|---|
| 双柱 | (156, yb+1..yb+4, 73) 与 (156, yb+1..yb+4, 76) | 5 原木 | #8B5A2B——4 高（原 3 高 +1），与门框桩同料 |
| 门楣 | (156, yb+5, 73..76) 一线 4 格 | 6 木板 | #9C6B35——横贯门宽连双柱顶 |
| 悬牌·塔行 | (156, yb+4, 74) 与 (156, yb+4, 75) | **3 石** | 石色——**钟塔图案**：与隔离带钟楼剪影**同块 id 同色**（id3=剪影石色替代料）＝「牌上画的=门后看到的」材质互文 |
| 悬牌·径行 | (156, yb+3, 74) 与 (156, yb+3, 75) | **5 原木** | #8B5A2B——**小径图案**：横木线=路的牌面记号，与脚下主径同轴同向 |
| 柱顶门灯 | (156, yb+6, 73) 与 (156, yb+6, 76) | 48 火把 | 暖光——门灯笼×2，落在门楣两角正上（支撑成立）；夜间发光，与钟楼顶灯互文=「门上的灯=塔上的灯」 |
| 牌下净空 | (156, yb+1..yb+2, 74) 与 (156, yb+1..yb+2, 75) | 空气（**禁填**） | 玩家穿行净空契约 |

**形制与读法**：

- **门坊=「门开着」的形态表达**：无门扇无闸，净空穿行——穿过门额下的图案牌=穿进画里（到达仪式，Metroid Prime 门=仪式先例语言同源）；
- **图案=「钟塔+小径向东」**（B.3 锁定方向的落块实现）：上行石=塔（视觉重心在上，与真塔同料）、下行原木=径（横线在下，与脚下同轴）。2 格宽画布由门口开间形制锁定（柱距=开间宽），图案在此画布下取**竖排双行**最简读法；
- **画框构图**：双柱框出 z74/75 视窗 → 正对开间 → 正对钟楼剪影 z74 **同轴**——「一眼看穿门到塔」（research §1.3 轴线对齐事实的到达段兑现）；
- **6 岁可读性三重奏**：图案不独立达意（2×2 抽象），达意靠 门形态（可穿）+ 双灯（迎宾）+ 门后实景（塔影）——零文字依赖满足（MISSION），图案是近距离彩蛋；
- **视线核对**：过场/去程视角（x150 眼高 yb+1.62 望 x158 塔尖 yb+8）穿 x156 处高度 ≈ yb+6.4——门楣（yb+5）之上、门灯（yb+6，z73/76 不在 z74/75 视线带）之间的空气窗，塔尖可见；平视穿 yb+1..+2 净空见门前小径与塔基——**上见塔尖、下见塔脚、中间是门**；
- **命名沿革**：函数名 `advEdgeEastSign` 沿用不更名（先例=ADV_GATE_PLAZA「沿革留档不更名」），注释改「镇门牌坊（原告示牌）」。
- **辅案文字案留档**（B.3 辅案，默认不做）：板面文字「**小镇在这边！**」（5 字形制对齐旧牌「小镇建造中」）——零文字依赖（MISSION）+ 需字模图集格位（图集突破），走查若翻案归 E4 独立图集票，不入主票。

### 3.2 件 B · 门口开间（x157，z74/75）——机制判据，维持

- 开间两格净空无杆无桩（`ADV_TOWN_GATE_OPEN_Z` continue，`:1500`）、侧邻门框桩 z73/76（各一根两高原木）、其余段原木桩每 3 格两高 + 缝格木板横杆 1 高——**全部维持**（机制判据不可动；四处同源消费：越线触发/回程门墩/东栅栏让位/开间保护）；

## 9. 备选案与放弃理由（防复议重开）

| 备选 | 放弃理由 |
|---|---|
| 牌移路侧「路牌式」（x156/z72 立地双柱牌） | 门额悬路=「穿进画里」的到达仪式，路侧牌只是信息件；且保护判据/测试坐标全钉 x156 z73~76，迁移工程面更大收益更低 |
| 板面维持 2×2 全木板、只加柱顶灯 | 零图案=旧「拼块形制无字」偏差原样，「没写完的牌子」正是 PO 要重做的建造中残留 |

| 板面加宽到 z73..76 四格大板 | 侵入柱位（柱 z73/76 已占），要么断柱要么移柱——门口开间「门框读法」形制被破坏；2 格画布+竖排双行已够近读 |
| 欢迎花境入主票 | 需动「花田恰 10 丛」钉死断言；主票保持测试面最小，降为登记项 E3 |

| 隔离带剪影重排（换位/加房/换深蓝灰） | 剪影保留是 B.3/A.7 锁定决策；构成语义（高低错落+钟楼最高+灯 4 粒）在新读法下全部成立；换色归 E4 既有拍板口径 |
| 门前小径铺满隔离带全带宽 | 破坏「院墙外是草地」的前院读法，且搅动四角楔边界语义；2 格宽=「路的延续」最小语义单元 |
| ①②段加中段路标/望塔指向件 | ①②走查通过维持；B.2 已有登记项 E5，不重复立项 |
