### P2 · 保护清单判据 + 挖掘/放置守卫 【纯工程】（判据选型 T7 内定） 规模 M

- **范围**：T6 v2 唯一保护清单落地——三向未解锁屏障件 + 东向栅栏/告示牌/栈桩不可挖、不可替换（像基岩）。
- **判据选型（票面授权 T7 定）**：**推荐「坐标+件纯函数」**，备选「旗标（受保护格 Set/格子旗标位）」。理由：
  1. 单一权威——判据直接复用各向屏障建场权威函数（北 `advEdgeNorthMountainH(x,z)>0`、南沙丘 `advEdgeSouthCrest` 剖面带 z144..147、西深水带矩形 x13..18、东栅栏 x157/告示牌 x156 栈桩坐标清单），建场与守卫同源，不会漂移；
  2. 零常驻状态——旗标方案需要模块级 Set（数千格条目）并处理清场/重建同步，多一个失步面，还踩「零新常驻大对象」红线；纯函数零状态零内存；
  3. 可单测——vm 直测纯函数逐坐标断言；旗标 Set 的断言要先跑建场再查表，脆。
  - 误伤面登记：老档玩家在屏障列上的旧 edits 件与建场件同 id 时挖不动（罕见边缘，话术「冻住啦挖不动」语义可自洽，接受）。
- **判据函数**（AC 新增政策段，建议挂边界带段之后）：
  - `advEdgeProtectedAt(x, y, z) → bool`（不可挖）：北=山体列 y≥ADV_GROUND 段；南=脊线四段剖面体（z144..147 且 y≥地形面）；西=x13..18 水体格/泥岸格/苔石坐标；东=x157 栅栏桩/杆与栈桩格、x156 告示牌柱/板格。
- **挖掘链挂点（复用「挖不动就是真挖不动」既有拒绝链，不造第二份拒绝机制——T6 v2 前提+north-spec §7）**：
  - PK `mineTick` 起手守卫：现走 `def.hard == null → o.hardText(id)` 缝（L306-317）。**扩展 hardText 签名为 `(id, x, y, z)`**（PK 调用处一行；老注入多收参数向后兼容），ADV 的 `advMineHardText` 增加 `advEdgeProtectedAt` 分支返回屏障拒绝占位文案（spec §6 建议文案，如北「这堆雪冻得硬邦邦的，挖不动——先去把任务做完，它自己会让开的！」；终稿归 T8）——拒绝语义自动继承：不起蓄力、方块原地不动、3s 节流话术。
  - **TNT 链豁免**：实施时核对 advTntRoll→advExplodeCells 爆炸格结算路径，对 `advEdgeProtectedAt` 命中格跳过破坏（防 TNT 掀屏障绕过守卫）；补一条「TNT 轰屏障件原地不动」断言。
  - **放置替换守卫**：tryPlace 的 replaceable 覆盖路径（花草/火把被盖）也要拦——PK tryPlace 在 editBlock 前判 `advEdgeProtectedAt`（经新注入缝或 hardText 同族缝），拒绝+话术不扣物品。
- **与原型差异**：原型无任何守卫（advEdgeEastFence 注释「本原型不拦」）；本项为纯新增政策层。
- **红线**：判据纯函数零状态、零 THREE/DOM；建场序零改动。
- **验收（可测断言口径）**：vm 装载同测试惯例——北山体列某格（用 advEdgeNorthMountainH 找正面格）、南沙脊格、西深水带水体格、东栅栏桩格/告示牌板格、栈桩格各断言 `advEdgeProtectedAt===true`；带内普通雪/沙/泥/草格、东隔离带 x158 格断言 `===false`（x158 隔离带剪影件可挖性=可挖，登记）；`advMineHardText(带屏障格 id, x, y, z)` 返非空文案、普通格返空串；TNT 链断言见上。
- **依赖**：无外部依赖；与 P3 共享判据函数族（同段实现）。

### P3 · 翻越拦截：屏障足迹列禁放柱 【纯工程】（T6 v2 已授权口径，走查验收） 规模 S~M

## 3. 性能方案（用户硬要求）

### 3.1 建场基线实测与量化阈值

**口径**：临时 Node 脚本（`C:\Users\user\AppData\Local\Temp\opencode\t7-perf-baseline.js`，**未进仓库**），vm 装载真引擎件+adventure-core（test 同款惯例），hrtime 计时，预热 2 次后各 11 次取中位；「禁带对照」=vm context 内把 `advBuildEdgeBands` 绑定覆盖为空函数再跑 advBuildWorld（函数声明绑定可写，实测可行）。

| 指标 | 实测（2026-11-06，Node/Win） |
| --- | --- |
| advBuildWorld 全量（含带+四角） | **median 655.2ms**（min 650.9，11 样本极差 ≈10ms） |
| advBuildWorld 禁带对照 | **median 362.6ms**（min 360.8） |

| 确定性 | 两次全量建场逐字节一致 = true ✓ |

结论：带建场已占建场近半——这是**走查通过原型里已存在的成本**，不是转正新增；转正观感层零改动 ⇒ 建场成本零新增。

**3.1.3 量化验收阈值建议（写进 P6 钉测断言）**

- 主口径（倍率，抗机器抖动）：`(全量中位 − 禁带中位) / 禁带中位 ≤ 0.93`（基线 0.807 × 1.15 余量——实施噪音/判据纯函数增量各留口）。
- 防呆口径（绝对值）：全量中位 ≤ 1500ms（防真实回归——回归通常翻倍，此线不会误报正常波动）。
- 机器口径登记：Node 22/Windows/2026-11-06 基线；CI 或换机跑出超阈值时先复核基线再判回归。

### 3.2 每帧路径审计（红线②）

1. **早退链**：`advDim!=='overworld' || advMap!=='home'` 两条比较先退（下界/副本/他图零成本）；`setSkyBase`/`scene.fog` 存在性守卫（Node/无渲染静默）——均 O(1) 无分配 ✓。
