## 1. 带宽定稿：**32 格**（z 128..159，全 x 宽度）

三条理由：

1. **MC 同构**：32 格 = 8 个 MC 4×4×4 biome cell patch，落在 T1 调研 §5 建议「24~40 格 ≈ 6~10 patch」区间中段。「草掺沙斑（3 patch）→ 混匀核心（2 patch）→ 沙底纯化（3 patch）」三段渐变都摆得开，不挤。
2. **工程友好**：32 = 2×16（chunk 对齐），南带恰好是南缘两个整 chunk，建场函数按 chunk 判带边界最简单，利于确定性红线。
3. **体感**：160 格世界里走完 32 格约数秒，足够天色完成渐变、读出三段叙事，又不至于「走不到头」；带占世界 20%，核心玩法区不受挤占。

## 3. 天/雾渐变锚点

沙漠天端点 `#E6D19E` ≡ 票面 `(0.90, 0.82, 0.62)`（0.90×255≈230=0xE6，0.82×255≈209=0xD1，0.62×255≈158=0x9E）。

| 玩家到南缘距离 d（格） | 天/雾色 | 说明 |
| --- | --- | --- |
| d ≥ 32 | `#8FC7FF` | home 全量，无感知 |
| d = 32（b0） | lerp 起点 | **天色先行**：脚下还是纯草（b4 才见沙斑），天已开始变暖——MC「温度→天色」官方同构（调研 §2.3/§4） |
| d = 16（屏障处） | ≈ `#BACCCE` | 中性暖灰 =「沙暴天」，为屏障做体感铺垫 |
| d = 0（缘） | `#E6D19E` | 沙漠全量 |

- 机制建议（答地图「Not yet specified·渐变机制」）：按 `d/32` **连续线性 lerp RGB**（逐帧，不设档位）——MC 高斯模糊口径的精神是「柔和不硬切」；雾带 = 同色向白 mix 30%。
- home 端 `#8FC7FF`、沙漠端雾色偏暖 `#F2E8CE` 一档（图上雾带已示意）。

## 4. 未解锁屏障：**沙暴墙**（主案）

- **位置与体量**：b16..19（带中点附近，满足拍板 8「过渡带中段」），4 格宽，沿南缘整条 160 格连续横跨。
- **形态**：4 根沙柱并立的旋转沙暴；柱顶翻卷沙檐、柱身斜纹、底部卷浪、顶端飘沙尾。色 `#B89A5E→#E6D19E` 暖沙系半透明。
- **动画**：斜纹缓慢向右上漂移——**借 MC 边界墙条纹动画之「形」，不借其红 vignette/掉血之「罚」**（调研 §1/§4 口径）。无红、无全屏恐吓、无音效惊吓。
- **为什么是沙暴墙（6 岁可读性）**：
  1. 生活经验「风沙迷眼」秒懂「过不去」；
  2. **非方块语言 = 真正不可挖、且一眼读出不可挖**：T6 v2 下带内可挖可建，「周围都能挖能盖、唯独这面风墙不是方块」的对比本身就是最清晰的「过不去」信号；屏障件列入 v2 唯一保护清单（不可挖、不可替换，语义同基岩）——原「不能设计成可以挖开的样子」的要求正好落实为受保护件语义；
  3. 暖色无威胁语义；屏障处天色 `#BACCCE` 与墙同系 =「沙暴天」，天色先行正好提前预警；
  4. 接近行为（给 T8）：距墙 ≤3 格出话术气泡挡回，零伤害。
- **备选案**（若用户不买账）：砂岩陡崖——纯方块语言，但需配「整块光滑崖面」贴图才能避免「可挖」误读，成本更高，故列 fallback。

## 6. 解锁态语义（图底部对比条）

## 走查反馈修订（2026-11-06，实机原型第二轮）

> 用户逐字反馈：「沙漠都是墙的感觉，不好，你起码感觉是沙丘吧。沙丘地形还好，多点小草和低矮的树。（整体要求，四带通用）当前场景的植物到目标场景的植物应该在过渡带有过度。」

### 修订 1：屏障形态 —— 沙暴墙柱阵 → 连绵大沙丘（原型观感层）

- **问题**：z144..147 沙柱 3~4 高 + 每 8 列砂岩柱芯的建场语言，实机读成「一排墙柱」——是方块墙，不是沙。
- **新形态**（已落建场，`advEdgeSouthBarrier`/`advEdgeSouthCrest`）：脊线沿 x 双正弦叠加起伏（相邻列变化 ≤~0.3），脊顶高 **4..10 全幅渐次**；剖面四段 = 迎风坡脚（≥2 高）→ 陡升（级差恒 2）→ 脊顶（C）→ 背风肩（C−2 缓落）；砂岩**只做脊顶零星露头**（实测 12 列，非柱芯节奏）；背风侧接 0..3 高沙海丘原（`advEdgeSouthSwell`）+ 洼地，整体读「一大片沙丘丘原」。
- **屏障语义不变**：迎风坡脚级差 ≥2（跳跃 1.42 格翻不过）+ 陡升段级差恒 2（邻带饰件落在坡前的「垫脚石」最多上到坡脚顶即止步）——T6 v2「不可挖不可替换」保护件语义、z144..147 位置（§4 拍板）都不动；「不可挖不可替换」旗标仍归 T7 落位，沙暴动效（斜纹缓漂）是否还需要/如何与沙丘地形叠加归 T7 评估——**沙丘地形可直接作解锁态「沙暴散去」的地形底**。
- **防翻丘配套**：apron z139..143 裸沙不落南带自件（查表 b13 草残点随之改沙）；树冠搭桥残留按 §8.7 归 T7 拦截口径（中段矮树选位 z≤136，距坡脚 ≥8 列，冠层够不着坡脚）。

### 修订 2：植被过渡 —— 入口密 → 带内渐稀 → 远端零星（消长全程在带内）

- **入口侧 b0..b3（z128..131）**：home 草丛 0.26→0.20→0.15→0.10 逐行渐降（实测入口段 121 丛，含 home 散布自然份额）；花田（ADV_MEADOW）花海 r 圈自然漫到 z137，入口中段的花由花海承担（南带不再另撒花——保住「花只在核心圈/花田/东带」的全图扫描口径）。
- **带内 b4..b10**：沙斑上零星草丛 0.12→0.08→0.05 渐稀（只长沙面，「沙里一撮撮绿」）。
- **低矮耐旱树**：矮干（原木 1~2）+ 扁小冠（3×3 缺角 + 顶心，总高 3~4 = home 树一半），中段 b5..b8 与远端沙海零星共 8 棵；新增建场件 `advEdgeSouthScrub`（既有图集格位 5/7，零新贴图）。
