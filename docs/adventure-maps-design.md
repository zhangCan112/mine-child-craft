## 0. 一句话架构

**多张 128×128 主题地图 = 「种子 + 地形常量表 + 调色板」的数据行（冒险地图注册表）；切换 =
传送门站桩仪式 + 全屏遮罩下走既有 loadScene 装场 seam（同步成本实测 ≈12–25ms）+ 分桶账本
换装；每张地图用「替换语义」配一套专属怪，用「唯一结构 + 专属资源」给孩子去的理由。**

方向拍板（对应 map-transition-research §6）：**方向 A（分地图 + 遮罩过渡）打底，方向 B
（chunk 流式）的最小子集已是仓库现状**（mesh 分块网格化 + Worker + 距离环），不做单世界
无限流式。理由：① 工程上主题差异下沉为数据（Krunker「换 JSON 不换引擎」先例），遮罩是
DOM/CSS/音频层低风险工作；② 体验上「进门仪式 → 到达雪原」比群系渐变更可预期、更有到达感，
对 6 岁孩子是加分项；③ 遮罩必须快（Mass Effect 电梯教训），本项目纯 CPU 生成无网络等待，
实测成本一二帧，2–4 秒仪式绰绰有余。

## 2. 地图体系（冒险地图注册表）

### 2.1 一期地图清单与「五件套」

每张地图 = 注册表一行，五件套齐活才是「一张图」（MC 沙漠模板：沙色地表 + 仙人掌 + 尸壳
替换 + 骆驼 + 沙漠神殿，见 minecraft-biome-research §2.2 注记）：

| 地图 | 调色板四元组（地表/植被/水/天） | 专属怪（替换语义） | 唯一结构 | 专属资源与交互 |
| --- | --- | --- | --- | --- |
| **家园草原 home**（重设计，§2.4） | 草绿/橡树/常规蓝/常规 | 僵尸·骷髅·蜘蛛·苦力怕（巢穴梯度重排） | 出生小屋 + **门阵广场** + 初始农田 + 畜牧围栏 | 同心圈层布局（§2.4）；湖/坑/洞/巢按风险-距离梯度重排 |
| **黄沙沙漠 desert**（新） | 沙 `#86,0.80,0.55`/枯灌木+仙人掌/小绿洲/暖黄天 | **尸壳替换僵尸** + 骷髅·苦力怕（夜） | **沙漠神殿**（金字塔 + 地下宝箱室） | 仙人掌（采集收藏）、砂岩层、神殿宝箱 |
| **白雪雪原 snow**（新） | 雪白/云杉深绿/冰面淡蓝/冷白天 | **流浪者替换骷髅** + 僵尸·苦力怕（夜） | **雪屋**（圆顶小屋 + 地下宝箱） | 雪块（挖）、**雪球投掷**（雪仗，零伤害击退）、冰面 |
| **青苔沼泽 swamp**（新） | 暗绿/垂藤橡树/灰绿水/灰蒙天 | **沼骸替换骷髅** + **女巫小屋常驻** + 史莱姆（夜，水池） | **女巫小屋**（高脚木屋 + 宝箱） | 黏液球主场（史莱姆掉落，items 已注册）、蓝色兰花（唯一产地，装饰收藏） |

- **调色板四元组**是每图美术的约束（MC 引擎用温度×降水采样草/叶/水/天色，沼泽等特判固定
  色——研究 §1.3）：本项目方块是程序化纯色/图集，定义每图一组（地表色、植被色、水色、
  天色基准）+ 昼夜插值仍走 DaylightCore。天穹/雾换装走 nether applySky 同款缝。
- **替换语义**（研究 §2.4）：沙漠图**不刷白僵尸只刷尸壳**、雪原图**不刷白骷髅只刷流浪者**
  ——布尔替换，不做权重混刷。孩子对「这张图的主人公是谁」一目了然。
- 二期候选（本设计只登记，不展开）：丛林（丛林神庙/可可/西瓜/溺尸+守卫者的海岸线）、
  掠夺者前哨站事件（灾厄帮 4 怪的家园）、蘑菇岛式零怪游乐场。

### 2.2 家园的定位

home 是**安全基地与教学关**：小屋/床/大宝箱/熔炉/工作台/门阵都在家；其余三图是「远征」
——无床无熔炉（或仅神殿旁一个熔炉），死了**回家**（§10 拍板②：满血传送回家门口，
强化「家=安全」）。这张「家-远征」结构与 MC 主世界-下界的心跳一致（出发→历险→满载
回家）。

### 2.3 传送门阵与解锁仪式

- home 小屋旁建**门阵**：每图一扇 6×7 黑曜石门（下界门口径，场面压得住），紫门面常亮。
  已解锁的门**常亮**；未解锁的门**门面熄灭 + 锁形提示**（TTS：「做出铁镐，沙漠之门就会亮起来」）。
- 目标图侧常驻**回程门**（nether RETURN_PORTAL 同款：落地就在门跟前，门在身后）。
- **解锁 = 任务链点亮**（MC 末地门「集齐钥匙逐格点亮」的儿童版，研究 §5.2）：完成前置
  任务（如「挖到铁」）→ 门面点亮仪式（光束 + 音效 + TTS 播报）。不做「亲手搭门」（黑曜石
  采集对 6 岁太磨），保留「看着门亮起来」的仪式感。
- 每图探索度可做二期「图鉴页」（本设计不展开）。

### 2.4 家园地图重设计（home 整图重排，2026-10-27 用户两次追加拍板）

原 home 的问题不只是寡淡（y24 一刀切平面 + 40 棵随机散树），更在**布局不合理**：小屋在
(61,81) 而湖在 (22,24)——黏土教学链要孩子横穿 69 格；三巢与两坑零散分布无难度梯度。
重设计以小屋为锚（**小屋与家园核心圈压平在 y24 且坐标不动**——老档的出生点/床边/站立
位零悬空风险），整图按「同心圈层」重排：

```
        北(z=0)  ←—————— 128×128 ——————→  东(x=127)
   ┌─────────────────────────────────────────┐
   │ 深险圈: 山洞口(62,10 附近) 钻石穴室·远巢(苦力怕,20,16) │ z≈10-24
   │        树林带北片 + 丘陵起伏(±3)                      │
   │ 资源圈: 湖(36,58, 挪近) 树林带·近巢(僵尸,44,60)        │ z≈36-60
   │ 矿业圈: 煤坑(100,52) 铁坑(24,44) 中巢(蜘蛛,96,36)      │ 外环东/西
   │ 家园核心圈(压平y24): 小屋(61,81 不动) 门阵广场(东)      │ z≈64-96
   │                      农田(屋南) 畜牧围栏(屋西) 花草场   │ x≈36-88
   └─────────────────────────────────────────┘
        南(z=127)
```

| 圈层 | 距小屋 | 内容 | 危险度 |
| --- | --- | --- | --- |
| **家园核心圈** | ≤18 | 小屋(原坐标) · 东侧门阵广场(三扇门+圆石铺装) · 屋南初始农田(4×3 耕地+已熟小麦——点亮种子→小麦→面包教学第一环) · 屋西畜牧围栏(原木柱+木板栏, 四畜在场内, F4 畜牧 AI 零改动) · 花丛(蒲公英黄/雏菊白,新方块)草场 | 零（火把环亮着） |
| **资源圈** | 25~45 | 湖挪近至 (36,58)——黏土/沙岸教学链步行 30 秒内可达 · 两片小树林(疏密节奏替代随机 40 棵) · 近巢(僵尸一家, 温和) | 低 |
| **矿业圈** | 40~60 | 煤坑挪 (100,52) · 铁坑挪 (24,44)（两坑分踞东西, 探索动线成环) · 中巢(虫虫族) | 中 |
| **深险圈** | >60 | 山洞口挪北边缘 (62,10)——隧道向南深潜, 钻石穴室在最深处 · 远巢(草木族·苦力怕) 居西北角 · 丘陵最高点 | 高（远征预演） |

设计原则（合理性的来源，MC 主世界同构——风险-距离梯度）：

1. **越远越危险、越远越富**：近处木/食物/黏土 → 中距煤/铁 → 远端金/钻/强巢。孩子学会
   「走多远、带什么」的判断，这正是冒险模式的注意力训练价值。
2. **动线成环**：小屋→门阵→农田→牧场为家内环；出湖→矿区→山洞可绕外环一圈回home，
   小径（圆石间断铺装）做方向引导——不新增方块。
3. **起伏地形**：确定性高度场 `h(x,z)` = 基准 24 + 低频丘体（16×16 控制格 hash 幅度
   ±3、双线性插值、整格阶梯——坡度每步 ≤1 格，儿童可登可下）；圈层越外丘体越高（深险
   圈最高 ±3，家园圈 0）；湖盆/矿坑漏斗/山洞口/巢丘/门阵各带压平半径。工具落 SceneKit
   （引擎层「场景搭建工具」本份，确定性零玩法知识）——沙漠沙丘/雪原雪堆直接复用。
4. **植被层次**：花丛两款（thin 同草丛）散布家内草场；树林从「随机散」改为「两三片小
   树林 + 开阔草场」；深险圈丘陵带石露头（石头露面，视觉预告危险）。
5. **巢穴梯度 + 外观差异**：近巢矮丘少苔（僵尸）→ 中巢中丘常苔（蜘蛛）→ 远巢高丘密苔
   （苦力怕），巢丘参数进地图行。

**迁移代价（主动承受）**：湖/两坑/山洞/三巢的既有硬编码坐标全部更新；老档玩家在这些
区域的 edits 重放可能与新地形错位（世界卫生清扫会治愈浮空违例）；adventure-core.test
的形状断言随新坐标更新。**小屋坐标不动**保住老档出生语义。

克制边界：不做河流（湖已够）、不做村庄（二期候选）。

## 4. 切换机制：传送门站桩 + 遮罩（「不被感知」的完整配方）

依据 map-transition-research §2/§5 速查表 #1-#7 + 本仓库实测：

### 4.1 时序（站桩 2s，全程可反悔）

```
玩家走进门面(坐标区间触发, nether portalAt 同款)
 └─ 站桩计时开始: 门面光束变亮 + 上升音效(portal.trigger 双段式第一段)
     └─ 0~2s 内走出 → 一切归零(可反悔, MC 下界门口径)
 └─ 2s 站满:
     ① 全屏遮罩淡入 400ms(紫白渐晕 vignette, CSS overlay; 幼儿忌纯黑)
     ② 遮罩满格瞬间执行切图(同步, 实测 12-25ms):
        loadScene(目标图建场 + 分桶账本重放) → applyMapPalette(天/雾/水色)
        → Mobs.clear/Drops.clear/箭矢清(下界先例: 投射物不跨图) → spawn 落回程门内
     ③ 渐进收尾已自动铺开(loadScene 先建脚下, 数帧铺满远景)
     ④ 遮罩淡出 400ms + 第二段音效(travel) + TTS「到沙漠啦!」
     └─ 玩家从回程门里走出来, 面朝新图(下界门口径: 门在身后)
```

- **遮罩必须快**（Mass Effect 教训，≤5s 上限）：全程 2.8s 左右，其中真正的「看不见画面」
  仅 0.8s。
- **预构建**（速查表 #2/#10）：站桩开始的 2s 是空闲窗口——把目标图的建场挪进来？**一期不做**
  （实测同步成本仅 12-25ms，不值得引入双世界数据的复杂度）；二期若做「上图 mesh LRU 回程
  秒开」（速查表 #13）再一起动 world.js。
- **chunk 淡入**（速查表 #7，MC 1.21.11 官方做法）：渐进收尾「先脚下后远景」已是事实淡入；
  二期可选给新建 chunk 材质加 200ms opacity 渐变，锦上添花。
- **防误触**：0.8s 传送冷却（nether NETHER_PORTAL_CD 同款）+ 落点在回程门内 2 格（走出
  门外才可能再触发）。

### 4.2 切图的清场契约（复用 mode-switch 收口的守恒契约）

切图沿用模式切换的兜底清单（docs/mode-switch-unification-design.md）：Mobs.clear（重挂
引擎回调）、Drops.clear、advArrows.clear（投射物不跨图）、flyMode=false、站点缓存重扫
（advRescanStations）、树苗计时重挂（advRescanSaplings）、流体编辑账本缝重挂
（setFluidEditSink 不变——账本本身分桶，见 §5）。**每图一份的运行时状态**（巢穴节拍器
advNestT、夜怪节拍、任务谓词缓存）在切图时随地图行重置。

### 4.3 不做的东西（明确出界）

- 不做单世界无限流式（noa 级调度投入，研究 §6 已评估）；
- 不做世界数据双缓冲/后台预生成（成本仅一二帧，无必要）;
- 不做 biome blend 边界渐变（离散地图无边界）；
- 不做骑滑动窄道/电梯（分图场景无连续走廊可挂）。

## 5. 存档扩展（分桶账本）

`adventure_world_save` 五键扩展（**老档零迁移**：decode 补缺省即自动归位）：

```
edits: Map("x,y,z"→…)                →  edits: {home: Map, desert: Map, …}   // 建造分桶同款
furnaces: Map(posKey→炉态)            →  furnaces 分桶同上（每图炉位独立）
livestock: {dead:[]}                  →  分桶（每图畜牧账独立）
pos/hp                                →  随当前图（切图时由门落点接管, 老档缺省 home）
dayTime                               →  保持全局单一时钟（MC 口径: 切图时间连续）
+ map: 'home'（当前所在图, 老档缺省 home）
+ unlocked: ['home','desert',…]（门阵点亮账; 或并入任务档 counts, 见 §10）
```

- WorldJournal 的桶形状是消费方政策（world-journal-core.js:35 注释明示），**journal 零改动**，
  探险壳照建造先例「当前桶换装 journal.edits」。
- 大宝箱全局账户（adventure_chest_save）**不分桶**——「全冒险一个家底」正是它的人设。
- 背包（ADR 0002 背包壳）跨图随身——远征满载回家的乐趣依赖这一点。
