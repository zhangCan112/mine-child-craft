# 怪物巢穴与地下副本（Den）· 设计定稿

> **需求**（用户 2026-10-29）：给冒险模式主地图添加一个怪物巢穴——白天怪物只在地下洞穴，
> 门口有个别几只；到了晚上大量怪物从地下洞穴出来，在周围游荡。主世界的地下做得稍微
> 厚一点，并做一次「巧妙的地图切换」：主人公进入后进入一个怪物地下巢穴的副本地图。
> **状态**：已实施（本文为施工契约与拍板记录）。
> **参照先例**：下界相位（docs/nether-merge-design.md 的切界/分桶/O(1) 判定机制泛化）·
> 门阵站桩仪式（docs/adventure-maps-design.md §4）· MC 刷怪笼地牢（minecraft.wiki：
> spawner 地牢=昏暗石室+刷怪笼+宝箱；只取语义与观感语言，像素与数值自绘/自配）。
> **日期**：2026-10-29。**§7**（2026-10-30）：苦力怕主题改造——七房弯隧道/谱系分层
> 布防/关底苦力怕王/深处祭坛房波次制，用户四轮拍板，见文末 §7。

## 0. 一句话架构

**主世界 home 图新增「黑巢」POI（地表巨丘 + y24→y10 深洞道 + 巢厅「怪物巢穴之心」），
巢之心旁站桩 2s 切入探险模式第三维度 `den`（地下巨洞副本：祭坛刷怪 + 矿藏 + 宝箱）；
白天门口个别几只走既有巢穴机制，夜间新增「涌出」铺法从巢口爬怪在巢穴周围游荡；
存档走既有分桶账本加 `den` 桶，老档零迁移。**

## 1. 决策清单（全部已拍板）

## 2. 主世界：黑巢（home 图新 POI）

### 2.1 位点与形态

- **ADV_DEN_NEST = {x: 100, z: 8}**：深险圈北缘东侧。距小屋 (61,81) 82.7 格（>60 深险圈 ✓）；
  山洞口 (62,10) 东 38 格、松林圈 (122,28,r15) 西 30 格、煤坑 (100,52) 北 44 格——无压平区重叠；
  巢穴难度序（距小屋单调递增）收尾：近巢 27.7 < 中巢 43.8 < 远巢 76.2 < **黑巢 82.7**。
- **地表巨丘**（advBuildDenNest）：r5 黑石巨丘（比普通巢 r2 大一圈），冠 h5/身 h4~3/裙 h2
  三段纵剖面（2026-10-30 观感票加高冠）：丘冠（d<1.2）黑曜石为主=黑石王冠、丘身石芯+
  苔石点缀+偶黑曜石、丘裙只石苔（随机黑块不撒到草皮边）；斑块逐格掷点（y 入盐，
  旧版整列同 id 的「黑柱串」观感消除）；**不用煤矿斑**——矿带断言锁「煤矿只在 y12~20」
  全图红线（adventure-core.test），丘体装饰不入矿带（设计初稿的「煤矿斑」作废）。
  丘体全件上图集贴图（苔石/黑曜石格，2026-10-30 巢穴观感票——此前 faceColor 纯色兜底
  是「黑巢读不出黑」的根因）。洞口朝南 2×2 敞廊；丘足印压平登记 ADV_FLATS。
- **深洞道**：洞口 y24 → 2 宽台阶下潜至 y10（14 格深），中段 (100,16) 处向东转折一个小前厅
  （4×4×3）再折回向下——比既有山洞直隧道更「绕」，沿途洞壁镶煤/铁（可见性教学，山洞同款）。
  入口露天段（z13~16）与进厅台阶（y11→y8）全程 **1 格级、双向可走**（2026-10-30 修：洞道
  carve 顶穿草皮留 4 格壕沟困人 + 台阶错层，已回填对齐；夜袭涌出点 z15 即在台阶上）。
- **巢厅**（y7~y10，9×5×4）：中央 B_SPAWNER 怪物巢穴之心（微红光），角落 1 块发光岩
  （微弱引导，不破坏黑暗感）；巢之心是副本入口判定锚。

- **巢穴之门**（2026-10-30 增，用户拍板迁移入口）：洞口画廊北端 z11 小门——黑曜石门槛+
  2×2 B_PORTAL 紫门面+发光岩门楣；门内站桩 2s 切入副本（advPortalTick 门阵同款站桩，
  advDenDoorAt 认领）。原「巢厅巢之心旁站桩」废除（用户反馈「传送门不知道在哪，莫名被
  传送」）；巢之心保留为巢厅地标，不再判定。门框柱同日补（2026-10-30 观感票）：
  门面两侧贴廊壁各一根黑曜石柱（y22~24，经典门框观感）；黑曜石/发光岩/苔石入
  贴图图集（texture-atlas 格 47~49）。**门面回退玻璃通道**（2026-10-30 用户拍板）：
  门面贴图三试三否（v1 斜纹平紫块 / v2 逐块小漩涡 / v3 4×4 宏格大漩涡——「太丑了」
  「2 格门没考虑」），门面/熄门不入图集，B_PORTAL 走 glass 通道平紫半透明渲染
  （贴图前观感，2 格门/3 格门天然均匀，无任何特殊处理），辨识度改由**常驻紫色
  光柱**承担（advBeamsRelayout 巢门查表补束 + Fx.portalBeam 芯柱加宽提亮，
  init 即锚不再等首次切图）。

## 3. 副本维度：den「巨怪巢穴」

### 3.1 地形（advDenBuild，确定性零 Math.random）

160×160 整图岩石体（y0~y40 石头），中部掏出巨洞世界：

```
        北 (z=0)
   ┌───────────────────────────────┐
   │  实心岩石（y0~y40）              │
   │   ┌─────────────────┐          │
   │   │ 回程裂隙门(76,66) │          │ z≈60-70
   │   │   ┌───────┐      │          │
   │   │   │刷怪祭坛│       │ 矿藏廊→  │ z≈70-90  东侧走廊+两矿腔
   │   │   │(80,80)│      ├────────┤ │
   │   │   └───────┘      │ 宝箱室   │
   │   └─────────────────┘ (116,80) │
   │     出生点(80.5,92.5) 面朝北     │
   └───────────────────────────────┘
        南 (z=159)
```

- **巨洞大厅**：中心 (80,80) 半径 14 圆厅；地面 y6（苔石/泥地确定性混铺）；穹顶从厅缘
  y30 斜升至中央 y38（ADV_DEN.roof 常量——D10 的未来扩高锚点）。
- **刷怪祭坛**：厅心 3×3 B_SPAWNER 平台 + 四角黑曜石柱（y7~y11）+ 柱顶发光岩；
  副本刷怪的家锚与出生环心。
- **回程裂隙门**：大厅北墙 (76,66) 常亮传送门（advPortalFrame 经典黑曜石口径），
  建场直写不记账（互锁红线：基座建场不进 edits）。
- **矿藏廊**：大厅东墙洞口 → 东向走廊 (94~112, 78~82) → 两间矿腔（煤/铁/金/钻高密度
  镶矿，advTryOre 白名单登记=矿位跨天回填自动生效）→ 尽头**宝箱室** (116,80) 5×5×3
  （B_CHEST + 两支火把；advMapChestKey 'den' 行挂 chest_den 任务键）。
- **发光岩簇**：穹顶+地面确定性低频散布（SceneKit.rand 盐值分层）——黑暗氛围里的
  路标，防 6 岁孩子纯黑迷路。
- **无熔岩**（拍板：副本的危险=怪物，不叠第三重压力；「唯一危险=岩浆」是下界设定）。

### 3.3 入口站桩时序（与门阵仪式同构）


## 4. 「地下做厚一点」的实现口径（D10 展开）

用户要的「地下厚」是**体验层**的可探索深度与藏怪空间，不是全局世界高度的数值加高：

1. **主世界**：黑巢深洞道 y24→y10（14 格，带转折前厅）+ 巢厅——home 图此前最深的
   可探索结构是山洞穴室（y2~5 直隧道），黑巢提供了第二条「更深更绕」的地下动线。
2. **副本**：地下巨洞净空 30+ 格（y6 地面 / y38 穹顶）——「深入地底」的体感由
   巨洞体量+黑暗+穹顶发光岩承担。
3. **为什么不动 WORLD_H**：全局高度影响所有模式的内存（worldCells+双光场 ≈ +1.2MB）
   与网格打包成本（低核 iPad 红线）；而「地表抬升换地下加厚」会重排全部既有 y 坐标
   并使老档 edits 重放错位（存档红线）。副本穹顶高度收在 ADV_DEN.roof 常量，
   未来若升 WORLD_H（48→64）只改两个数字即可受益。

| # | MC 机制 | 本项目口径 | 后果与理由 |

## 7. 苦力怕主题改造（2026-10-30，用户四轮拍板 · 已实施）

> **需求**（用户 2026-10-30，四轮）：① 更多怪物分布在房间；② 分布按谱系和层级有高有低，
> 低级怪物以苦力怕为主 ≥60%，关底 boss 是苦力怕王；③ 更多隧道通向更多怪物房间，
> 最后关底大房间里是苦力怕王，房间要有布置、有火把照亮；④ 隧道不要全直线，弯弯曲曲
> 增加恐怖气氛；⑤ 苦力怕王掉 10 个火药+稀有道具钻石剑；⑥ 允带其他地底生物增加生态
