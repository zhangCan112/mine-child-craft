## 1. 决策清单（全部已拍板）

| # | 决策 | 理由 |

## 2. 主世界：黑巢（home 图新 POI）

  山洞口 (62,10) 东 38 格、松林圈 (122,28,r15) 西 30 格、煤坑 (100,52) 北 44 格——无压平区重叠；

## 3. 副本维度：den「巨怪巢穴」

### 3.1 地形（advDenBuild，确定性零 Math.random）

160×160 整图岩石体（y0~y40 石头），中部掏出巨洞世界：

```
        北 (z=0)
   ┌───────────────────────────────┐
   │  实心岩石（y0~y40）              │
   │   ┌─────────────────┐          │
   │   │ 回程裂隙门(76,66) │          │ z≈60-70
   │   │   ┌───────┐      │          │
   │   │   │刷怪祭坛│       │ 矿藏廊→  │ z≈70-90  东侧走廊+两矿腔
   │   │   │(80,80)│      ├────────┤ │
   │   │   └───────┘      │ 宝箱室   │
   │   └─────────────────┘ (116,80) │
   │     出生点(80.5,92.5) 面朝北     │
   └───────────────────────────────┘
        南 (z=159)
```

- **巨洞大厅**：中心 (80,80) 半径 14 圆厅；地面 y6（苔石/泥地确定性混铺）；穹顶从厅缘
  y30 斜升至中央 y38（ADV_DEN.roof 常量——D10 的未来扩高锚点）。
- **刷怪祭坛**：厅心 3×3 B_SPAWNER 平台 + 四角黑曜石柱（y7~y11）+ 柱顶发光岩；
  副本刷怪的家锚与出生环心。
- **回程裂隙门**：大厅北墙 (76,66) 常亮传送门（advPortalFrame 经典黑曜石口径），
  建场直写不记账（互锁红线：基座建场不进 edits）。
- **矿藏廊**：大厅东墙洞口 → 东向走廊 (94~112, 78~82) → 两间矿腔（煤/铁/金/钻高密度
  镶矿，advTryOre 白名单登记=矿位跨天回填自动生效）→ 尽头**宝箱室** (116,80) 5×5×3
  （B_CHEST + 两支火把；advMapChestKey 'den' 行挂 chest_den 任务键）。
- **发光岩簇**：穹顶+地面确定性低频散布（SceneKit.rand 盐值分层）——黑暗氛围里的
  路标，防 6 岁孩子纯黑迷路。
- **无熔岩**（拍板：副本的危险=怪物，不叠第三重压力；「唯一危险=岩浆」是下界设定）。

## 4. 「地下做厚一点」的实现口径（D10 展开）

用户要的「地下厚」是**体验层**的可探索深度与藏怪空间，不是全局世界高度的数值加高：

1. **主世界**：黑巢深洞道 y24→y10（14 格，带转折前厅）+ 巢厅——home 图此前最深的
   可探索结构是山洞穴室（y2~5 直隧道），黑巢提供了第二条「更深更绕」的地下动线。
2. **副本**：地下巨洞净空 30+ 格（y6 地面 / y38 穹顶）——「深入地底」的体感由
   巨洞体量+黑暗+穹顶发光岩承担。
3. **为什么不动 WORLD_H**：全局高度影响所有模式的内存（worldCells+双光场 ≈ +1.2MB）
   与网格打包成本（低核 iPad 红线）；而「地表抬升换地下加厚」会重排全部既有 y 坐标
   并使老档 edits 重放错位（存档红线）。副本穹顶高度收在 ADV_DEN.roof 常量，
   未来若升 WORLD_H（48→64）只改两个数字即可受益。

### 7.5 波次 5 轮封顶与战利品宝箱（2026-10-30 第二批拍板 · 施工契约）

> **需求**（用户 2026-10-30）：① 刷怪祭坛从无限波次改为**最多 5 轮**；② 第 5 轮清完后
> 刷出一个**战利品宝箱**——与玩家可造箱子（B_CHEST）不是同一物品的**占 2 格新方块**，
> 红+金经典配色专属贴图，点击敲击 2 秒打碎，打碎掉落各种道具；③ 掉落内容**全部任务
> 完成后再与用户讨论**——先用占位表跑通链路。

**波次封顶口径**（D15）：`advDenStep(cleared, t, dt, wave, chestDone)` 纯核扩展——
wave<WAVES 走既有 advSpawnPulse「全清→10s→下一波」节拍；wave≥WAVES 时全清即发
`chest` 信号（chestDone=false 才发，发一次）并熄火（t 恒 0，不再出波）。壳层
advDenTick 只落地：出波令 →wave+1 布防；chest 信号 → 刷宝箱+庆祝话术。

**宝箱刷出与打碎链路**（D16/D17）：

- 刷出：深处祭坛房北墙贴墙 2 格（ADV_DEN.loot，跨 x 62~63 @ z22 面朝南厅），setBlockRaw
  直写不记账（回程门同款互锁红线），mesh 两列当帧收口；win 琶音+TTS/toast 庆祝。
- 敲碎：蓄力挖掘链照走（hard 1.33 → 徒手 ≈2s）；配对破坏计划 advLootChestPlan（床配对
  同款缝，挂在 place-kit breakBlock 与 TNT 链两处）→ 另一半同拍清除+记账，掉落表掷骰
  恰一次、逐条 Drops.spawn（走 D14 修好的副本掉落物理）。
- 掉落表（已拍板）：ADV_DEN_LOOT = 火药 3+50% 加成 1 · 铁锭 2+50% · 金锭 1+50% ·
  苹果 2 · 钻石必得——用户 2026-10-30 拍板「就用当前占位表」，初版即终版。
- 持久化：无专用账。宝箱出现本身是会话演出（波次同命）；打碎记录经 edits 生效——
  重进后宝箱不在场，直到再次通关 5 轮。可逆决策（改语义只动壳层刷出点），不立 ADR。

**施工落点**：config.js（B_LOOT_CHEST=71）· texture-atlas.js（格 50/51 红金画师+layout 行）·
adventure-dims-core.js（WAVES/loot 常量 + advDenStep 扩展 + ADV_DEN_LOOT/advDenLootRoll/
advLootChestPlan）· modes/adventure.js（advDenChestDone 态 + advDenTick 刷箱 +
advDenLootSpawn + TNT 链挂配对破坏）· place-kit.js（lootChestApply 配对破坏分支）·
mesh-core **零改动**（标准图集立方体通道）。测试：adventure-den（封顶节拍/掷骰/配对计划/
2 秒口径）· place-kit（配对破坏契约）· texture-atlas（格 50/51 像素）· adventure-nether
（真世界 5 轮流程→刷箱→打碎→重进不再现）。

**低档小奖励箱**（D18，2026-10-30 第三批拍板 · 体验馆试玩工位）：

- 方块：B_LOOT_CHEST_SMALL=72（号段顺延，73+ 仍预留）——单格整箱**无配对**：
  advLootChestSmallPlan 按破坏块 id 认主（大箱四邻认亲读的是世界，小箱读的是
  「刚敲的是什么」——两判据互补），cells 恒空（无第二格要清，触发格已由破坏链
  清格记账）。place-kit lootChestApply **先认小箱再回退** advLootChestPlan 四邻
  认亲——小箱挨着大箱也不误吃大箱的配对。敲 2 秒口径与 71 同款；无 drop 字段
  （TNT 掷普通表掷不到东西，掉落由破坏计划兜底——炸了也给，儿童零惩罚，71 同
  款）；无 lchest 旗标（那是配对破坏身份，单格款没有配对可认）。
- 掉落表：ADV_DEN_LOOT_SMALL = 火药 2 · 铁锭 1 · 苹果 1（无金无钻无掷骰）——
  advDenLootRoll 加 table 注入参（缺省 ADV_DEN_LOOT，旧调用零改动），「表只存
  数据、掷骰在消费方」契约不变。
- 纹理：复用 71 的红金图集格 50/51（texture-atlas layout 加一行映射，零新增画师
  格位，count 仍 52）——「新 id 好认物，红金好认箱」，单格 vs 双格一眼分大小。
- 刷出：体验馆 showroomLootChest 双工位——大箱 (66..67, g+1, 62)、小箱 (66, g+1, 60)
  （北邻错行，与大箱不共线——红金同纹不会误读成三连箱；避坑清单同上批工位）。
  进场直写不记账，重进必得新箱。**副本侧零接线**（TNT 链与蓄力链的 id 透传是
  通用口径，非副本刷出）。

**副本宝箱室换箱与补给定版**（D19，2026-10-30 第四批拍板）：

- 换箱：宝箱室原木箱（B_CHEST 储物箱）→ **小宝箱**（B_LOOT_CHEST_SMALL，同坐标
  ADV_DEN.chest={116,8,80}，任务键 chest_den 同源不变）。建场预置随世界档持久：
  打碎经 edits 记账，重进不复活=**一次补给**（与祭坛房大宝箱「5 轮通关可重刷」
  的演出语义互不相干）。
- 掉落定版：ADV_DEN_LOOT_SMALL = **铁剑 1 + 苹果 10**（D18 初版火药 2·铁锭 1·
  苹果 1 是试玩占位，随箱进副本转正；体验馆工位同箱同表）。
- 任务计数随箱型迁移：**「打开」→「打碎」**——place-kit 新政策缝
  onLootChestBreak(x,y,z,id,quest)（两条破坏链汇聚点，计划命中才发），壳层经
  advMapChestKey(advSceneKey(), …) 场景+坐标双判定后 advTally('chest_den')；
  TNT 链 quest=false 不计数（P6：掀掉的不算任务），补给照掉。其余三结构
  （神殿/雪屋/女巫屋）仍是 B_CHEST 开箱计数，互不干扰；q26 文案同步
  「打开→打碎/敲碎」。
- 施工落点：adventure-dims-core.js（建场一行+表定版）· place-kit.js
  （onLootChestBreak 缝）· modes/adventure.js（壳层 tally 接线）·
  adventure-core.js（q26 文案）· adventure-maps-core.js（键注释）。测试：
  adventure-den（建场小宝箱同源锚/补给表掷骰/单格计划）· place-kit（钩子契约
  坐标+id+quest 全参/误吃锚回归）。
