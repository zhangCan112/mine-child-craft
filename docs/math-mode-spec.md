# 数学冒险岛 · Spec

> 生命周期：已完工 — 施工期工件，仅作历史依据；行为权威见 [math-mode-design.md](math-mode-design.md)

> 状态：**ready-for-agent**（to-spec 产出，2026-10-24；测试缝已经用户确认）。
> 证据链：`docs/math-thinking-research.md`（研究）→ `docs/math-mode-plan.md`（需求定稿 D1~D9）→ `docs/math-mode-design.md`（实现设计与切票 T1~T9）。
> 相关 ADR：0001（每日预算单一存档键——math 预算并入同一账本）、0002（共享背包——数学是新的"只产出"消费方）。

## Problem Statement

用户想给正在读一年级（将升二年级）的 6-7 岁孩子锻炼数学思维。市面做题 App 是"穿游戏皮的题海"，孩子很快识破；而孩子深爱的方块世界（本项目）目前只有注意力训练（专注训练营），没有承载数学练习的模式。家长需要的是：把校内第一学段（1~2 年级）正在教的内容，变成孩子**主动要玩**的游戏，且难度要按教材的扩展题/附加题水平设计——重点培养思维方法，而不是计算熟练度抄写。

## Solution

新增训练营类游戏模式**数学冒险岛**：主菜单一张新卡，进入后是一张 120 关的关卡地图（G4 扩容，用户拍板"扩到 120 关"）。地图按教材四个学期带（一上→二下）推进，带内**六个玩法族轮转**（数一数/算一算/跳一跳/摆一摆/搭一搭/找一找，共 26 种关卡形态 + 情境皮肤 + 带末综合挑战），孩子每玩两三关就换一种玩法。难度执行"**数值跟着教材走，思维跳到附加题**"双轨：数字范围严格不超前，题型按算式谜、等量代换、周期问题、移多补少、隐藏块计数等附加题经典形态设计。整套成关框架（三星评价、每日 6 关/20 分钟独立预算、图标+中文 TTS 零文字依赖、过程性表扬、战利品进共享背包）复用专注训练营的既有机制。

## User Stories

**孩子（一年级玩家起步，覆盖到二年级）**

1. 作为一年级孩子，我想在主菜单看到一张新的大卡片"数学冒险岛"，这样我和专注训练营一样知道去哪儿玩数学。
2. 作为孩子，我想每次进岛玩到的关卡都不重样（六族轮转），这样不会像练习册那样翻两页就腻。
3. 作为孩子，我想玩"怪物快照"——一群怪物闪一下，我点出有几只，这样练一眼看出数量的本领。
4. 作为孩子，我想玩"按数取物"——系统说"给我 7 个方块"，我点够数搬进箱子，这样数词和数量对上号。
5. 作为孩子，我想玩"比多少"——两堆方块谁多、多几个，这样理解多与少是能算出来的。
6. 作为孩子，我想玩"移多补少"（挑战）——从多的一堆搬几个到少的那边才一样多，我可以搬着试错，这样体会"移 1 个差变 2"的规律。
7. 作为孩子，我想玩"材料够不够"——看看背包里的木板够不够做木镐，这样练习点数和比较。
8. 作为孩子，我想玩"还差几个"——配方缺了材料，算出还差几个，这样减法有了真用途。
9. 作为孩子，我想玩"合成订单"——做 2 把木镐要几块木板，这样乘法在合成台里先遇到。
10. 作为孩子，我想玩"魔法空格"（挑战）——配方里挖了个空（?+3=8），我填出神秘数字，这样学会倒着想。
11. 作为孩子，我想玩"多解找齐"（挑战）——哪两个数合起来是 10，把所有答案都找齐才满星，这样学会按顺序找、不漏不重。
12. 作为孩子，我想玩"怪物天平"（挑战）——2 只僵尸=4 只苦力怕，那 1 只僵尸等于几只，这样体会等量代换。
13. 作为孩子，我想玩"掷骰前进"——在一条笔直的方块路上走棋子，这样数字顺序走在我脚下。
14. 作为孩子，我想玩"跳格子任务"——从 14 格跳到 18 格要跳几格，这样"相差多少"看得见。
15. 作为孩子，我想玩"间隔问题"（挑战）——从第 3 格走到第 9 格中间经过几格，我自己走一遍数出来，这样植树问题不再绕晕。
16. 作为孩子，我想玩"规律跳"（挑战）——每次多跳 1 格，猜第 5 次落在哪，这样数列规律有感觉。
17. 作为孩子，我想玩"站位比大小"——两个数字谁站得远谁大，这样数轴上比大小。
18. 作为孩子，我想玩"魔法镜补全"——半边建好的蝴蝶/城堡，我把镜像另一半补齐，这样空间想象在手上练。
19. 作为孩子，我想玩"平移复制"和"旋转对称"，这样在二年级学图形运动前就玩过它。
20. 作为孩子，我想玩"拼组与省料"（挑战）——用给定的积木恰好拼出目标图形、或用最少的块搭一座能通行的桥，这样学会试、比、优化。
21. 作为孩子，我想玩"看图施工"——照着俯视图纸在 3D 里搭出建筑，这样图纸和立体在我脑里能互相转换。
22. 作为孩子，我想玩"反向选图"——看一座建筑，从几张图纸里选出正确的俯视图，这样两个方向都通。
23. 作为孩子，我想玩"数方块"（挑战）——这座塔一共有几块，包括藏起来看不见的，这样学会想见看不见的部分。
24. 作为孩子，我想玩"双视角推理"（挑战）——正面看是山、侧面看是墙，找出是哪座建筑，这样线索推理有画面。
25. 作为孩子，我想玩"花纹接龙"——红红蓝、红红蓝、下一个是什么，这样规律看得懂。
26. 作为孩子，我想玩"周期问题"（挑战）——红红蓝一直循环，第 15 个是什么，不许摆完靠规律推，这样大数也难不倒。
27. 作为孩子，我想玩"分装箱"和"找异类"，还能换一个标准再分一次，这样同一堆东西有不同看法。
28. 作为孩子，我想玩"线索排队"（挑战）——按"谁比谁高"的三条线索给三只怪物排队，这样逻辑推理像破案。
29. 作为孩子，我想在人民币商店里买东西、算找零，还能想出"付钱有几种付法"，这样认识人民币有真场景。
30. 作为孩子，我想看岛上的昼夜大钟并玩认时刻的关卡（整时/半时/过一刻钟是几点），这样钟表不陌生。
31. 作为孩子，我想用"数格子"量距离（到那棵树几格、来回几格），这样测量就用方块当尺子。
32. 作为孩子，我想每带结尾玩一次"小镇集市"综合挑战——连闯三个族的小任务，这样学过的本领一起用上。
33. 作为孩子，我想每关只有 2-3 分钟、规则用语音讲给我听、全程图标不需要认字，这样我自己就能玩。
34. 作为孩子，我想答对了听到"你倒着也想出来了！"这样的表扬（夸我努力和方法，不夸聪明），做错了听到"没关系我们慢慢来"，这样我不怕错。
35. 作为孩子，我想拿到三星评价、点亮族徽章，第三颗星要过"思维挑战关"才亮（补过后前面的星也会亮起来），这样挑战有关联感。
36. 作为孩子，我想关卡掉落战利品（矿石、染料、花……）飞进我和探险模式共用的背包，这样数学岛的收获在别处也看得见。
37. 作为孩子，我想每天玩够 6 关或 20 分钟后系统温和地告诉我"明天再来"，这样妈妈放心让我玩。
38. 作为孩子，我想关卡从教学关起步、每关只多一个新的变化，这样不挫败。
39. 作为孩子，我想重玩打过的关刷新星星，这样还想再试一次。
40. 作为孩子，我想难度"数字不超纲"——一年级上学期只遇到 20 以内的数，但题目会让我多想一步、倒着想、找多种答案，这样有点难又够得着。

**家长**

41. 作为家长，我想数学岛有独立的每日限额（默认 6 关/20 分钟），不占孩子的游玩时限、也不与专注训练营互相挤占，这样三类活动均衡。
42. 作为家长，我想在家长面板看到"六族 × 四学期带"的正确率矩阵和趋势，以及"思维挑战通过率"单列，这样知道孩子哪类思维强、哪类需要生活中补。
43. 作为家长，我想导出 CSV 记录留档，这样必要时给老师看过程数据。
44. 作为家长，我想看到诚实的说明——只说"练习数数、加减、找规律、推理和空间构造"，不承诺提高成绩/智商/治疗，这样不被夸大宣传误导。
45. 作为家长，我想孩子的进度经既有同步机制在多设备间一致，这样换电脑不丢进度。

**开发者/维护者**

46. 作为开发者，我想模式清单只在模式注册表加一行、由三重命名测试对着入口页断言，这样手滑即红。
47. 作为开发者，我想全部玩法决策（曲线、编排、判分、掷骰、迁移）都在零 DOM 零渲染的库层并配单测，这样行为可锁定、回归可测。
48. 作为开发者，我想出题与判分是种子注入的纯函数（同 seed 同输出），这样概率边界与谜题正确性可断言。
49. 作为开发者，我想引擎层零改动——世界族全部经既有 seam（场景装填、场景搭建工具、玩家形象、相机装置的瞄准射线、特效、语音）接线，这样不碰渲染回归面。
50. 作为开发者，我想战利品走共享背包壳、只产出不消耗、掉落以基础材料为主（遵循 ADR 0002 经济口径），这样未来消费模式的存量可消化。
51. 作为开发者，我想每日预算并入单一存档键的既有账本（遵循 ADR 0001），午夜翻转与迁移逻辑不另起炉灶。
52. 作为开发者，我想新文件自动被规范守门（命名、模块头五要素）覆盖，这样风格不漂。

## Implementation Decisions

- **模式定位**：训练营类（同专注训练营先例）——全屏接管 UI、独立每日预算、不属于游玩模式、不占儿童时限；主菜单一张卡，入口经模式注册表（清单唯一权威，`id math`，无菜单页）。三重命名断言自动覆盖。
- **新模块**（一文件一模块，模块头走五要素契约）：
  - **数学关卡参数表（MathLevels）**：数值唯一权威——六族与变体元数据（图标/规则话术/提示话术）、四带数值轴、每族双轨难度曲线、120 关编排生成、通过门槛/三星判定（纯函数）、战利品表与掷骰政策、存档默认值与迁移。零渲染零 DOM。
  - **谜题纯核心（PuzzleCore）**：出题与判分的纯数据变换——镜像/平移/旋转图案生成与判分、俯视图投影、隐藏块与露面计数、数列与周期生成、合成多解枚举、天平代换链、线索排队生成、间隔问答。种子注入。注意：是**生成器不是题库**。
  - **数学屏流引擎**：屏流族的"呈现-点选-反馈"流程与小部件（数量选择条、方块堆、序列槽、天平、线索卡、背包清单、商店、钟面），DOM 惰性、零渲染引擎。
  - **模式层装配（MathMode）**：入口/今日页/关卡地图/结算/图章/家长面板的屏幕流装配 + 世界族场景装场与交互接线 + 时长入账节拍。
  - 配套样式表（屏流与地图视觉，像素图标语言、TTS 并行）。
- **呈现双轨**：屏流族（数一数/算一算/找一找全变体、站位比大小、情境关）走 DOM 屏流；世界族（跳一跳的行走类变体、摆一摆、搭一搭）走 3D 场景——谜题数据一律出自纯核心，两轨只差呈现。图纸用纯函数投影画成 2D 像素图，**不用**引擎相机远拍。世界轨每关独立小场景（≤32×32），进场装场、退出清场（场景装填纪律），不写建造存档；放置/走子走相机装置的瞄准射线（准星所指即所操作），纯鼠标，无键盘依赖。
- **难度双轨**（需求拍板核心）：数值轨四带上限 [20, 100, 100, 10000]（带内随 tier 微升，永不超前）；推理轨阶梯 single → two-step → reverse → multi-solve，随 tier 段进。定性跳变概率渐进混入（台阶变坡道）。认知负荷红线写进曲线公共约束：一次呈现 ≤4 组块、线索 ≤3 条、每关只动一个难度维度。
- **关卡编排**：120 关 = 四带 × 30（G4 扩容，原 100 = 四带 × 25）。带内：六族轮转（配重 count/pattern=16、craft/hop=24、mirror/plan=20，算一算/跳一跳主线与新变体承载族略高），每族带内末 1~2 次出现为该族思维挑战变体（★★；G4 起 plan/dualview 与 mirror/bridge 双挑战在带内末两次各占一），带末 1 关综合挑战（三族串联），带首 1~2 关复习上一带；带 0 以教学关开局。tier 沿带与出现次数推进（顶格 19 截断）。新挑战变体带位：dualview 只在带 2+（二年级"观察物体"同频）、bridge 带带 1+。
- **通过门槛与三星**：通过 = 正确率 ≥70%（自适应训练带下界，与专注训练营同口径）；挑战关门槛 ≥80%。三星 = 通过 → ≥85% → ≥95% 且无连续 3 错，**且**该族当带挑战关已通过（纯函数注入布尔，存档查表）；补过挑战关后常规关第三星回溯点亮。
- **存档形状**：星星表（关号→星数）、挑战完成表（族:带→真）、图章日历（日期→当日关数，滚动 90 天）与自选章图案、家长面板数据日志（日期→族→{正确率聚合, 计数, 挑战遇/过}，滚动 90 天）。经既有同步存档槽机制读写，默认值与迁移住在库层可单测。
- **每日预算**：并入单一存档键账本（ADR 0001）——时长 + 关数双维度，默认 6 关/20 分钟，常量与专注限额同址；关内每秒入账（菜单/地图页不计），关数结算时计数；到量温和锁定（今日页文案 + 明天再来）。
- **战利品回路**（遵循 ADR 0002）：数学是共享背包的新"只产出"消费方，经背包壳入包，不得自开存档键；掉落表按族主题化、以基础材料为主、稀有权重低（为未来消费模式留经济余量）；掷骰政策与专注训练营同构——正确试次概率掉落、连对每满 3 保底稀有、教学关豁免、只奖不罚。图章独立一本（不与专注共用）。
- **话术与零文字依赖**：规则/提示/表扬全走 SpeechKit 语音；图标语言 + 数字符号（数字是学习对象，允许出现）。表扬话术数学向、夸方法与努力（过程性表扬）。
- **家长面板**：六族×四带正确率矩阵、思维挑战通过率单列、CSV 导出；只报过程指标，不做能力诊断。
- **宣称口径**（约束所有面向家长的文案）：只说"在方块世界里练习数数、数字顺序、加减、找规律、推理和空间构造"；不出现提高成绩/智商/奥数/竞赛/治疗类表述。
- **引擎层零改动**：全部经既有 seam 接线（场景装填/搭建工具/怪物库/玩家形象/相机装置/特效/语音/纹理图集单格雪碧皮肤模式）。

## Testing Decisions

- **什么算好测试**：只测缝上的外部行为（纯函数的输入输出与结构不变量、注入假文档后的回调流、冒烟链路），不测实现细节；概率与谜题用种子注入锁定边界（同 seed 同输出）。
- **三条测试缝**（已经用户确认，全部为既有缝，不新增）：
  1. **库层纯函数缝**（主战场）：数学关卡参数表与谜题纯核心经 Node vm 直载。断言：双轨曲线（数值轨不越带、推理轨单调）、100 关结构不变量（每带每族出现次数/配重、末次=挑战、带末=综合）、三星挑战挂钩（未过挑战封顶 2 星、补过回溯）、掷骰概率边界（池概率和=1、教学豁免、连对保底）、迁移幂等、每类谜题答案正确性（手算对照）、多解枚举不重不漏、隐藏块计数。
  2. **屏流引擎假 doc 缝**：数学屏流引擎注入假 document，断言试次流、正误反馈回调、语音挂钩、认知负荷红线参数不越界。
  3. **boot 冒烟 + 规范守门缝**：入口页 script 加载序、模式注册表三重命名断言、模块头五要素、模式进出与预算锁定路径不崩。世界族装配（模式层接线）按仓库惯例只吃冒烟——判定逻辑全部已下沉到缝 1。
- **先例**：专注范式/关卡参数表的 vm 直测、模式壳的假 document 单测、模式注册表对入口页的断言、boot 全链冒烟、规范守门测试。

## Out of Scope

- 家长加时通道（专注训练营也没有；未来需要时按"读时求值"加时模式补，不新建账本）。
- 专注训练营式的每日体检/魔鬼特训类比玩法（先观察孩子对数学岛的热度）。
- 触屏适配、账号系统/云存档（走既有设备级同步，不新增）。
- 二年级以上的内容（万以内的加减运算、乘除竖式等）；数值轨严格止步第一学段。
- 引擎层的任何改动；世界轨自由建造级别的交互（只做关卡内的点选放置/走子）。
