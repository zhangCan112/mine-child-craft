## 1. 概述与验收锚

**验收锚（R1-19，置顶）**：「能看到美丽风景，体验到飞翔的感觉和快乐」。

验收画面：孩子从高处跳下（或直接走出悬崖），背上的翼自动展开，缓缓左右转向飘翔，
第三人称看见自己张开的翼与身下的风景，平稳落地（或水面轻轻入水），落地安全、
零惩罚零说教，孩子说「再来一次」。

滑翔翼是**探险模式专属**的装备道具：无消耗永久使用（ADR 0012），装备栏专属第五槽、
与盔甲互不排斥（ADR 0013），离地 >2 格自动展翼、只缓降不爬升、左右转向、落地自动
收翼（ADR 0016）；不带翼从高处坠落有摔落伤害（ADR 0014）——滑翔翼正是「高→摔」
因果的安全出口（拍板理由：培养安全意识，R1-10）。获取仅合成：金锭×4 + 线×2 + 皮革×2，
工作台级（ADR 0015，数量终版已 PO 确认 2026-11-15，§8①）；任务链新增「合成滑翔翼」里程碑（R2-05）。

**整体验收口径**：§3 各功能块验收标准全过 + §4 引用的 UI spec 走查项
（§3.5/§4.5/§5.4/§6.7 四组清单）全过 + `npm test` 全绿（含规范守门）+
`npm run lint` 零错误 + `node server.js` 手工走查验收画面。

## 2. 范围声明

### 2.1 范围内（本期做）

1. 滑翔翼物品注册（ITEMS / ITEM_HINTS / ITEM_PIX 三件接线，UI spec §5 定稿）。
2. 工作台级合成配方：金锭×4 + 线×2 + 皮革×2，3×3 图案本 spec 定稿（§3.2）。
3. 装备栏专属第五槽（`glider` 键），EQUIP_SLOTS 四槽表扩五槽，存档 `worn` 第五键。
4. 滑翔状态机：离地 >2 格自动展翼（不分跳跃/走落）· 只缓降 · 左右转向 · 落地自动
   收翼 · 主动取消（再点跳跃）· 取消闩锁 · 水面软着陆 · 滑翔中暂停挖/放/攻击/吃 ·
   滑翔中卸翼=立刻收翼按无翼坠落。
5. 无翼摔落伤害（新机制，现状没有摔落伤害——research §1）：约 3 格内无伤，4 格起
   每高 1 格扣 1 血，血尽走现有死亡流程；零 TTS。
6. 相机两形态（U-01，实现侧评估裁决）：自动第三人称（优先）或第一人称退化预案，
   两路径验收标准齐备（§3.6）。
7. 第三人称背部翼观感 + 纸娃娃翼显隐口径（MobLook 玩家档加翼骨甲案，UI spec §6/§4
   定稿；UI spec v1.2 起：翼只在滑翔时可见，纸娃娃任何状态不显示翼——「已装备」
   信号走第五槽图标+话术补偿）。
8. 音效两枚：`wing_open` / `wing_close`（UI spec §7 建议口径）。
9. 任务链新增「合成滑翔翼」（链尾追加，R2-05）。
10. HUD 装备条第五槽 + 装备页第五槽 + 滑翔中金描边呼吸（UI spec §3/§4 定稿）。

## 3. 功能规格

> 每块含行为定义 + 验收标准；验收标准是拆票后逐票验收与整体验收的共同口径。
> 涉及 UI 观感处只给行为验收，视觉细节一律以 UI spec 对应节为准（§4 路标）。

### 3.1 滑翔翼物品注册

**行为定义**

- 新物品 id **`glider`**，中文名「滑翔翼」。物品 id = 装备槽键 = 存档第五键，三处同名
  （UI spec §0.3 建议名，本 spec 确认采纳；同名免一层映射，词汇单源）。
- 接线必改三件（research §5）：
  1. **ITEMS 行**（js/items-core.js）：含 `armor` 判据描述 `{slot: 'glider',
     tier: 'gold', pts: 0, tough: 0, dur: 1}`（判据形状照盔甲行，如
     `helmet_leather` items-core.js:191）——`slot: 'glider'` 使 wornPut/wornNormalize
     槽校验成立；`pts: 0, tough: 0` 使盔甲点/韧性/击退合计零贡献（UI spec §4.4
     「盔甲点不计滑翔翼」由此机械成立，零特判）；`tier: 'gold'` 是**本 spec 裁定**
     （非拍板项）：mkArmorDef 手持薄片用 `ARMOR_SIDE_COLORS[a.tier]` 上色
     （held-item.js:208-211 六档色表），gold 档 `0xe9b115` 与 UI spec §5.1 金骨
     主色**同值**——手持侧壁即金骨色，零新色表条目；若用未登记的新 tier 名，
     手持渲染拿到 undefined 色（实现陷阱）。`dur: 1` 为满值占位（wornNormalize
     要求 dur>0 才能过档；**任何路径不得扣减**，见 §5 红线 5）。emoji fallback
     icon 建议 `🪂`（真图标走 ITEM_PIX）。
     另：armor-overlay 只显式渲染 helmet/chestplate/leggings/boots 四分支
     （armor-overlay.js:279 起，无第五槽分支）——翼观感走 MobLook 翼骨甲案
     （UI spec §6.1），overlay 零改动即天然不渲染滑翔翼，符合设计。
  2. **ITEM_HINTS 行**（js/item-hint-registry.js）：名「滑翔翼」，说明「穿上它，
     从高处跳下就会张开翅膀滑翔啦」（UI spec §5.3 建议话术，本 spec 采纳定稿；
     与 R1-14 无 TTS 不冲突——那是滑翔过程安静，这是点到物品的既有介绍通道；
     不得出现耐久/损坏暗示，ADR 0012）。
  3. **ITEM_PIX 键**（js/icons.js）：`ITEM_PIX.glider = {art: GLIDER_ART, map: {...}}`，
     字符画与色板照 UI spec §5.2 定稿（16×16，展开双翼意象，PO 工单 7cd34ace 拍板）。
- 穿戴使用逻辑零手写：item-use-registry 从 ITEMS armor 判据派生 wear 动作
  （js/item-use-registry.js:48-50）——手持滑翔翼使用=穿上第五槽，与盔甲同管线。

**验收标准**

- [ ] 背包内滑翔翼卡显示像素图标（UI spec §5.4 五处一致走查：背包格/装备页第五槽/
      HUD 条/合成卡/任务卡）。
- [ ] 手持滑翔翼做使用动作=穿上第五槽；装备页点格穿上同效；卸下回背包。
- [ ] 点到物品出介绍话术「穿上它，从高处跳下就会张开翅膀滑翔啦」；全仓无该物品的
      耐久/损坏话术。
- [ ] 三件接线漏一即守门红：item-hint-registry.test（全键⊆ITEMS）、icons-item.test
      （键集=ITEMS）、craft-core.test（配方计数，§3.2）——`npm test` 可证。

### 3.2 合成配方（U-05 图案本 spec 定稿）

**行为定义**

- 材料（R2-01，ADR 0015）：**金锭×4 + 线×2 + 皮革×2**（`gold_ingot` / `string` /
  `leather`，全部 ITEMS 现有表，零新材料）。意象：金=翼骨、线=伞绳、皮革=翼面。
  数量终版**已 PO 确认：线×2（2026-11-15，§8①）**；原始答案线×4 作废（台账留痕
  ADR 0015，两源均在 interview.md），本 spec 全文按线×2 书写，ADR 0015 与 §3.2
  图案不动。
- 站点（R2-02）：**工作台级 3×3**（`station: 'table'`），与盔甲 20 条同口径。
- 产物：`glider`×1。
- **图案（U-05，本 spec 设计定稿）**——UI spec §5.2 图标的 3×3 直译，上下三行读作
  「翼尖骨、中脊鞍、侧膜绳」：

  ```
  行0:  [gold_ingot, null,        gold_ingot]    ← 左右翼骨前缘尖（外扬）
  行1:  [leather,    gold_ingot, leather]       ← 膜面两片 + 中央金脊
  行2:  [string,     gold_ingot, string]        ← 伞绳双系 + 底部金鞍座
  ```

  数据行（照 craft-core RECIPES 条目形状，js/craft-core.js:37-52）：

  ```js
  {id: 'glider', out: {item: 'glider', n: 1}, station: 'table',
    shape: {rows: [['gold_ingot', null, 'gold_ingot'],
                   ['leather', 'gold_ingot', 'leather'],
                   ['string', 'gold_ingot', 'string']]}},
  ```

  设计理由：①左右镜像对称（镜像匹配下自身对称，6 岁怎么摆都不吃亏）；②8 格 8 材
  料，唯一空格在正上方中央（翼上方留白=天空，读图自然）；③与图标 §5.2 逐区对应
  （外扬金弧/中脊/鞍座/膜身/伞绳五要素全保留）；④材料语义站位于「骨头在外、绳子
  在下」符合伞翼实物结构。材料合计 4+2+2=8 与数量拍板严格一致，cost 由 shapeCost
  派生（单一数据源，不另存计费表）。
- **隐藏配方与否：建议公开（不进 KIT_HIDDEN_RECIPES）**。理由（research §4）：
  1. 现状隐藏配方**不参与摆放匹配**（mode-kit.js:916-920 visibleRecipes 过滤
     matchNow）——若滑翔翼配方隐藏而未解锁，孩子摆对材料也合不出来；要隐藏就必须
     新增 advUnlockedRecipes 解锁谓词（现谓词=首收小麦/首杀骷髅/首杀蜘蛛，事件计数
     制），引入新机制。
  2. 任务 q27 的目标是「合成滑翔翼」——配方公开则任务卡与合成卡天然对齐，材料凑齐
     即可合成，与「与盔甲同口径」的拍板精神（R2-02）一致。
  3. 现有 4 条隐藏配方语义是「惊奇彩蛋」（面包/骨粉/弓/大背包）；滑翔翼是任务链
     正式目标+特性主角，不是彩蛋。
  4. 体验馆 hiddenRecipesOpen 全开机制与本建议正交兼容（§3.8）。
  此为 spec 作者建议，PO 可在 §8① 一并复核时推翻；若改隐藏，须同步新增解锁谓词并
  修订任务 hint（本 spec 届时回改）。

**验收标准**

- [ ] 3×3 工作台上按图案可合成出滑翔翼×1，材料扣减正确（金锭 4/线 2/皮革 2）；
      镜像摆放（左右翻转）同样命中。
- [ ] 随身 2×2 摆不出（站点门禁生效）；材料不足时产出槽不亮。
- [ ] craft-core.test 计数 76→77 更新；新增配方过形状防错网与两两不同构检查
      （craft-core.test.js:135 起/:188 起）。
- [ ] 配方卡在合成列表常显（不进 KIT_HIDDEN_RECIPES）；探险缺省策略下不依赖任何
      任务进度即可看见该卡。
- [ ] 合成产出即入合成卡（iconOf 通道免费，UI spec §5.3-4）；首次合成推进任务

### 3.3 装备第五槽（ADR 0013）

**行为定义**

- `EQUIP_SLOTS = ['helmet', 'chestplate', 'leggings', 'boots', 'glider']`——**尾部
  追加**（UI spec §3.1：数组序即 UI 序，盔甲四联阅读群组不破坏，专属槽收尾）。
  `mkWorn` 形状同步扩五键（equipment-core.js:29-31）。
- 专属不互换：`glider` 槽只收 `armor.slot === 'glider'` 的件（wornPut 槽校验机械
  成立）；与四件盔甲**互不排斥**——全身甲+滑翔翼可同穿。
- 穿/脱沿用现有政策链：wornPut / advTryWear / advWornTakeOff / advSyncArmor
  （改写口红线不变，adventure.js:999-1002），不造第二套穿戴流程（ADR 0013）。
- 存档形状：payload 键名仍为 `armor`（adventure.js:353），值为五键 worn 对象
  （`{helmet, chestplate, leggings, boots, glider}`，槽对象 `{id, dur}|null` 不变）；
  encode(:261)/decode=wornNormalize(:276)/defaults(:241) 机械改。
- **老档零迁移**：wornNormalize 缺键补 null（equipment-core.js:134-145），老存档
  读取后 `glider: null`，无迁移脚本、无提示、无感升级。
- 滑翔翼不参与盔甲减伤/击退/韧性合计（pts/tough/kb 全 0，sumArmor 机械零贡献）；
  不参与 wornWear 命中磨损（§5 红线 5 豁免）；装备页第五槽永不渲染耐久条
  （UI spec §4.4）。
- HUD 条/装备页/纸娃娃呈现：UI spec §3/§4 定稿（§4 路标）；盔甲 overlay 不涉第五槽
  （翼走 MobLook 翼骨甲案，非 overlay 拉伸，UI spec §6.1）。

**验收标准**

- [ ] 穿戴滑翔翼后：HUD 条第五槽常驻显示（未滑翔也显示，UI spec §3.2）；装备页
      第五槽在四槽正下方居中独立行；盔甲点数值不因滑翔翼变化。
- [ ] 全身钻甲+滑翔翼同穿成立；卸任一盔甲件不影响滑翔翼槽。
- [ ] 老存档（四键 worn）加载后第五键补 null，五槽界面正常，无报错无迁移日志；
      新档存→读往返后 worn 五键幂等（wornNormalize 幂等性）。
- [ ] research 核实的硬编码四槽守门测试全部更新（equipment-core.test.js:40 /
      mode-kit.test.js:1613 / armor-overlay.test.js:44）+ 全量测试抓出的其余硬编码
      （实测 adventure-mode.test.js:4324 四 null 断言亦必红）——**验收以 npm test
      全绿为准，不以本清单穷举为准**。
- [ ] 手持滑翔翼在第一人称手持视图正常渲染（mkArmorDef 惰性生成，research §5）。

### 3.4 滑翔状态机（核心块，ADR 0016）

**状态与触发总表**（状态权威与物理在引擎层 voxel.js，见 §5 红线 1；此处是行为契约）

| 态 | 进入条件 | 行为 | 退出 |
|---|---|---|---|
| 未装备 | worn 无 glider | 一切滑翔逻辑零参与；坠落按无翼（§3.5 计伤害） | 穿上滑翔翼 |
| 地面态 | onGround | 现状步行/跳跃不变 | 腾空且满足展翼条件→滑翔态 |
| 滑翔态 | 装备 + 离地>2 格 + 未闩锁（**不分跳跃/走落/被击飞，规则一元**） | 垂直=缓降速率匀速下降（高度只减不增）；水平=yaw 转向操控（轻操控）；挖/放/攻击/吃暂停；翼 spread+`wing_open`；HUD 槽金描边呼吸 | 落地→收翼回地面态；触水面→软着陆；按跳跃→主动取消+闩锁；装备页卸翼→立刻收翼按无翼坠落 |
| 闩锁态 | 滑翔中按跳跃（主动取消） | 自动展翼暂停；无翼自由坠落（伤害落差自收翼点重新累计，§3.5）；翼收拢过渡至不可见（v1.2 folding 过渡，无 folded 常驻态）+`wing_close` | 落地/入水→闩锁清除；空中按跳跃→解除闩锁+主动再展翼 |
| 游泳/水中 | 触水面（滑翔或不滑翔） | 现状游泳不变；落差累计清零（水面=安全） | 离水腾空后按上列规则重新判定 |

**行为细则与验收标准**

- **自动展翼（R1-16 + 拍板③）**
  - 行为：装备滑翔翼且未闩锁时，离地高度 >2 格即自动展翼，不分起因（跳跃/走出
    悬崖/被击飞一律）。判定=向下列探脚下地面取离地高度（引擎自实现，§5 红线 2），
    阈值按整格比较；展翼态持有至收翼触发（落地/入水/主动取消/卸翼），落地即收。
  - 自洽性锚：平地跳高 ≈1.42 格（adventure.js:1634）< 2 格阈值——平地跳跃**永不**
    误展翼，只有真高处才有滑翔（阈值设计自洽，回归安全）。
  - 已知接受边界：跨沟跳跃时若沟底离地 >2 格会短暂展翼、落地即收，无副作用——
    规则一元（ADR 0016 选项 A）的自然结果，接受，不做特判。
  - [ ] 从 ≥4 格高台跳下→翼自动展开+`wing_open`+滑翔反馈；直接走出悬崖（未按跳）→
        同样自动展翼；平地连跳 10 次→零误展。
- **只缓降（R1-03）**
  - 行为：滑翔中垂直速度恒为缓降速率（参数表 §3.9 记账值 −0.7 格/秒，2026-11-16
    PO 实飞拍板，同日调参链：−3.0→−1.5→−1.2→−0.7；匀速、慢于自由落体一个量级），高度只减不增，无任何爬升手段。
  - [ ] 滑翔全程画面匀速下降无失重抖动；任意操作（除取消收翼）不能让高度回升。
- **左右转向（R1-02）**
  - 行为：水平操控=现有 yaw 视角控制同源（research §6：摇杆/WASD 同一移动意图
    入口），滑翔中水平速度=操控速度（参数表初值 5.0 格/秒，不享受疾跑）；
    「想去哪飘到哪」对标 BotW。
  - [ ] 滑翔中左右转向跟手，桌面鼠标与触屏摇杆双通道语义一致。
- **落地自动收翼（R1-04）**
  - 行为：触地即收翼（`wing_close`+翼收拢过渡至不可见——UI spec v1.2 §6.4：无
    folded 常驻形态，收拢到位瞬间隐藏），恢复地面移动，零伤害零 TTS。
  - [ ] 任意高度滑翔落地安全；收翼后立即可跑可跳。
- **水面软着陆（R1-05）**
  - 行为：滑翔触水面=收翼+溅水+入水转游泳，零伤害；水上空的展翼判定照常
    （水面上方列探到水底，离水面 >2 格照常展翼，落水即软着陆）。
  - [ ] 从高处滑翔落到湖面/海面→轻溅水入泳，无伤害；入水后落差清零（此后无论
        潜多深上浮都不摔）。
- **主动取消（R2-04）**
  - 行为：滑翔中再点一次**跳跃键**=立即收翼转无翼自由坠落，零新增按钮零新增输入
    通道（ADR 0016）。收翼点即伤害落差起算点（§3.5）——「离地还高就会摔」（R1-06
    同源语义）。
  - [ ] 滑翔中按跳跃→翼立即收起+`wing_close`；此后坠落按无翼计（触地掉血可证）。
- **取消闩锁（R2-03，定稿名「取消闩锁」）**
  - 行为：主动取消后自动展翼**暂停至落地/入水**（消解「取消后被高度条件瞬间重展」
    矛盾）；闩锁期间空中再点跳跃=解除闩锁+主动展翼；落地/入水闩锁无条件清除。
  - [ ] 取消后从更高处经过→不自动重展；空中再点跳跃→再展；落地后跳崖→恢复自动
        展翼（闩锁已清）。
- **滑翔中动作暂停（R1-18）**
  - 行为：挖/放/攻击/吃四类动作在滑翔中无效——不触发、不消耗材料、不掉耐久、无
    半途残留；落地立即恢复。禁列以四项为准，门/开关等站定交互不在禁列（实现
    自由度，验收不绑）。准星保持原位原样（UI spec §8，防「界面消失」不安感）。
  - [ ] 滑翔中对准方块/怪物按挖/放/攻击/吃均无效果且无任何消耗；落地后同操作
        立即生效。
- **滑翔中卸翼（R1-06，ADR 0014 有意设计）**
  - 行为：滑翔中经装备页卸下滑翔翼=立刻收翼，此后按**无翼**坠落（伤害照 §3.5
    结算）。此条是对零惩罚哲学例内的组成部分，**不得当 bug「修掉」**（ADR 0014
    原文）；HUD 槽滑翔中**抑制脱下意图=§8② 已 PO 确认采纳（2026-11-15）**：滑翔中
    点 HUD 槽无效（不报意图、不弹话术，锁槽防误脱），落地解锁；「随时可卸」全语义
    由装备页面板口承担（UI spec §3.2 已同步注记）。
  - [ ] 高空装备页卸翼→立即收翼坠落→落地掉血（或致死走死亡流程）；无卡死、
        无重复音效、无翼残影。
- **全态兜底**
  - [ ] 未装备时：任意模式/任意高度坠落零滑翔参与（无展翼/无金边/无翼显隐/无滑翔
        音效），摔落伤害按 §3.5。
  - [ ] 切模式清场：探险→建造/竞技场后翼显隐对账兜底复位 hidden（v1.2：装备态不
        操纵翼，切模式/读档/死亡重生翼无条件 hidden），滑翔态不跨模式
        渗漏（UI spec §6.4）。
  - [ ] 死亡（含摔死）重生后：滑翔态清零、装备保留、无翼残影。

### 3.5 无翼摔落伤害（ADR 0014，全新机制）

**行为定义**

- 规则形状（ADR 0014 钉死）：落差 **≤3 格无伤；>3 格起每高 1 整格扣 1 血**。
  初始算法 `伤害 = max(0, floor(落差格数) − 3)`（取整方式归 §3.9 实现期可调）。
- **落差计量口径**（本 spec 钉定义，实现据此累计）：
  - 落差 = 「本次**连续无翼下落段**的峰值高度 − 落地点高度」；
  - 展翼滑翔段**不计入**：展翼瞬间落差累计重置（峰值=当前高度）——滑翔本身安全，
    收翼后的自由落体才危险；
  - 主动取消/滑翔中卸翼/闩锁态坠落：自收翼点重新累计（滑到 5 格高取消→摔 5 格
    的账，不追诉滑翔前起点）；
  - 入水清零（滑翔软着陆与无翼落水都不摔，research §1：现状 splash 即 vy 清零，
    同点清累计）；
  - 平地跳跃（峰值落差 1.42 格）恒无伤。
- **结算漏斗**：摔落伤害是**环境伤**（现状四事件外新增，research §1），走现有
  环境伤漏斗 `advEnvHurt`（adventure.js:977-986，原值直扣**不经盔甲折减**，与 D8
  环境伤口径一致）；血尽走 `advPlayerDied` 现有流程——'home' 切图回出生点满血 /
  体验馆 'inPlace' 原地满血，死亡零惩罚不掉装备。
- **事件缝实现约束（research §9 风险，必读）**：现状引擎无 land/fall 事件；
  落地速度存在可读窗口但仅限 voxel.js:359-367 引擎内部（`onGround=true` 与
  `vel.y=0` 之间），主循环模式层 update 在物理之后，**事后读 pos/vel 拿不到落地
  瞬间**。实现必须：引擎物理步内置位落地事实（照 `worldEvents` 的 voidFall/splash
  先例新增 land 类事件，main.js:388-391 分发先例），携带本次落差与触地时滑翔态；
  引擎只报事实（落差/是否滑翔），**扣血结算归探险模式层**（引擎不知道 HP）。
- 仅探险模式（建造/竞技场无 HP 不涉，ADR 0014）。
- **零 TTS**（R1-09/ADR 0014）：着地安抚、高处预警一律不配；与工具破碎安抚惯例
  不同属有意例外，「不得补齐话术」式回改被 ADR 0014 明文禁止。
- 虚空坠落现状语义不变（voidY 直达 voidFall 回出生点，不与本机制叠加）。

**验收标准**

- [ ] 无翼跳 3 格高台：无伤；跳 5 格：扣 2 血；跳 10 格：扣 7 血（参数表初值口径，
      自动化测试按参数表断言）。
- [ ] 摔至血尽：走现有死亡流程（回家重生满血/体验馆原地满血），装备背包全保留；
      全程无任何 TTS 语音。
- [ ] 滑翔落地/水面入水：零伤害（滑翔段不计落差可证：20 格高滑翔到 2 格取消→
      只摔 2 格账→无伤）。
- [ ] 被怪物击退上天后落地：按击飞高度计伤害（规则一元）。
- [ ] 落水（无论有无翼、无论高度）：零伤害。
- [ ] 建造/竞技场模式高处落地：无任何伤害逻辑参与。

### 3.6 相机（U-01，决策规则已钉，两路径验收齐备）

**决策规则（interview U-01，不变）**：实现侧评估代价——自动第三人称代价不高→

**路径 A：自动第三人称（优先，R1-15）**

        完整入画。
  - [ ] 落地收翼→视角自动回到滑翔前的设置（第一人称进→第一人称出，第三人称进→

**路径 B：第一人称退化（R2-07 生效时）**

  匀速过渡，与翼展开同拍起），落地收翼恢复原值；**准星保持常显不变**（原位原样，
  无作业语义但防「界面消失」不安感）；除 FOV 外不加暗角/滤镜/震屏/色偏（惊悚面

- 验收标准：
  - [ ] 滑翔全程第一人称；FOV 有可感但不惊悚的微扩，落地恢复原值。
  - [ ] 准星全程原位原样；无暗角/滤镜/震屏/色偏。
  - [ ] 滑翔中 HUD 第五槽金边呼吸正常生效（退化方案下的状态信号，UI spec §3.3

### 4.2 UI 与玩法的接缝（实现注意，非视觉面）

- **翼显隐接口**：滑翔态（hidden↔spread）走模式层意图接口（UI spec §6.4 v1.2 建议形
  `Avatar.setWings('hidden'|'spread')`——目标态声明，0.25s 过渡插值是形象层内部
  动作，参照 `Avatar.flash` 先例）——滑翔是玩法状态，形象层零玩法知识，状态判断
  归探险模式层；**接口命名归实现线**（UI spec §9.2-3），spec 只锁语义：翼可见性
  唯一驱动=滑翔状态沿，**装备态不操纵翼**（v1.2：Avatar.setArmor 不消费
  worn.glider，切模式/读档/死亡重生对账兜底=无条件 hidden），滑翔态切换由模式层
  在展翼/收翼时机调用；纸娃娃不经意图接口（paint(worn) 直读，v1.2 起纸娃娃任何
  状态不显示翼）。
  验收红线照抄 UI spec §6.4（v1.2 扩写）：**任意模式、任意读档顺序、任意装备状态
  下，非滑翔时刻的人物身上永不出现翼**。
- **滑翔态信号源**：金描边呼吸（UI spec §3.3）沿触发 class 切换、无逐帧重画——
  滑翔态是独立状态位，不进 mkArmorBar 的 id 签名；模式层在状态机迁移点（展翼/
  收翼）广播，验收=描边与滑翔状态严格一致、零闪烁抖动。
- **音效触发点**（UI spec §7.1）：`wing_open`=展翼瞬间（自动展与主动再展同点）；
  `wing_close`=收翼瞬间（落地自动收/软着陆/主动取消/滑翔中卸翼四触发同点）；
  `coolMs: 300` 防 R2-04 空中快速连点叠爆。

## 5. 实现红线（research + UI spec §9.1 汇总，违反即红）

1. **滑翔物理必须进引擎层 voxel.js**（步行分支重力段旁的新分支，flyMode 先例
   voxel.js:264-270）；模式文件禁直写玩家六绑定（pos/vel/onGround/yaw/pitch/
   flyMode，conventions.test.js:131-148 只扫 js/modes/）——滑翔态旗标与物理参数
   写进 adventure.js 会直接红测试。模式层读写滑翔态经引擎意图 API（先例
   `setFly`）；新增顶层绑定（如滑翔旗标）登记进 voxel.js 玩家段头注释白名单
   （唯一权威），并按 conventions §1.10 升格判据评估纳入守门正则（与 flyMode
   同待遇）。
2. **引擎不得依赖应用模块**：离地列探不得引 mobs.js 的 `groundUnderAt`
   （voxel.js 现状不引用 mobs，反向依赖违反分层硬规则）——引擎内自实现向下列探
   （raycastVoxel/列扫，research §2）或将公共件上移引擎层，归实现线裁决。
3. **滑翔翼物品注册进 ITEMS 不能下线**：wornNormalize 静默丢弃 ITEMS 未注册 id
   的穿戴件（equipment-core.js:139-141）——将来下线=玩家档内滑翔翼无提示消失
   （research §3 迁移语义警示）。三件接线（ITEMS/ITEM_HINTS/ITEM_PIX）漏一即
   守门红。
4. **EQUIP_SLOTS 第五槽连锁**：mkWorn 形状同改；research 核实硬编码四槽守门
   3 处（equipment-core.test.js:40 / mode-kit.test.js:1613 / armor-overlay.test.js:44）
   + 配方计数 76→77（craft-core.test.js:99-105）+ 本 spec 实测补充
   （adventure-mode.test.js:4324 四 null 断言）——**守门测试同步改，验收以
   npm test 全绿为准**。
5. **wornWear 耐久豁免（本 spec 新发现的实现陷阱，ADR 0012 红线的落地点）**：
   `wornWear`（equipment-core.js:83-101）遍历**全槽**扣耐久——滑翔翼进槽表后，
   战斗命中会磨损它直至清槽，直接违反 ADR 0012「任何代码路径不得扣减滑翔翼耐久」。
   必须豁免（判据旗标或槽名特判，归实现线）；**验收：任意次战斗命中后
   `worn.glider.dur` 恒不变、第五槽永不因磨损清槽**。
6. **ItemHint 键集守门**：话术行进 item-hint-registry（item-hint-registry.test

7. **音频「永不哑」互锁**：`wing_open`/`wing_close` 进 SFX_KINDS 各一行

8. **装备条样式补齐（§3.4 存量 wart，PO 已裁随票，2026-11-15）**：按 UI spec §3.4

## 6. 术语表（spec 内钉死概念定义；GLOSSARY.md 词条正文含实现细节，待实现完工后由实现线补）

- **滑翔翼（glider）**：探险模式专属装备道具；装备栏专属第五槽，无消耗永久使用；
  离地 >2 格自动展开，只缓降不爬升，左右转向，落地安全。物品 id = 槽键 = 存档
  第五键，同名 `glider`。
- **滑翔状态（滑翔中）**：已装备滑翔翼且翼已展开的空中运动态——垂直恒速缓降、
  水平视角转向操控、挖/放/攻击/吃暂停；是 HUD 金描边、翼 spread 形态、滑翔音效的
  共同信号源。
- **展翼**：进入滑翔状态的瞬间动作。自动触发=离地 >2 格（不分起因）；主动触发=
  闩锁态空中再点跳跃。伴随翼 spread 形态与 `wing_open` 音效。
- **收翼**：退出滑翔状态的瞬间动作。触发=落地自动收/水面软着陆/主动取消/滑翔中
  卸翼。伴随 `wing_close` 音效与收翼动画：翼由展平收拢过渡至**不可见**（UI spec
  v1.2 §6.4——folded 仅为 0.25s 过渡的起止姿态，非静止形态；收拢到位瞬间翼隐藏，
  无残影帧）。
- **取消闩锁（定稿名；访谈候选「收翼锁」弃用）**：主动取消滑翔后，自动展翼暂停
  至落地/入水的机制；空中主动再展=解除；落地/入水无条件清除（R2-03）。
- **软着陆**：滑翔触水面即收翼、安全入水转游泳的交互（R1-05）；无翼落水同样
  不摔（落差清零）。
- **无翼高坠（摔落伤害）**：未处于滑翔状态的高处落地扣血——落差 ≤3 格无伤，
  4 格起每高 1 格扣 1 血，血尽走现有死亡流程；零 TTS。对零惩罚哲学的唯一显式
  例外（ADR 0014），例外只覆盖「高坠」一条。
- **落差**：摔落伤害的计量——本次连续无翼下落段峰值到落地点的高度差；展翼滑翔段
  不计入，入水清零。
