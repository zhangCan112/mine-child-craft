# ADR 0018 · 篝火生命周期:自然燃尽消耗品

日期:2026-11-16 · 状态:已采纳(PO 立项拍板② + grill 访谈轮次 1 Q4/Q5/Q6/Q7/Q8/Q14 钉定)

## Context

PO 立项三拍板之二:「自然燃尽的消耗品(不照抄 BotW 永久营火)」。MC 正典篝火与
BotW 营火均为永久燃烧;本项目走消耗品路线——合成→放置燃烧→燃尽→再合成的小
经济循环。生命周期全链由 grill 访谈磨定(2026-11-16,`.scratch/campfire/interview.md`)。

## Considered Options

- **燃尽终局**:
  - **A. 干净消失,无掉落(采纳,PO 拍板)**:烧完火就没了,地面干净。
  - B. 消失+原地掉 1 木炭「柴烧成炭」(否决:PO 显式选干净消失——business-analyst
    推荐案被否,理由「不需要补偿,烧完就没」)。
  - C. 留灰烬/熄灭方块残渣(否决:还要再定清扫交互,复杂)。
- **浇熄终局**(水流接触燃烧中篝火):
  - **A. 立即熄灭,留「熄灭的篝火」方块,点击重新点燃并重置时长(采纳)**:教会
    「水灭火」的自然因果;篝火本体不损失;点击切换交互与门开关(tryDoorToggle)
    同先例。
  - B. 直接消失不留方块(否决:与燃尽混淆成两种「没了」,孩子无法区分「被浇灭」
    与「烧完了」)。
  - C. 浇不灭(否决:反直觉)。
- **燃烧中挖掘**:掉篝火道具本身(采纳,照本项目方块破坏惯例可回收——放错地方
  拿回来重放;MC 正典「挖燃烧中篝火掉木炭」不采纳,儿童友好优先)。

## Consequences

- 生命周期状态机(全链):篝火物品 → 放置**即燃**(零点燃步骤——本项目无打火石
  道具,6 岁少一步是一步) → 燃烧中(方块光 light 15 量级/烟/热气柱/烫人) →
  两种终局:
  - **燃尽**(约 5 分钟量级,灯笼 dur=300s 先例同档;具体秒数实现期调参不判需求
    变更,同 glider-spec §3.9 口径):方块消失,无掉落。
  - **浇熄**(水流入/流过):转熄灭态方块——不发光、不冒烟、不产气流、不烫、
    计时停止;点击熄灭态=重新点燃,重置为满时长。
- 熄灭态挖掘=掉篝火道具(与燃烧态一致);熄灭态可长期保留(直到挖走或重燃)。
- **随档恢复**:燃烧中篝火存档退出重进=继续烧剩余时间(熔炉 furnaces 键先例,
    世界档 payload 新增篝火账键承载,档键形状归 spec 技术裁定);体验馆照 dev
    store 惯例只活当次进场。
- 合成产量 2(一发多给一个)是消耗品路线的直接补偿;配方材料照 MC 正典
  (木棍×3+原木×3+煤炭或木炭×1,工作台 3×3)。
- 「重置时长」语义钉死:重燃=满时长重烧,不继承熄灭前余量(简单、孩子可预期;
    若要继承余量需回 PO 重拍)。
