# ADR 0014 · 无翼高坠摔落伤害:对零惩罚哲学的一次显式例外

日期:2026-11-15 · 状态:已采纳(滑翔翼特性立项拍板⑤;伤害规则访谈轮次 1 钉定)

## Context

MISSION 反馈哲学是「零惩罚」;探险现状**没有**摔落伤害(只有虚空坠落回出生点/溺水/岩浆/溅水
四事件,researcher 2026-11-15 核实)。滑翔翼特性立项时 PO 显式拍板:不带滑翔翼从很高处跳下
必须有摔落伤害——**这是对零惩罚哲学一次有意的、记录在案的例外**。PO 取舍理由
(2026-11-15 访谈原文):**培养安全意识,让孩子理解「高→摔」的因果**。滑翔翼正是该因果的
安全出口——穿翼滑翔落地永远安全,风险与工具并存,因果闭合。

## Considered Options

- **A. 扣血制·对齐 MC 折算(采纳)**:约 3 格内无伤,4 格起每高 1 格扣 1 血;血尽走
  **现有**死亡流程(回家重生、装备不丢——死亡本身已零惩罚)。
- **B. 不扣血直接送回家(否决)**:强制传送比扣血更打断玩耍心流,且掩盖「高→摔」因果。
- **C. 扣血但永不致死(否决)**:与现有死亡流程造出第二套「血量见底」语义,规则分裂。
- **D. 无伤害(否决)**:违反 PO 拍板;滑翔翼的价值失去锚点。

## Consequences

- 摔落伤害是**新环境伤害事件**(现状四事件外新增),仅探险模式(建造/竞技场无 HP 不涉;
  滑翔翼本身亦仅探险,interview R1-01)。
- 滑翔状态落地、水面软着陆永不触发;**滑翔中主动卸翼=立刻收翼按无翼坠落处理,属有意设计**
  (interview R1-06),不得当 bug「修掉」。
- **不配着地安抚 TTS、不配高处预警 TTS**(PO 2026-11-15 显式选择「保持安静」;与工具破碎
  有安抚话术的既有惯例不同——此处是例外,不得「补齐话术」式回改)。
- 例外只覆盖「高坠」一条;零惩罚哲学其余面(死亡不掉装备、过程性表扬、无倒计时压迫)不变。
  将来任何「调狠/调没」都需回到 PO 拍板。
- 数值(阈值精确格数/每格扣量)实现期可微调,规则形状以本 ADR 为准。
