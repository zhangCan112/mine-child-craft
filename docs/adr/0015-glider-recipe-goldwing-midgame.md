# ADR 0015 · 滑翔翼配方甲案:金锭×4 + 线×2 + 皮革×2,工作台级——「中期可得重要过绝对贵重」

日期:2026-11-15 · 状态:已采纳(访谈 R2-01 拍板 + 2026-11-15 PO 单独复核确认)

## Context

特性立项拍板①要求「材料贵重且组成合理」;访谈轮次 1 R1-11 PO 定档「金/铁之间,中期可得」
(对「贵重」的落位=中期经济里的贵重)。researcher 2026-11-15 核实现有贵重材料链完整
(铁锭/金锭/钻石/下界合金/皮革/线/末影珍珠)。访谈轮次 2 给出三候选,PO 选甲案并经单独复核
再次确认,复核原话理由:**「中期可得重要过绝对贵重」**(与 R1-11 同源,互相引用)。

## Considered Options

- **A. 甲案·金骨绸翼:金锭×4 + 线×2 + 皮革×2,工作台级(采纳)**:金=翼骨、线=伞绳、
  皮革=翼面,意象直观;金色观感讨喜;线/皮革是蜘蛛/牛的中期副产品,零新增刷料苦工;
  与 R1-11 档位自洽。
- **B. 乙案·铁骨滑翔翼:铁锭×6 + 线×4 + 皮革×4(否决)**:铁锭用量大,中期采集压力
  偏向刷料苦工,6 岁不友好。
- **C. 丙案·珍珠浮翼:金锭×4 + 线×4 + 末影珍珠×1(否决)**:末影珍珠要打末影人,
  获取晚于「中期可得」档位;飞行意象留待将来(皮肤/改名类活动)再用。

## Consequences

- 配方走**工作台级 3×3**(与盔甲 20 条同口径,贵重件仪式感);图案形状归 spec
  (贴合伞/翼意象即可)。
- 材料全部在 ITEMS 现有表,**零新材料引入**。
- **台账偏差备案**:relay 工单 0f0002b4 原始答案为「线×4」,2026-11-15 PO 单独复核定稿
  「线×2」,以复核为准(最新 PO 意思表示优先;两源均在 .scratch/glider/interview.md 留痕)。
- 改配方本身是数据行改动、可逆;但「中期可得 > 绝对贵重」的档位原则是配方演进的约束,
  动配方先对照 R1-11/本 ADR。
