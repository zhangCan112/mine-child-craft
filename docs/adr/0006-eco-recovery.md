# ADR 0006 · 生态恢复机制：繁育续场 + 树位分钟级再生 + 矿位跨天回填（世界档 v2）

日期：2026-10-28 · 状态：已采纳（docs/eco-recovery-design.md；调研依据 docs/minecraft-eco-recovery-research.md）

## Context

探险模式资源只出不进：树砍了永久消失（唯一恢复路 = 孩子手动种树苗）、矿挖了永不回填、
牧场死一只少一只（F4 拍板「不重生=保护动物教育」）。用户要求资源缓慢恢复且绝不波及
已建建筑。MC 正典调研（2026-10-28）确认：正典树/矿均**无**自主再生（安全靠「位置白名单
+ 拒绝式生长」两层不变量保证），动物恢复主通道 = **繁殖**（5 分钟冷却、幼崽 20 分钟成年）。

用户拍板：① 动物走繁育续场（幼崽持续出现→慢慢长大→长大前免伤），树木同理；② 树分钟级
当次可见、矿跨天回填；③ 矿位回填全覆盖。

## Considered Options

**A. 繁育模型 + 位置账本恢复（采纳）**
动物 = MC 繁育模型照抄（自动触发：同种成年邻近 + 冷却 + 上限双闸门）；树/矿恢复 =
只认**位置账本**（树位复用 `advTreeSpots` 确定性清单；矿位建场期收口记录），执行前
拒绝式预检，被玩家建筑占用即放弃/销账——建筑天然在账本之外，机制上不可能被恢复覆盖。
优点：与 MC 安全不变量同构；存档增量最小（繁育清单 + 开采日期账）。
代价：世界档 v2（见下）。

**B. 凭空重生（否决）**
定时把动物/树/矿补回原位。与既有 F4「不重生」拍板正面相撞，且「保护动物」教育语义丢失；
矿位若不记账本就得全图扫描，违反位置白名单不变量。

**C. 全局随机刻层（否决）**
移植 MC 随机刻底座驱动一切恢复。违反既有「随机刻不移植」决策（block-lifecycle：确定性
重放红线 + 儿童即时反馈哲学）；恢复只是它的第三个消费者，升格判据不过。

## Consequences

- **世界档 v2（不可逆点：落档即前向兼容承诺，回退需迁移）**：
  `livestock` 桶从索引数组升级 `{dead, bred:[{k,b}]}`（三代档形解码归一，老档零动作可玩）；
  新键 `oreRegen`（`<场景键>:x,y,z` → 日期串，缺省 `{}`）。
- 「F4 动物不重生」拍板**不推翻**而是收窄口径：凭空重生仍然不做，恢复改走繁育通道
  （MC 同款）；GLOSSARY 牧场条 `_Avoid_` 措辞随此修订。
- 树/矿自主恢复为对正典的刻意扩展（差异登记见设计稿附录 B）；恢复语义必须保持
  「位置账本 + 拒绝式预检」两不变量，后续任何资源类型接入（如果树/农田）同走此缝。
- 幼崽免伤为永久偏差（正典幼崽可被伤害），零惩罚哲学优先。
