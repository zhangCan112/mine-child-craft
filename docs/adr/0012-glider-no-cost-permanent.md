# ADR 0012 · 滑翔翼无消耗:不设耐久、不设单次时长/体力上限

日期:2026-11-15 · 状态:已采纳(滑翔翼特性立项拍板④;访谈轮次复核维持)

## Context

装备系统既有口径是「耐久 ≈ MC×2、归零破碎消失」(工具/盔甲,docs/equipment-design.md D9)——
给新装备顺手配耐久是本仓惯例路径。滑翔翼特性立项时 PO 显式拍板:滑翔翼**无消耗、永久使用**,
并**明确否决耐久方案与单次时长上限方案**(interview R1/A14 一致口径:滑翔全程安静,无损耗话术)。

## Considered Options

- **A. 无消耗永久(采纳)**:滑翔是本特性的快乐核心(验收锚:「体验到飞翔的感觉和快乐」),
  不是资源管理课;滑翔中耐久耗尽=空中强制中断+摔落,会与摔落伤害(ADR 0014)叠加成双重惩罚,
  与零惩罚哲学的体感冲突最大。
- **B. 耐久制(否决,PO 明确)**:空中「翼碎了」的惩罚烈度远超工具归零消失的静态损失,
  且滑翔中断直接触发坠落伤害链。
- **C. 单次时长上限(否决,PO 明确)**:单次滑翔 N 秒强制收翼,同样是空中强制中断。
- **D. 体力条(BotW 式)(否决)**:引入全新资源条系统,超出本特性范围。

## Consequences

- 滑翔翼是装备系统第一个「耐久不参与玩法」的穿戴件;条目形状(dur 给满值永不扣 vs 新形状)
  归 spec,**红线:任何代码路径不得扣减滑翔翼耐久**。
- ItemHint/话术不得出现耐久/损坏暗示;「翼坏了」不存在。
- 将来若引入消耗,属新特性需求变更(PO 拍板权),不是缺陷修复。
