# ADR 0008: 专注训练营升格第六维度（视觉搜索），接受存量进度关卡重排

日期：2026-10-29 · 状态：已采纳

## 背景

专注训练营为五维范式 100 关螺旋（CPT/GoNoGo/Flanker/Corsi/Switch）。2026-10-29 一手调研
（[focus-interaction-research.md](../focus-interaction-research.md) §A1）确认：对 6 岁有强证据、
与现有五维构念重叠低的最佳新增范式是**视觉划消/搜索**（TEA-Ch2 J 5-7 岁常模子测验 Balloon Hunt 系）。
接入形态二选一：附加训练块（如魔鬼特训式的独立入口，零进度影响）或升格第六维度（进 100 关螺旋，
与五维同等地位、交错练习）。

## 决策

1. **升格第六维度**：`FOCUS_DIMS` 追加 `search`，教学关 5→6，螺旋 `k%6`，大师关六节，
   体检/魔鬼特训/任务单/进步页/家长面板随 FOCUS_DIMS 自动扩展。
2. **接受重排**：编排从五维变六维必然重排 unlocked 之后的关卡内容与 stars 按关卡号的历史归维
   展示。接受理由：①tier 公式 `min(19, 2+⌊k/5⌋)` 与通过门槛/三星全部不动，孩子在同一档位带内
   连续推进，mkAdapt 阶梯与挫败阀兜住体验；②换新游戏对 6 岁是正性事件（调研 B4：EndeavorRx
   「没有通关、难度恒定在个人挑战带」同构）；③交错练习的科学编排价值（间隔+交错，Cepeda 2006 /
   Klimovich 2025）要求新范式进螺旋而非旁挂。
3. 挡回的替代方案：附加块形态保留为**未来新范式的低风险入口**（如听观数狗叫 P1 候选可先走附加块
   观察兴趣，再评估升格——届时另立 ADR）。

## 后果

- 正面：第六维与五维同等地位；大师考验/体检/魔鬼特训全覆盖；掉落/图章/里程碑体系零新增成本。
- 代价：孩子（当前 unlocked≈L54）后续关卡序列变化，家长面板历史趋势中按关卡号归维的统计有
  装饰性漂移（按维度聚合的正确率/反应时仍是同构念连续数据）。
- 不可逆性：中——编排公式回退会二次重排；接受后不再为「恢复旧序列」回退（无回退价值）。
