# ADR 0017 · 篝火乘热气流:对滑翔「只缓降」契约的显式例外

日期:2026-11-16 · 状态:已采纳(篝火特性 grill 访谈轮次 1 Q9/Q10 拍板)

## Context

滑翔翼契约(ADR 0016 / glider-spec §3.4)钉死:滑翔态「垂直=缓降速率匀速下降,
高度只减不增,无任何爬升手段」。篝火特性立项(机制源自 BotW 上升气流)的核心意图
是:篝火产生向上热气流柱,玩家乘滑翔翼可被托升——与「无任何爬升手段」直接冲突。

PO 访谈拍板(2026-11-16,`.scratch/campfire/interview.md` Q9/Q10):气流只认装备了
滑翔翼的玩家(风托的是翼不是人);篝火正上方气柱内**跳跃=立即展翼起飞**(柱内展翼
门槛从「离地>2 格」豁免为「离地即展」——站篝火旁一跳就升空,一步起飞,路过篝火
不会被动吸上天);气柱量级**高约 20 格、宽 3×3**(能上山头,飞得更爽——PO 主动
改推荐,原推荐 12 格)。

## Considered Options

- **A. 气流柱=契约例外区(采纳)**:柱内滑翔垂直速度可为正(托升);柱内展翼门槛
  豁免为「离地即展」(跳跃即起飞);柱外一切照旧(离地>2 格展翼、只缓降)。
  例外边界窄,单一判据=玩家是否处于活跃气流柱水平范围内。
- **B. 严格 BotW:气流只作用于已在滑翔态的玩家(否决)**:孩子必须先找/搭一个
  ≥3 格高台跳下滑翔、飘进气柱才被托升——PO 理由:6 岁门槛太高,篝火定位是
  「家门口起飞器」,少一步是一步。
- **C. 不做乘流(否决)**:砍掉特性核心意图,立项不成立。
- **D. 装备翼入柱即自动吸升(否决)**:零步操作,但路过篝火会突然上天,容易吓到
  孩子/打扰步行——被动改变玩家状态与「规则一元不打扰」的既有手感相悖。

## Consequences

- ADR 0016「无任何爬升手段」由本 ADR 显式修订为「**气流柱外**无任何爬升手段」;
  乘热气流上升是滑翔翼唯一爬升手段,本期唯一气流源=燃烧中的篝火。
- 「只缓降」契约其余面(匀速缓降/左右转向/落地自动收翼/取消闩锁/水面软着陆/
  滑翔中动作暂停)在柱内柱外**全部照旧适用**——例外只开「垂直速度可为正」与
  「柱内展翼门槛」两点,不得外溢。
- 无滑翔翼玩家完全不受气流影响;怪物/掉落物本期均不受气流影响(风托的是翼)。
- 踩着篝火方块本身起跳同样起飞(气柱 3×3 含篝火格);「踩火起飞不被烫」由
  ADR 0019 伤害节拍天然成立,不另设特判。
- 热气流必须做成**引擎层可复用机制**(PO 点名的 spec 硬约束,参照 fluid-core
  先例:引擎不知玩法、纯核心+同名单测、明确时钟语义)——「气流场」与「篝火」
  解耦,未来其他气流源(风柱/喷泉等)复用同一机制,不写死篝火。
- 气柱数值(高度 20 格/宽 3×3/上升速度)进参数表,实现期调参不判需求变更
  (同 glider-spec §3.9 口径);气柱遇实体方块遮挡的截断语义归 spec 技术裁定。
