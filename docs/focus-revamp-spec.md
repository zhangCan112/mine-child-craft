## Problem Statement

专注训练营上线后久未更新，6 岁的真实玩家（已玩 12 天 72 局、解锁第 54 关）遇到了两头别扭的
体验：一半游戏（苦力怕排队、听指挥的小矿工）通过率 100%，碾压到没有挑战、拿三星如探囊取物；
另一半游戏（挖矿小能手、钻石闪闪光）在难度台阶处反复撞墙（单关六连败），一天的 6 关额度被
同一关烧掉 4 关。家长视角则是：游戏观感两年没变、没有让孩子"明天还想来"的长线动力，
也缺少参照成熟作品（任天堂《脑锻炼》系列）验证过的习惯结构。同时，新一期完成的物品与
合成系统（像素图标/背包/掉落物）的素材完全没有被训练玩法利用。

## Solution

训练营 2.0 四位一体升级：

1. **数据驱动的难度再平衡**——简单维度提顶（更长队伍、双价干扰、更多选项），困难维度的
   qualitative 跳变全部改成渐进混编（台阶变坡道），整体更难且不再有烧额度的墙；
2. **脑锻炼结构层**——图章打卡日历、训练师村长主持人格、每日体检（探险家火苗）、集章解锁、
   魔鬼特训（参照《5 分钟鬼训练》的 5 分钟硬顶/逐日锁定/85-66 双阈鬼等级，但不引入 n-back）；
3. **战利品收集回路**——答对赚像素物品、飞入矿袋、进全游戏唯一共享背包、宝物柜收集展示、
   里程碑工具授予（木→钻的长线追求）；
4. **观感升级**——训练场矿洞化贴图皮肤、MC 立体按钮、战利品飞行与爆星动效。

科学口径不动：五维范式、通过门槛、三星规则、每日预算、家长面板 CSV 与免责声明全部保持。

## User Stories

**作为 6 岁玩家：**

1. As a 6 岁玩家, I want 苦力怕排队在高关卡变难（队伍最长 9 只、捣蛋鬼占 65%、还有中立行和
   混入的其他生物）, so that 我通关时觉得"真厉害"而不是无聊碾压。
2. As a 6 岁玩家, I want 听指挥的小矿工在高关卡出现第五个方块、旗子换成不打招呼就变、干扰项
   和目标一样大, so that 我必须真的盯住规则而不是靠旁边的线索偷懒。
3. As a 6 岁玩家, I want 假钻石第一次出现时只有少量、之后慢慢变多, so that 我不会突然卡死在
   同一关想哭。
4. As a 6 岁玩家, I want 要记 4 个钻石的关卡里混着一些只记 3 个的轮次, so that 台阶变成我能
   爬上去的坡道。
5. As a 6 岁玩家, I want 最高难度的钻石闪闪光会在我取巧记位置组合时换格子布局, so that 通关
   靠真本事。
6. As a 6 岁玩家, I want 答对时有小宝物从游戏里飞进我的矿袋, so that 每一次正确都有看得见的
   收获。
7. As a 6 岁玩家, I want 连续答对 3 次保底得到稀有宝物和音乐喝彩, so that 努力保持专注有
   额外的惊喜。
8. As a 6 岁玩家, I want 通关后矿袋打开、战利品列队展示, so that 结算时刻像开宝箱一样开心。
9. As a 6 岁玩家, I want 玩到第 10/30/50/70/90/100 关时获得越来越厉害的镐和剑（最后是钻石
   镐和钻石剑）, so that 我有理由明天再来。
10. As a 6 岁玩家, I want 一个宝物柜看到我收集的所有东西、点一下就有人念它的名字, so that
    我可以炫耀我的收藏（即使我还不会读字）。
11. As a 6 岁玩家, I want 背包满了的时候听到温柔的提示而不是失败, so that 收集永远不让我
    难过。
12. As a 6 岁玩家, I want 教学关没有任何掉落和压力, so that 第一次学新游戏时轻松愉快。
13. As a 6 岁玩家, I want 一位白胡子矿工村长爷爷陪我玩（开场打招呼、给我读规则、为我喝彩）,
    so that 训练营像个有人气的地方而不是一堆题目。
14. As a 6 岁玩家, I want 每天练一关就在日历上盖一个图章、练满 3 关得大图章, so that 我能看见
    自己的坚持。
15. As a 6 岁玩家, I want 哪天没来玩也不会有任何红叉或"断签"惩罚, so that 偶尔休息不焦虑。
16. As a 6 岁玩家, I want 集章能换图章图案、矿袋皮肤和烟花彩蛋, so that 打卡有漂亮的小奖励
    （而且永远不会锁住游戏内容）。
17. As a 6 岁玩家, I want 每天能玩一次 90 秒的"今日体检"看到我的探险家火苗, so that 我有
    一个属于自己的、简单好玩的状态仪式。
18. As a 6 岁玩家, I want 火苗只和我自己以前比、变亮时村长为我欢呼, so that 我永远不会被
    拿去和别人或某个标准比较。
19. As a 6 岁玩家, I want 每天一次 5 分钟的魔鬼特训（鬼村长上岗、维度每天换）, so that 我能
    挑战"更凶但更爽"的高难度。
20. As a 6 岁玩家, I want 魔鬼特训有鬼等级 1~10、答得好就升级, so that 我能追求一个明确的
    强度记录。
21. As a 6 岁玩家, I want 魔鬼特训输了也不重置、不扣任何东西, so that 再难的挑战也不吓人。
22. As a 6 岁玩家, I want 训练场看起来像真正的矿洞、按钮是立体的、进度条上有镐子游标,
    so that 训练营和游戏的其他模式一样精致。
23. As a 6 岁玩家, I want 干扰矿和宝物用新的像素图标（铁锭金锭、火把、骨头）, so that 游戏
    更好看也更像真正的我的世界。
24. As a 6 岁玩家, I want 更新后我的进度、星星和背包都还在、已经该拿的工具自动补给我, so
    that 更新不惩罚老玩家。

**作为家长：**

25. As a 家长, I want 每天 6 关/20 分钟的硬顶不被任何新内容突破（体检计入时长、魔鬼特训计
    2 关额度）, so that 防沉迷承诺依然可信。
26. As a 家长, I want 家长面板的口径、CSV 列和免责声明保持不变, so that 我的历史记录和工具
    不被打断。
27. As a 家长, I want 孩子不再把每日额度烧在撞墙上（困难维度通过率进入 70~90% 带、简单维度
    正确率降到 80~90% 带）, so that 每天的训练时间花在刀刃上。
28. As a 家长, I want 游戏里不出现"专注年龄/智商分"之类标签化数字, so that 孩子不会被伪科学
    评分伤害。
29. As a 家长, I want 孩子玩的范式都有儿童文献支撑、没有 n-back 这类低龄无验证内容, so that
    训练宣称与实际一致。

**作为实现代理/维护者：**

30. As a 实现代理, I want 每张工单有明确交付物与测试验收清单, so that 我认领即可开工、
    全绿即可交付。
31. As a 维护者, I want "qualitative 难度跳变必须渐进混编"被回归测试锁死, so that 未来任何人
    改参数表都不会把坡道改回台阶。
32. As a 训练营实现者, I want 直接复用既有共享背包薄壳与其单测缝（授予流走背包核心纯
    函数），so that 接入零迁移、不叠第二层包装。

## Implementation Decisions

**难度再平衡（设计稿 §2 D1~D5 为数值权威）：**

1. 100 关螺旋编排公式、通过门槛（70% 正确 + 警觉/抑制另需 60% 命中率）、三星规则全部不动；
   "难一点"只由关卡参数曲线承载。
2. 曲线改造总原则：一切 qualitative 变化（伪装/长度/格阵/规则元素）以概率渐进混入而非
   一步全量；时间类参数仍交给既有阶梯自适应（mkAdapt）做关内微调。
3. 警觉维度基本不动（真实数据显示校准恰好）；抑制维度新增伪装率参数（30%→60%→90%→100%
   渐入，替代原 tier8 一步全量）；干扰维度提顶（队伍 3/5/7/9 阶梯、不一致占比下探 35%、
   新增中立行与混入生物）；视空记忆维度新增长度混编（过渡档 50% 出上一档长度）与反组块
   参数（顶格按概率打乱格位，4×4 格阵推迟与长度跳档脱钩）；规则切换维度新增双价干扰
   （无关维度线索失效）、第 5 选项与切换点抖动。规则数量封顶 3（6 岁文献上限）。
4. 干扰物/宝石/材质族刺激换用物品系统像素图标（iconOf 统一出口）；羊毛沿用训练营自有
   图标管线（物品注册表无羊毛，补画留二期）。

**引擎与分层：**

5. 范式引擎新增可选的逐试次事件回调（引擎只报"对/错/连对/维度"，不知道奖励与背包存在）；
   既有调用方不传回调零影响。
6. 对接既有共享背包薄壳（Backpack，code-review 轮 S6 已装配并配单测）：存档键唯一持有、
   load 原地换槽、save 落账；授予流 = 背包核心纯函数直接作用于背包本体再加 save，**不在
   壳上叠包装方法**；宝物柜渲染归训练营模式层。未来任何模式（建造/下界）接入都经此壳，
   不得自开存档键（ADR 0002；探险模式已为第一个消费方，训练营为第二个）。训练营只产出
   不消耗：不接配方/耐久/挖掘/放置。

**战利品回路（设计稿 §3 为数值权威）：**

7. 掉落政策归训练营模式层：正确试次按概率掷骰（教学关除外）、3 连对保底稀有池、通关与
   三星有追加；掉落表按维度主题化、以基础材料为主（为未来探险经济留余量）。
8. 产出上限天然封顶：每日预算 6 关 + 线性推进无选关重打；战利品只增不减（零惩罚）；
   满包静默忽略 + 每关至多一次提示。
9. 里程碑工具表（进度阶梯）与图章奖励（习惯阶梯）双轨独立计数：里程碑按解锁关数发放
   四阶工具（木镐→钻镐→钻剑），存量档按当前进度一次性追溯补授、不重授。**工具授予不进
   共享背包**（F3 混装核定选型 B：双模式可堆叠种类并集 35 + 6 件工具死占用 > 27 槽；记账进
   训练营存档专字段，宝物柜从该字段渲染；附带免疫"白送铁镐"贬值探险任务链）。

**脑锻炼结构层（设计稿 §8 为数值权威）：**

10. 图章日历：当日完成 ≥1 关得章、满 3 关得大章；漏签无任何负面标记；记录滚动保留 90 天。
11. 集章解锁只发观感/收集类奖励（图章图案/矿袋皮肤/烟花/金图章），永不锁训练内容与关卡。
12. 每日体检：每天一次约 90 秒、复用五维连跑机制、计入时长不占关数额度；产出三档探险家
    火苗（≥85%/≥70%/其余），小火苗配中性温暖文案；只与自己近 7 天均值比、只显示变亮
    不显示回落。不使用年龄/百分位/排名框架。
13. 魔鬼特训：每天一次、5 分钟硬顶（到点当前小节打完即强制结束、当日锁定入口）；计 2 关
    额度 + 计入时长；维度按日轮换；参数取该维度当前档 +2 的挑战档，但阶梯自适应与挫败阀
    照常生效（失败无任何扣损/重置）；每维度独立鬼等级 1~10，按 85%↑/66~84%→/≤65%↓ 双阈
    进退，降级文案中性。
14. 训练师村长：像素主持人格（微笑/喝彩/打盹三表情 + 魔鬼特训鬼化变体），主持开场/规则/
    喝彩/仪式/宝物柜导览；文案与语音走既有应用层话术与语音通道（夸努力不夸聪明）。
15. n-back 不引入（鬼训练的招牌内核即 N-back，MISSION 对 <8 岁排除条款生效）；孩子满
    8 岁的重议入口记录在设计稿 §7.7，先补文献复核再动 MISSION。

**观感与工程（设计稿 §4/§5 为清单权威）：**

16. 训练场皮肤复用贴图图集（TextureAtlas）的程序化贴图做 CSS 雪碧；按钮立体化、进度条
    分段 + 镐子游标、战利品贝塞尔飞行、连对琶音、爆星粒子全部走 CSS 动画与既有音效库，
    不新增音频资产。
17. 训练营存档新增图章/体检/鬼等级/里程碑工具四块字段，迁移幂等补默认值，存量进度字段
    原样保留。
18. 新增脚本只有共享背包壳一个，加载位置在背包核心之后、训练营模式层之前（工单以
    "index.html 加载声明"方式交付，由集成者统一写入，单一写入者防冲突）。
19. 家长面板展示口径与 CSV 列不变；真实数据仍只在家长面板呈现。

## Testing Decisions

**什么是好测试**：只测外部可观察行为——参数曲线的不变量（渐进性/单调性/封顶下界）、纯函数
边界（双阈/三档映射/进退等级）、存档往返与拒收行为、掉落表与物品注册表的交叉合法性；
不测内部实现细节（DOM 结构、动画帧、单次随机结果、CSS）。既有测试（门槛边界、编排不变量、
自适应阶梯）必须保持全绿——它们是本特性"不动什么"的合同。

**测试缝（用户已确认；基线核对后背包壳缝已由 S6 装配，本特性零新缝）：**

- **范式引擎 vm 缝（主战场，既有）**：vm 共享词法环境加载关卡参数表 + 范式引擎（stub
  DOM/语音/图标），覆盖——新曲线不变量（每个 qualitative 参数在引入档必须 0<值<1 且单调
  不减至封顶；长度/格阵/选项的档位边界；时间参数下界）、鬼等级双阈边界（85↑/66 保持/65↓、
  等级 1 不下探 10 不上溢）、火苗三档边界、体检参数时长上界、掉落表概率和=1 且全部 id 在
  物品注册表注册且可堆叠、里程碑 id 全为工具、掉落政策纯函数（保底/教学关豁免/满包余量）、
  图章/体检/鬼等级记录滚动 90 天裁剪、逐试次事件回调的触发契约、存量存档迁移幂等。
- **背包壳缝（既有，S6 已装配并配单测）**：既有单测保持全绿即可；训练营授予流不在此加
  断言——掷骰政策纯函数进范式引擎 vm 缝直测。
- **boot 全链冒烟（既有，自动覆盖）**：真实 index.html 加载序执行含新脚本的完整清单，抓
  共享词法环境顶层重名与加载即炸。
- **规范守门（既有，自动覆盖）**：新文件命名语法与模块头注释五要素契约。

**先例**：范式引擎现有单测（vm 双文件加载 + 依赖注入 stub 的加载器写法）、存档槽与模式
工具箱的单测（壳层 vm 测试惯例）、物品核心/背包核心既有单测（交叉断言先例：掉落表引用的
id 必须全部注册——本特性的掉落表断言沿用同型）。

## Out of Scope

- n-back 及鬼计算式玩法（<8 岁无验证，MISSION 排除条款；满 8 岁重议走文献复核流程）。
- "专注年龄"/智商分/百分位排名等任何标签化单一指标。
- 每日随机挑游戏（破坏间隔+交错的科学编排，只做"今日任务单"呈现层）。
- 训练营接入配方/耐久/挖掘/放置等消耗侧玩法。
- 选关/重打已通关卡（防刷，线性推进不变）。
- 家长面板的任何口径/列/免责声明变更。
- 节日彩蛋（设计稿 B7，低优先，二期再做）。
- 触屏适配、多档案、社区/联机功能。
- 新增音频资产（全部复用既有音效库）。
