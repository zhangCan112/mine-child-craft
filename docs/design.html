一条 seam，四个模式

同一个小 interface：arena 1337 行 / tnt 628 / focus 318 / build 405，对外全部只是 mkMode(cfg) 的十来个钩子。main 与 input 对模式内部零了解。
mkMode 是深 module：chrome 显隐、hotbar 数字/滚轮/点选、KeyB 暂停、onVoidFall 兜底回出生点，全部收进一份 implementation。
政策不在引擎里：DailyBudget 到量只回调 onWarn/onExhausted，何时打断游戏由 main 决定——零 DOM / 零 THREE / 零语音。

三处留意（图中红虚线）

voxel ↔ input 双向耦合
physics 直接读 input 的全局 keys/touchSprint，input 又调 raycastVoxel/physics。体素模型的 interface 隐含了"按键从 input 全局读取"，两者只能一起换。
focus.js 读全局 Budgets
main.js 定义、靠 script 加载序和 typeof 防御撑着。这条依赖没有自己的 seam。
world.js 三条写路径
setBlockRaw / editBlock / editBlockDirty + flushDirty——调用方要知道"批量改动走 dirty + flush"，是 interface 里的一条隐性契约。
