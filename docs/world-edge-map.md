## Destination

在本 worktree（分支 `map-boundary-design`）**实现**：home 图四边视觉无限化——北雪原/南沙漠/西沼泽三条边做地形过渡带+走到尽头瞬间传送到对应远征图，东边做「通向小镇」的观感收尾（小镇本体是未来世界，本次不做）；四个方向的视觉由 4 位 UIDesign designer 子 Agent 分方向设计、经 relay 逐方向与用户确认通过后才实施；收尾验收 = `npm test` + `npm run lint` 全绿 + 用户实机走查。

### 拍板记录（探讨已定，票内引用编号）

1. **目的地=直接实现**（Q1C）：规划与执行同一张图，实施票在图上。
2. **体验北极星=并重**（Q2C）：走得通的边做地形过渡，走不通的边做自然屏障，任何方向都不出现裸露空气墙/世界断面。
3. **范围=只做 home 图边界**（Q3A）：远征图自身边界维持空气边界（回程门挪边除外，见 8）。
4. **东向=小镇观感**（Q4 用户提案）：第四方向做成通向小镇的样子，土路+栅栏+告示牌「小镇建造中」，走到头被栅栏挡住+话术（Q6A）；小镇本体 out of scope。
5. **方向分配**（Q7A）：北=雪原、南=沙漠、西=沼泽、东=小镇。
6. **触发=越线立即传送**（Q5A）：无站桩，白闪+音效掩护（下界门「瞬间+0.8s 冷却」是仓库先例）。
7. **home 三扇门阵移除**（Q8A）：边缘传送是去远征图的唯一入口。
8. **解锁判定保留**（Q9A）：未解锁的边，过渡带中段被自然屏障挡住+话术引导回任务；远征图回程门保留为唯一回家路，且**回程门挪到面向 home 的那条边缘**（用户补充），边缘传送落点=对应回程门旁。
9. **UIDesign=4 designer 分方向**（用户追加）：T2~T5 各配一名 designer，经 relay 与用户确认；Q11C 两步走（概念图→轻量原型）。
10. **远征图回程门保留**（Q10A）。

## Decisions so far

- [T1 · MC 边界与群系过渡的官方观感语言调研](world-edge-tickets.md)：报告在 [docs/mc-world-border-research.md](mc-world-border-research.md)——边界墙借形不借罚（动画条纹/状态色，伤害红屏不搬）、群系渐变=4 格小窗口涌现（本项目 24~40 格带属无冲突自定义扩展）、雾=渲染边界是官方口径、穿雾地标要大件深色（信标先例）。
- [T2~T5 · 四方向过渡带定稿](world-edge-tickets.md)（2026-11-06 二轮实机走查通过）：北=连绵雪山脊+落雪杉、南=大沙丘丘原+耐旱矮树草丛梯度、西=迷雾深水带+黑巢副本迁驻 (26,72)、东=栅栏小镇收尾（冻结）；四角交接 post-pass（NW 冻沼渐变 / NE 镇郊融雪楔 / SW 沙洲没入沼泽 / SE 流沙半埋栅栏+草甸南侵）；规格权威 docs/world-edge-design/{north,south,west,east}-spec.md（各含走查反馈修订段+四角交接小节）。原型代码〔边界原型·T2~T5〕标记，T7 转正收编。
- [T6 · 过渡带禁挖禁建政策](world-edge-tickets.md)：**修订 v2（2026-11-06）**——带内可挖可建全放开；唯一保护清单=各方向未解锁屏障件+东向栅栏/告示牌（不可挖，像基岩），拍板 8 由保护清单守住；「垫塔翻屏障」口子留给 T7 落口径。

## Not yet specified

- **过渡带夜怪政策**：home 夜怪池要不要在过渡带按邻接世界主题变化（雪边刷 stray?）——等设计定稿后看观感需要。
- **天/雾渐变机制细化**：按玩家到边距离 lerp 两图调色板的实现口径（逐帧插值 vs 分档）——等 T1 调研 + 设计定稿后升格。
- **图集新格位清单**：过渡带/告示牌/栅栏若需新贴图格位，等设计定稿列清单。
