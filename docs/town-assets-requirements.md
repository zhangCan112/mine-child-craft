# Midport Village 素材需求清单（Town Assets Requirements）

> 文档状态：**设计权威（素材制作输入）**  
> 产出日期：2026-11-12  
> 输入依据：[`docs/town-map-design.md`](town-map-design.md) · [`docs/town-villagers-design.md`](town-villagers-design.md) · [`docs/design/town-buildings-visual-spec.md`](design/town-buildings-visual-spec.md) · [`docs/design/town-villagers-visual-spec.md`](design/town-villagers-visual-spec.md) · [`docs/minecraft-movie-town-research.md`](minecraft-movie-town-research.md)

## 1. 目的与使用方式

- **目的**：为下一阶段素材制作（模型/贴图/音效/动画与 UI 素材）提供可执行清单与规格基线，确保与地图、村民与视觉 spec 一致、不遗漏关键项。
- **范围**：覆盖地图建筑地标、环境道具植被、村民与生物、交互/提示相关素材；实现代码与引擎接入细节不在本文。
- **优先级**：`P0` 首版必须、`P1` 首版强烈建议、`P2` 可选后置（与 buildings spec/map design 对齐）。
- **状态标注**：**【建议为游戏性调整】** 为默认制作基线；**【待 PO 确认】** 项见 §10，未确认前按默认值推进。

## 2. 版权、风格与全局技术约束

- **版权口径**：**自绘/自建资产**，不搬运受版权保护的官方像素/纹理/模型资产（含 Mojang 与电影官方素材像素复刻）；地名/母题仅作可识别气质锚点（延续 research 与 visual specs 惯例）。
- **视觉风格**：体素/方块语言，暖亮低威胁、6 岁高可读；细节“少而准”，轮廓清晰。建筑材质与色板以 `docs/design/town-buildings-visual-spec.md` §4 为准；角色色板与对比规则以 `docs/design/town-villagers-visual-spec.md` §3 为准。
- **去威胁化硬约束**：无战损/血迹/焦痕/尖刺/铁笼压迫感；Lava Chicken 仅暖橙装饰光意象（`#FF9A3C/#FFC56B`），**禁止**真实流动熔岩、明火焰、烫伤暗示（buildings spec §8）。
- **贴图/像素基线（建议）**：角色与小道具像素单位 `1px = 1/16 格`（与 villagers spec 一致）；方块/建筑贴图建议 16×16（可 32×32 用于招牌等关键读图面，需统一风格）；程序化/手绘像素均可，但同类资产分辨率与描边风格一致。
- **色彩容差**：实现/烘焙可在基准色 ±8% 亮度内微调，保持“温暖明亮、职业/地标可辨、对比清楚”。

## 3. 命名、目录与交付规范（建议）

- **命名建议**：`town_<类别>_<对象>_<变体/状态>`，小写 snake_case，便于检索与批量处理。
  - 建筑：`town_bld_plaza_belltower`、`town_bld_shop_lava_chicken`
  - 角色：`town_chr_v01_amian`、`town_chr_g01_ashou`
  - 氛围动物：`town_amb_a01_xiaohuaji`、`town_amb_a02_mimiao`、`town_amb_a03_xiaohetuo`
  - 道具/植被：`town_prop_market_stall_bread`、`town_veg_tree_sakura`
  - UI/提示：`town_ui_marker_bell`、`town_ui_hint_find`
  - 音效：`town_sfx_ui_confirm_soft`、`town_sfx_plaza_day`
  - **前缀语义（【铺开后补·默认已采纳，PO 可推翻】2026-11-12）**：角色用 `town_chr_`、氛围动物用 `town_amb_`（与铺开交付一致）；音效统一用 `town_sfx_` 前缀（避免与动物前缀冲突）。
  - **中文名↔slug 对应规则（【打样后补·默认已采纳，PO 可推翻】2026-11-12）**：slug 与角色/生物中文名语义一致（如 G01 阿稳 → `ashou`，A01 小花鸡 → `xiaohuaji`）；现有 `town_chr_g01_ashou` 由此一致化。
- **状态后缀**：`_ok`/`_crack1`/`_crack2`/`_crack3`/`_crack4`（傀儡裂纹）、`_day`/`_night`（可选光照态）、`_open`/`_idle` 等。
- **交付建议**：源文件（可编辑）+ 导出运行资产；附一份资产索引表（id、优先级、依赖、状态数、备注）与色板对照；三视图/立面文字规格已在 design docs 中，资产评审以其为对照。

## 10. 依赖关系与制作顺序建议

1. **基线先行（P0）**：全局色板与材质样板（buildings/villagers 各一）→ 广场+钟塔（B-P0-01）→ 村民通用基座（C-BASE-V）→ V01/V07 → Lava Chicken（B-P0-02）→ 铁傀儡 G01（完好+中裂）→ 基础路面/樱花。
2. **氛围补全（P1）**：民居/风车/农田/Secret Stash → 其余常驻村民变体与附件 → 环境道具植被 → 交互图标与 UI 底板 → 环境音与 UI 音效。
3. **可选扩展（P2）**：彩蛋地标、摊位变体、氛围动物全量、额外动画与夜态资产（取决于 PO 确认）。
