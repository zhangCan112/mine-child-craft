## 1. 目标 / 非目标

**目标**
- 简单维度（flanker/switch）提顶：中高 tier 真正构成挑战，顶格逼近 6 岁能力上限。
- 困难维度（gonogo/corsi）断层平滑：台阶变坡道（渐进混编），撞墙烧额度的现象消失。
- 战利品回路：答对赚像素物品 → 飞入矿袋 → 进共享背包（`inventory_save`）→ 宝物柜收集展示
  → 里程碑工具授予（木→石→铁→钻的长线追求，服务"明天再来"）。
- 观感升级：训练场矿洞化（TextureAtlas 贴图皮肤）、MC 立体按钮、战利品飞行/连对琶音/爆星。
- 刺激素材升级：干扰物换成物品系统真像素图标（iconOf），四阶工具色板同形异色当难度梯子。
- **结构层（§8）**：脑锻炼式习惯外壳——图章日历、训练师村长、每日专注体检、集章解锁。

**非目标**
- 不动通过门槛/三星/每日预算/家长面板口径（家长面板 CSV 列不变）。
- 不接配方/耐久/挖掘/放置——专注只**产出**战利品，不**消耗**（训练口径不动，ADR 0002）。
- 不加倒计时压迫、不加惩罚（战利品只增不减）；不加选关/重打（防刷，线性推进不变）。
- 不动 100 关螺旋编排公式（tier = min(19, 2+⌊k/5⌋）——只改 `paramsFor` 曲线内容）。

## 2. 难度再平衡（D1~D5，逐维度）

统一记号：t=(tier−1)/18 ∈ [0,1]；"过渡档"= 某 qualitative 参数首次引入的 tier。
设计原则：**qualitative 变化一律渐进混编**（新元素以概率 p 混入，p 随 tier 上升至 1），
相邻 tier 之间的体验差永远可吸收（`mkAdapt` 的 calib 杠杆管时间参数，混编管结构参数）。

## 3. 战利品回路与共享背包（L1~L6）

### L1 · 共享背包 Backpack（新文件 `js/backpack.js`，应用层 adapter）

- **唯一拥有 `inventory_save` 存档键的模块**（ADR 0002）：`SyncDB.slot('inventory_save',
  {defaults: serialize(mkInventory())})`；满包/损坏回落空背包。
- interface：`load()→inv` · `add(id,n)→余量`（内部落账+onChange）· `count(id)` ·
  `total()` · `onChange(fn)` · `renderGrid(doc?)→宝物柜 HTML`。
- 依赖：inventory-core（引擎纯核心）、SyncDB、iconOf（icons.js）。index.html 挂载位置：
  inventory-core 之后、modes/focus.js 之前。
- 未来消费方（探险/建造生存/下界掉落）一律经此壳，不得自开键。

### L2 · 引擎事件缝（focus-paradigms.js，分层不破）

- 四引擎的 handler 契约新增**可选**回调 `h.onTrial({ok, streak, dim})`——范式引擎只报
  事件，不知道奖励、物品、背包（引擎层不知道玩法，分层规则不破）。不传则零开销，
  既有调用方与单测不受影响。

### L3 · 矿袋奖励政策（modes/focus.js，应用层）

- 触发：`onTrial({ok, streak})` → 正确以 **p=0.45** 掷骰掉落；**3 连对保底**一掷稀有池
  （连续正确的"desirable difficulty"正反馈，只奖不罚）。
- 教学关（kind=tutorial）不掉落——零压力入门。
- 关卡通过：+1 结算件（torch / apple 二选一）；三星：追加 1 钻石。
- 掉落表 `FOCUS_LOOT`（focus-levels.js 数据，按维度主题化，概率和=1）：

| 维度 | 掉落池（id × 权重） | 稀有池（3 连对） |
| --- | --- | --- |
| cpt 瞭望塔 | coal .40 / iron_ore .25 / torch .20 / iron_ingot .12 / gold_ingot .03 | gold_ingot .6 / diamond .4 |
| gonogo 挖矿 | cobble .30 / coal .25 / iron_ore .20 / iron_ingot .15 / diamond .10 | 同上 |
| flanker 排队 | gunpowder .45 / string .25 / bone .20 / slimeball .10（苦力怕/蜘蛛/骷髅的掉落物） | 同上 |
| corsi 闪闪光 | diamond .40 / gold_ingot .25 / iron_ingot .20 / bone_meal .15 | 同上 |
| switch 小矿工 | planks .25 / stick .25 / brick .20 / clay_ball .15 / bread .15 | 同上 |

- 满包：`add` 余量>0 → 静默忽略 + 每关至多一次 toast「背包满啦」（不惩罚）。
- 掉落观感：像素图标从刺激位置沿贝塞尔弧线飞入矿袋槽位（复刻 drops.js 真空吸附观感，
  CSS keyframes 实现），落袋叮咚（sfx('pick')），槽位弹跳。

### L4 · 里程碑工具（长线追求）

- `FOCUS_MILESTONES`（focus-levels.js 数据）：
  `{10: pick_wood, 30: pick_stone, 50: pick_iron, 70: sword_iron, 90: pick_diamond, 100: sword_diamond}`
- 触发：unlocked 首次越线 → 全屏授予仪式（像素工具大图 + sfx('level') 琶音 + TTS
  「你获得了铁镐！挖矿越来越厉害啦！」），工具经 Backpack.add 进包（不并堆、占 6 槽，
  27 槽余量充足）。
- 追溯：已越线的存量档在下次进入训练营时一次性补授（按 unlocked 计算，不重授）。

### L5 · 宝物柜（收集可见性，零文字依赖）

- 今日页新增 🎒 按钮 → 全屏收集柜：按 材料/矿物/食物/工具/方块 分组（iconOf 像素图标 +
  数量角标），点击 TTS 读物品名（`ITEMS[id].name`）。
- 关卡结算页：本关战利品从矿袋飞出列队 + 计数回顾，然后才是三星爆星。

### L6 · 防刷与经济口径

- 产出上限 = 每日 6 关预算（线性推进、无选关重打，天然封顶，不新增账本）。
- 战利品只增不减；掉落以基础材料为主、钻石类权重低（为未来探险经济留余量，ADR 0002）。

2. 矿袋：答对飞行入袋、3 连对稀有保底、结算回顾、宝物柜计数、满包 toast 一次性。
3. 里程碑：unlocked=50 的档首次进入 → 补授铁镐仪式；L100 通关 → 钻石剑。
4. flanker/switch 顶格关（tier 18/19 手动体验）：len9 行宽、中立行、双价干扰的可读性。
5. 家长面板：CSV 列与口径不变；lint/test 全绿。

## 7. 风险与开放问题

1. **共享背包经济**：探险模式（未来）需消化专注存量物品——已按 ADR 0002 用"材料为主+日额
   封顶"缓解，探险设计稿立项时必须复读该 ADR。
2. **Mobs.face 接口形状**未核实（HTML 片段 or URL）：不合用则 focus-icons 补画猪/羊头
   （16×16，与苦力怕脸同管线）——实现期第一件事先验证。
3. **len9 行宽**：9×(56+8)=576px，理论放得下，需真机看可读性；不行则 len9 降为 8。
4. **概率参数的体验方差**：disguiseRate 0.3 的 tier8 单局可能一个伪装都没出（nogo≈5 时
   p(全不中)≈0.17）——方差由 mkAdapt 吸收，家长面板观察两周后再定是否把 tier8 提到 0.35。
5. **羊毛像素图标缺失**（ITEMS 无羊毛）：一期混用 mcIcon 羊毛与 iconOf 材质，风格差异极小
   （同 16×16 像素管线），补画留二期。
6. 观感工作量集中在 CSS（§4 约 8 项）——可与逻辑改动分两个提交，先逻辑后观感，回归压力小。
7. **n-back 满足年龄后重议**：孩子满 8 岁且证据口径不变时，可评估是否引入鬼计算式
   1-back 作为魔鬼特训的第六选型（先补 <8 岁排除条款的文献复核，走 MISSION 变更流程）。

## 8. 脑锻炼结构层（B1~B8，习惯回路 + 高强度特训格式）

> **参照系**：任天堂《脑锻炼》系列的两个条目。**初代**（DS 2005）贡献习惯外壳——每日短训、
> 图章日历、体检指标、主持人格；**《5 分钟鬼训练》**（3DS 2012，欧美版 *Brain Age:
> Concentration Training*，**用户指定的参照版本**）贡献高强度格式——每日 5 分钟特训块、
> 逐日锁定、85/66 双阈自适应阶梯、鬼化主持人格（该作儿童本就是目标用户，日文维基明确）。
> 范式内核（五维）不变。
> 来源：Wikipedia *Brain Age*（图章机制）、日文维基 鬼トレーニング 条目（八种鬼训一览 /
> 5 分钟强制结束与逐日锁定 / 85%↑·66~84%→·≤65%↓ 阶梯 / "过训可能反伤大脑"的封顶理由）、
> 任天堂官方训练介绍页、Nintendo World Report 评测（八练习·专攻工作记忆）、机核设计史。
> **改造而非照搬的地方都有理由**，两条最重要的：
> ① **年龄框架不用**——任天堂自家说明书都为"脑年龄"免责（"仅用于查看训练进度，不作任何
> 其他用途"），且对 6 岁儿童有标签化风险，本设计一律不用年龄/分数排名框架；
> ② **n-back 不引入**——鬼训练的招牌内核（鬼計算/鬼耳算/鬼めくり/鬼記号）全是 n-back 族
> （川岛在 Miiverse 亲口确认鬼計算即 N-back），而 MISSION 明确排除 n-back（<8 岁无验证），
> 玩家 6 岁。**借格式与阶梯，内核换成我们已有文献支撑的五维参数**；孩子满 8 岁后可重议
> （记入 §7 开放问题）。

### B1 · 图章日历（每日打卡，只庆祝不惩罚）

- 今日页新增本月日历条：当日完成 ≥1 关即得像素图章（⛏️/💎 图案）；**当日练满 3 关得大图章**
  （与脑锻炼"完成 3 个训练项目图章变大"同构；我们日限 6 关，3 是"过半"的自然里程碑）。
- 漏打卡无任何负面标记（没有"断签"概念——零惩罚哲学；脑锻炼同样只缺席不惩罚）。
- 记录进 `focus_camp_save.stamps`（`{日期: 当日关数}`，滚动保留 90 天，防存档膨胀）。
- **双轨长线**：里程碑工具（§L4）= 进度阶梯（按解锁关数），图章奖励 = 习惯阶梯（按训练天数），
  两条轨道独立计数、互不折算。

### B2 · 今日菜单（呈现层，编排不动）

- 脑锻炼的"每日训练随机挑三个游戏"**不搬**——我们的 100 关螺旋是间隔+交错的科学编排
 （focus-levels.js 头注释引用 Cepeda 2006 / Klimovich 2025），随机化会破坏它。
- 只做呈现升级：今日页把今天将轮到的 2~3 个游戏用游戏图标排成"今日任务单"，配村长开场白，
  让"换着玩"的节奏被孩子看见。

### B3 · 每日专注体检（脑年龄检测的儿童安全版 → 探险家火苗）

- **入口**：今日页「🔥 今日体检」，每天一次，约 90 秒；复用 master 关的五维连跑机制
  （`runFocusLevel` 的 sections 分发），各维度取低档短参数（约 6 试次/节）。
- **计费**：计入时长预算、**不占** 6 关额度（防沉迷口径不加例外）；当日做过即入口消失。
- **产出 = 探险家火苗**（不是年龄、不是百分数）：三档火苗 🔥小火苗/🔥🔥中火苗/🔥🔥🔥大火苗，
  按当次五维平均正确率映射（≥85% 大 / ≥70% 中 / 其余小）；小火苗配中性温暖文案
  （"今天慢慢来，火苗明天会长大的"）。
- **成长对比只和自己**：当次均值 > 自己近 7 天体检均值 → 村长喝彩 + sfx('level')
  （"比上次更亮啦！"）；不显示任何下降对比，不与常模比较（诚实口径：体检是练习状态的
  自我观察，家长面板才看真实数字，措辞与免责声明口径不变）。
- 记录进 `focus_camp_save.checks`（`{日期: {acc, flame}}`，滚动 90 天）。

### B4 · 训练师村长（主持人格）

- 现有文案里"训练师要休息了"的**训练师**落地成角色：像素**老矿工村长**（白胡子 + 矿工帽 +
  头灯），16×16 手绘 → 96px（focus-icons 管线），三表情：微笑 / 喝彩 / 打盹（锁定页）；
  另有**鬼化变体**（矿工帽加一对鬼角 + 坏笑，B8 魔鬼特训专属上岗造型）。
- 出现位置：今日页开场白、规则说明页（替代纯文字框，头像 + 气泡 + TTS 读规则）、
  结算喝彩、里程碑/集章仪式主持、宝物柜导览（"哇，这么多钻石！"）。
- 分层不破：村长是应用层 UI 组件 + 文案（FOCUS_PRAISE 同层），语音走 SpeechKit。
- 投资依据：脑锻炼 PSP 版砍掉川岛形象后玩家"总觉得没那个味道"（机核）——主持人格是该
  品类的身份载体；我们用 MC 观感语言自绘，零外部素材。

### B5 · 我的进步（儿童版成绩曲线）

- 今日页「📈 我的进步」：五维各一列**星柱**（该维度累计星数向上堆叠 + 最新突破纪录的 ✨ 标记），
  零文字（图标 + 点击 TTS 读维度名）；只呈现累计与突破，不呈现下滑。
- "每日首训才计入曲线"的防刷原则我们天然满足：星级本就取每关历史最高（focusPassed/focusStars
  语义），重玩不稀释指标。

### B6 · 集章解锁（只解锁观感，不锁训练内容）

- 累计图章数达到里程碑 → 村长授予**观感/收集类**奖励：3 章=自选图章图案（⛏️💎🧨 三选一）、
  7 章=矿袋皮肤（木箱→铁箱）、14 章=宝物柜烟花彩蛋、30 章=金图章、每 30 章递进。
- **红线**：不解锁任何关卡/范式/难度——训练内容的推进只由 100 关进度决定（训练连续性优先，
  也避免"为了解锁多玩"与防沉迷目标打架；脑锻炼用图章解锁训练内容，我们不抄这条）。

### B7 · 节日彩蛋（可选，低优先）

- 特定日期（1/1 儿童节 6/1 等）村长节日造型 + 一句问候，`Date` 判断，零存档成本。

### B8 · 每日魔鬼特训（鬼训练 5 分钟高强度块，借格式不借 n-back 内核）

- **入口**：今日页「👹 魔鬼特训」，每天**一次**，硬上限 5 分钟；到点后当前小节打完即强制
  结束、入口当日消失——鬼训练同款"逐日锁定"，其封顶理由（长时间鬼训可能反伤大脑，
  日文维基引官方口径）与我们的防沉迷哲学同向，每日预算再兜一层。
- **计费**：计 2 关额度 + 计入时长（预算完整性优先，不加例外）。
- **选型**：维度按日轮换（`天数 % 5`）——鬼训练用八种分散"过训"风险，我们用五维轮换达成
  同样效果；参数取该维度「孩子当前 tier + 2」（封顶 19）的挑战档，但 **mkAdapt 阶梯与
  挫败阀照常生效**（魔鬼也要零惩罚底线：失败无任何扣损、不重置）。
- **鬼等级阶梯**：每维度一条独立「鬼等级」1~10（存档持久）。一组打完按鬼训练同款双阈判进退：
  正确率 **≥85% 升级 / 66~84% 保持 / ≤65% 降级**——与我们 70~85% 自适应训练带同构
  （互为印证），降级文案中性（鬼村长坏笑："下次再来！"）。
- **仪式感**：特训期间村长戴鬼角上岗（B4 鬼化变体），开场白「魔鬼特训，5 分钟，准备好了吗！」；
  通关得**鬼图章**（B1 日历的特殊章，与普通章并存，集章数合并计入 B6 里程碑）。
- **不搬的部分**：n-back 族（头注②）；3DS 的"合盖中断整套重来"惩罚（零惩罚哲学，
  中断只是不划算，不重置不扣损）。
