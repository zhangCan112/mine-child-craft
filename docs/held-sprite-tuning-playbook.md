# 手持薄片朝向调参手册（held-sprite-tuning-playbook）

> 2026-11-06 剑前倾五~七轮观感战役沉淀的可迁移方法论（七轮实机迭代，
> 用户逐轮验收：贴身→回调→好多了→+20°收官）。
> 适用 = 所有手持薄片（工具四件/剑/弓/剪刀/盔甲薄片）第三人称朝向调参。
> 下一次调角度先读这页：五分钟上手，不走七轮弯路。
> 剑的个案史（探针数据全表）在 [equipment-design.md](equipment-design.md) §4.2。

## 1. 旋钮模型——先弄清拧的是什么

- grip 组层级：`arm Group`（肩枢轴 `(0.3125, 1.375, 0)`）→ `grip Group`
  （手枢轴，pos y 要再减 `GRIP_DY = -0.16`）。`grip.rot` 是 three.js
  Euler `'XYZ'`，矩阵序 `M = RX·RY·RZ`，**向量先吃 RZ**（七轮探针数据实证，别再怀疑这个序）。
- 三个自由度各管一件事，调参时概念分离：
  - **RY(−90°)：镜像免疫档**。薄片侧棱对前后相机 = 薄刃剪影；此时薄片
    法线恒 ±x，**其它旋钮怎么动都不改侧棱朝向**——背面镜像修复不会被前倾破坏。
  - **RZ：前倾单旋钮**。直读恒等式见 §2。
  - **pos：抬持/前移**（MC translation 折算），管「握点在手心」与「离甲袖前脸」。
- **调参纪律：已验收基座上一次只动一个旋钮**——变化可归因，翻车只改一行数字。
- **第一人称（fp）同轴不同语义，别拿第三人称直觉套**（2026-11-06 剑「横扛」轮实证）：
  - 挂载链：itemSlot 视空间 `(0.56, −0.52, −0.72)`（相机右下前方），`fp.rot`
    全权决定姿态（Euler 'XYZ' 同序）。族档 `FP_HANDHELD` = rot `[0,−90,25]°`
    + scale 0.8；方块族 `FP_BLOCK` = rotY 45°。
  - **挂载点差异改「面可见性」判据**：第三人称物体在相机正前方（法线 ±x =
    侧棱剪影）；第一人称物体在右下前方（法线 ±x = **大面正朝相机**）——
    两通道结论相反，第三人称的「侧棱对相机」经验不可迁移。
  - **sprite 对角物品第一人称要 +45° 补偿**：剑/工具头薄片长轴是像素画对角
    （与薄片 +y 夹 45°），竖直盒体物品（木棍/火把/镐柄）长轴即 +y——同一族档
    RZ(25°)，盒体自然收、对角片横扛。修法=对角片 RZ+45°（剑=FP_SWORD 70°），
    第一人称探针实测屏幕长轴与盒体同形。对照 §2：第三人称前倾=RZ−45°，
    第一人称补偿=RZ+45°，方向相反。
  - **第一人称探针判据**：与第三人称骨架同构，投影换 NDC=(x/−z)/tan(fov/2)
    （x 再除 aspect），挂载点平移在前；输出「屏幕长轴角 + 端点深度」——
    深度正=朝观者放大（戳脸/外撇感）、负=朝画面内收（自然持握）。

## 2. 前倾角恒等式——别再推 atan

- 对角带方向（rot `[0, −π/2, θ]` 时）= `(0, sinθ+cosθ, sinθ−cosθ)/√2`；
  √2 归一后 `tan(前倾) = tan(θ−45°)`，即：

  **前倾角 = RZ − 45°**（逐度线性，直读）

- 直读表：RZ 55°→前倾 10° · 75°→30° · 95°→50°。**RZ>90° 合法**
  （cos 变负），前倾继续加深，剑尖越过水平线朝前下 (RZ−90°)。
- 用户报角度 ↔ 落数值：前倾 30° → RZ=75°=1.3090 rad；前倾 50° → RZ=95°=1.6581 rad。

## 3. 探针定案——禁脑内推欧拉

- **手持定位争议禁止脑内推欧拉**：七轮里脑算两次全错，探针一次定案。
  three.js 旋转组合直觉不可靠，写脚本跑数。
- 骨架（TEMP 探针 v7 收录入库，Node 直跑，require 本仓库 `lib/three.min.js`）：

```js
'use strict';
const THREE = require('<仓库根>/lib/three.min.js'); // r128 UMD

const PIVOT = new THREE.Vector3(5 / 16, 22 / 16, 0); // 肩枢轴
const GRIP_DY = -0.16;
// 判距盒（player 官方等比；换物品/换模型先核这批常量）
const TORSO  = {x0: -0.25, x1: 0.25,  y0: 0.75,  y1: 1.5,   z0: -0.125, z1: 0.125};
const ARM    = {x0: 0.25,  x1: 0.5,   y0: 0.75,  y1: 1.5,   z0: -0.125, z1: 0.125};
const SLEEVE = {x0: 0.219, x1: 0.531, y0: 1.219, y1: 1.531, z0: -0.156, z1: 0.156}; // 甲袖带
const PALM = new THREE.Vector3(0.31, 0.72, -0.10); // 掌心（柄-手距判据）

function boxDist(p, b) {
  const dx = Math.max(b.x0, Math.min(p.x, b.x1)) - p.x;
  const dy = Math.max(b.y0, Math.min(p.y, b.y1)) - p.y;
  const dz = Math.max(b.z0, Math.min(p.z, b.z1)) - p.z;
  return Math.hypot(dx, dy, dz);
}
// 四姿态：[名, 臂X, 臂Z]——站立/行走摆臂前后/跳跃收臂
const POSES = [['站立', 0, -0.05], ['摆前', 0.51, -0.05], ['摆后', -0.51, -0.05], ['跳', -0.45, -0.5]];

function probe(label, gripPos, gripRot) {
  for (const [pn, ax, az] of POSES) {
    const arm = new THREE.Group();
    arm.position.copy(PIVOT);
    arm.rotation.set(ax, 0, az);
    const g = new THREE.Group();
    g.position.set(gripPos[0], gripPos[1] + GRIP_DY, gripPos[2]);
    g.rotation.fromArray(gripRot);
    arm.add(g);
    arm.updateMatrixWorld(true);
    // 采样剑带对角线 7 点（薄片 parts 对角向量；换物品换采样向量）
    const pts = [];
    for (let i = 0; i <= 6; i++) {
      const t = i / 6;
      pts.push(new THREE.Vector3(-0.14 + 0.62 * t, -0.14 + 0.62 * t, 0).applyMatrix4(g.matrixWorld));
    }
    const tip = pts[6], pom = pts[0];
    let dT = 9, dS = 9;
    for (const p of pts) { dT = Math.min(dT, boxDist(p, TORSO)); dS = Math.min(dS, boxDist(p, SLEEVE)); }
    console.log(pn + ': 尖(' + tip.x.toFixed(2) + ',' + tip.y.toFixed(2) + ',' + tip.z.toFixed(2) + ')'
      + ' 躯干' + dT.toFixed(2) + ' 袖' + dS.toFixed(2) + ' 柄-手' + pom.distanceTo(PALM).toFixed(2));
  }
}
// 用法：probe('RZ95°', [0.10, -0.30, -0.18], [0, -1.5708, 1.6581]);
```

- 输出判读：尖端 z 更负=更朝前（玩家面前是 −z）；「最差」行取四姿态
  最小值当安全线；**扫档对比看趋势**（3 档并排跑）。

## 4. 安全线参考（剑档实测；其他物品重跑探针自定）

| 判据 | 剑七轮实测 | 含义 |
|---|---|---|
| 躯干距 | ≥0.13 | 穿模红线 |
| 袖距 | ≥0.18（前倾越大越好：55° 时 0.04 → 95° 时 0.26） | 别怕前倾贴袖——尖朝前下走反而离甲袖远 |
| 柄-手距 | ≤0.12 | 剑脱手观感 |
| 尖最低 y | 摆后/跳 1.01 为下限 | 低于此向「拎着剑耷拉」旧观感回头（85° 档 1.11 尚可、再加深即危险） |

## 5. 用户沟通口径

- 用户说「30度」= **剑尖到胳膊（竖直）的前倾角**，不是 RZ 值！
  汇报用「前倾 X°」与用户对齐，RZ 是内部实现细节。
- 「幅度再大 20 度」= 前倾角 ±20°，§2 恒等式直读换算后落 RZ。
- 迭代节奏：探针扫档报数据 → 落盘 → 实机强刷验收 → 验收后定档留回落档。
  用户「我看看」= 中间态，**文档注释与数值同频更新**（不同频=文档撒谎）。

## 6. 流程模板（七轮蒸馏，照抄）

1. **先 commit 打锚**——观感调参翻车即 `git reset --hard <锚>`，不污染历史
   （ef987fb 实战验证，用户明示要求）。
2. 探针扫 3 档 × 4 姿态，选档报数据给用户（含尖端坐标表）。
3. 单旋钮落盘：`TOOL_GRIPS.X` 与 `HELD_DEFS` 模板条目**两处 grip 必须同步**
   （模板注释有「同 TOOL_GRIPS.sword」承诺）；注释史同步更新。
4. 注释/设计稿含全角字符（°「」−·），**一律 Node 区间替换 splice**
   （读文件、indexOf 前后标记、splice 写回）；`edit` 工具对全角断行不可靠
   （七轮里两次 mismatch 都栽在抄错断行）。纯 ASCII 数值行可安全走 edit。
5. 门禁：单测（held-item 面）+ lint；全量在收官时跑。
6. 服务逐请求读盘 = 代码即最新，用户强刷（Ctrl+Shift+R）即见。

## 7. 死路存档（七轮实证，别回头）

| 死路 | 症状 |
|---|---|
| 正典直折不抬持 | 「尖戳腋」（尖悬甲袖带 1.22~1.53） |
| 无抬持加前倾 20°/40.7° 救 | 仍贴身——**抬持才是与一轮的关键差**，不是角度 |
| 并入工具档（竖持） | 薄片背面镜像总爆发：玩家面朝相机时第三人称看 −z 背面（水平镜像），尖/柄两端对调 |
| RZ 加到 85°+（前倾 40°+）还想再加 | 尖垂「拎着剑耷拉」旧观感回头——85° 已是竖直上限档，过 90° 前必须用户实机拍板 |

- 薄片镜像的正解是 **RY(−90°) 侧棱档**（§1），不是调前倾救。
