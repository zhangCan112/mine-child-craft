## Problem Statement

孩子现在有五个游玩模式，但世界是「创造口径」的：方块无限拿、打怪没掉落、工具没有差别、收集没有去处、怪物打完只剩一个数字。孩子最喜欢的我的世界循环——「劳动 → 收获 → 制作 → 变强」——在游戏里完全不成立；而完整我的世界对 6 岁孩子又太难（网格摆位合成、饥饿系统、死亡掉落、文字依赖）。家长希望游戏既保留这个循环的乐趣，又符合零惩罚、零文字依赖的儿童口径。对开发侧（用户本人）而言，这套能力不能绑死在某个模式里——下界冒险、建造模式将来都想按需接入。

## Solution

新增「**探险模式**」作为物品系统的第一个消费者：孩子空手进入一张草原地图（树林、湖泊、两个露天矿坑、一条山洞、出生小屋、三个怪物巢穴），跟着 12 步语音任务链——砍树 → 木板 → 工作台 → 木镐 → 圆石 → 石镐 → 煤 → 火把 → 铁矿 → 熔炉烧铁 → 铁镐 → 钻石——最终合成钻石剑、获得「小小探险家」称号与烟花。一路上的行为全部有物质反馈：挖碎的方块蹦出掉落物并自动飞进背包、树叶飘出苹果和树苗、湖底能挖黏土烧红砖、怪物巢穴限量刷怪且必掉材料。合成走**点选配方书**（材料齐点亮、缺什么灰什么、点击即成 + 语音表扬），工具**有耐久但坏了有语音安抚**，工作台/熔炉**放置后走近解锁**。底层是引擎层三纯核心 + 掉落物实体库 + 怪物击杀事件，任何模式按需接入，不接的模式零改动。

## User Stories

**物品与背包**

1. 作为小探险家，我想要一个背包自动收好我捡到的一切，这样我的收获永远不会丢。
2. 作为小探险家，我想要最常用的东西放在底部快捷栏里一键选中，这样挖矿打仗不用翻包。
3. 作为小探险家，我想要相同的材料自动堆成一摞（最多 64 个），这样背包不乱。
4. 作为小探险家，我想要一个「整理」按钮把背包一键排整齐，这样不用先学会整理术。
5. 作为小探险家，我想要所有物品的图标是像素小画，这样不认字也知道哪个是煤、哪个是铁。
6. 作为小探险家，我想要背包快满时收到提醒，这样我知道先去合成掉一些。
7. 作为小探险家，我想要背包、任务进度和世界改动自动云同步，这样换台电脑也接着玩。
8. 作为模式开发者，我想要背包是全局唯一、选配接入的引擎资产，这样我做的模式想要就拿去用，不想要就完全不感知。
9. 作为家长，我想要这套系统不改变防沉迷账本结构，这样所有游玩模式仍共享同一份每日限额。

**挖掘与采集**

10. 作为小探险家，我想要按住挖方块时准星出现进度圈、手里的工具不停挥动，这样我能感觉到「快挖开了」。
11. 作为小探险家，我想要挖碎的方块炸出同色碎块并蹦出掉落物，这样「破坏」和「收获」有看得见的因果。
12. 作为小探险家，我想要掉落物离我近了就自己飞进背包，这样不用练习走位去踩。
13. 作为小探险家，我想要捡到新材料时听到语音告诉我捡到了什么，这样不看字也学会了物品名字。
14. 作为小探险家，我想要空手就能挖泥土、砍树、打草丛，这样开局什么都不做也能起步。
15. 作为小探险家，我想要镐子挖石头明显更快、斧头砍树更快、锹挖土更快，这样一眼明白工具的意义。
16. 作为小探险家，我想要挖不动的高级矿（等级不够）时听到「需要更硬的镐子哦」并看到图标提示，这样知道下一步该升级什么。
17. 作为小探险家，我想要徒手挖石头又慢又不掉东西但不会无限磨，这样学会做镐子但不绝望（时间封顶）。
18. 作为小探险家，我想要树叶掉树苗和苹果，这样既能种树又有零食。
19. 作为小探险家，我想要树苗放在草地上过一会儿长成大树，这样我砍掉的森林能长回来。
20. 作为小探险家，我想要草丛里能打出小麦种子，这样先认识「种子」，等二期开农田。
21. 作为小探险家，我想要湖底有能挖的黏土、烧成红砖砌红砖墙，这样湖不只是一滩水。

**自然矿物**

22. 作为小探险家，我想要站在露天矿坑边就能看见裸露的煤矿和铁矿，这样不用瞎猜地下有没有宝。
23. 作为小探险家，我想要越深的矿越稀罕（煤浅铁中金少钻最深），这样挖到钻石像过节一样。
24. 作为小探险家，我想要挖煤矿直接拿到煤炭、挖铁矿拿到铁矿石，这样理解「有的矿直接用、有的要烧」。
25. 作为小探险家，我想要石头挖掉变成圆石、圆石烧一下变回石头，这样建材链像我的世界一样自洽。

**怪物掉落**

26. 作为小探险家，我想要打倒苦力怕捡到火药，这样我能亲手做 TNT 炸开矿洞。
27. 作为小探险家，我想要每只怪至少掉一个材料，这样从来没有白打。
28. 作为小探险家，我想要僵尸偶尔掉铁锭，这样打怪有惊喜彩蛋。
29. 作为小探险家，我想要骷髅掉骨头、蜘蛛掉线，这样后期的骨粉和弓都有来路。
30. 作为小探险家，我想要怪物只在巢穴限量出现、清完休息一会儿再来，这样不会突然被一大群围住吓哭。

**合成与烧炼**

31. 作为小探险家，我想要配方书里材料齐的卡片亮着、点一下就合成，这样完全不用学「摆格子」。
32. 作为小探险家，我想要缺材料时卡片上缺的那样变灰，这样一眼知道接下来去挖什么。
33. 作为小探险家，我想要合成成功时听到具体的表扬（「木板做好啦！你真会想办法」），这样被夸的是努力不是聪明。
34. 作为小探险家，我想要长按卡片连续合成，这样一次做一摞木板不点到手酸。
35. 作为小探险家，我想要把工作台放在地上、走近它就解锁更多配方，这样感受到「基地在变大」。
36. 作为小探险家，我想要熔炉放进矿石就自动挑最省的燃料，这样不用理解燃料表也能烧。
37. 作为小探险家，我想要熔炉工作时有进度条、烧好有语音通知，这样等待也是期待。
38. 作为小探险家，我想要配方按「全部/工具/食物/方块」分图标页签，这样找配方不用翻很久。

**工具、战斗与生存**

39. 作为小探险家，我想要木头→石头→铁→钻石的工具一阶比一阶强，这样每一步升级都摸得到。
40. 作为小探险家，我想要选中工具时手里真的换成那把工具的样子，这样有「装备上了」的实感。
41. 作为小探险家，我想要工具耐久快用完时提前听到提醒，这样有心理准备。
42. 作为小探险家，我想要工具坏掉时听到温柔的安慰和「再做一个更棒的」的指引，这样不哭鼻子。
43. 作为小探险家，我想要吃苹果和面包能回血，这样受伤了有自己能做的事。
44. 作为小探险家，我想要打不过死掉时保留全部背包、回到出生小屋满血复活，这样敢去危险的地方探险。

**任务链与仪式感**

45. 作为小探险家，我想要每一步任务都有语音和图标告诉我做什么，这样全程不认字也能玩。
46. 作为小探险家，我想要完成每一步立刻有过程性表扬，这样越玩越有劲。
47. 作为小探险家，我想要挖到第一颗钻石时有特别的仪式感，这样记住这个瞬间。
48. 作为小探险家，我想要走完 12 步拿到「小小探险家」称号 + 烟花庆祝，这样有毕业的成就感。

**观感（pinpoint 批注吸收）**

49. 作为小探险家，我想要方块有像我的世界的贴图（矿石嵌斑、木头年轮、木板板缝、树叶孔洞），这样一眼认出「这是煤矿、那是工作台」。
50. 作为家长，我想要贴图与图标全部程序自绘、风格参考但不复制官方素材，这样没有版权隐患也不引入外部资源。

## Implementation Decisions

**总架构（用户拍板①：引擎层基础系统）**

1. 系统落在引擎层，模式选配接入：三个**纯核心**（物品注册表 / 背包核心 / 合成核心——零渲染零 DOM，共享词法环境顶层声明，与手持物注册表同款形态）+ 一个**引擎壳**（掉落物实体库，接口窄面镜像怪物库）+ 怪物库加**击杀事件**。任务、表扬话术、掉落政策、地图全部在应用层新探险模式。
2. 引擎不知道玩法：怪物库只在击杀判定瞬间回调一次死亡事件（现有击碎块特效的同一时点），不解释死因；掉落物实体库只负责实体与拾取，收集后的语音与入包由消费方决定。
3. 既有文件三处扩展：方块注册表每条加 hard / tool / tier / drop 四字段并新增方块 id 36~49；新增怪物掉落数值表；手持物注册表增加「四阶材质色板 × 镐/斧/剑/锹」的参数化生成入口（锄头维持现状不进耐久系统）。

**数据模型（参数表驱动，加内容 = 加一行数据）**

4. 物品注册表条目四类：材料（堆叠 64，部分带放置型 block 字段与燃料热值）/ 工具（堆叠 1，带 kind-tier-dmg-dur-speed）/ 食物（带回血值）/ 放置型。一期约 42 条：26 材料 + 16 工具（4 阶 × 镐斧剑锹）+ 食物与站点件。
5. 配方表条目 = 产物 + 材料计费（材料项支持「任选其一」，如煤/木炭）+ 站点（手搓随时 / 工作台需站点）。烧炼表 = 原料→产物映射。燃料热值照搬 MC（煤与木炭 8 件、木质 1.5 件、木棍 0.5 件）。
6. 怪物掉落表条目 = 「保底掉落 + 概率加成 + 稀有掉落」三段式（儿童配平：保底 1、50% 概率 +1，替代 MC 的可能空手）。一期覆盖巢穴四怪：僵尸（腐肉，5% 稀有铁锭）、骷髅（骨头）、苦力怕（火药）、蜘蛛（线）。
7. 破坏时间纯函数：时间 = 硬度 ×（工具匹配 ? 1.5 ÷ 工具速度 : 5），封顶 8 秒、下限 0.15 秒；镐等级不足可挖慢但掉落不触发，同时发提示事件。硬度原值照搬 MC。
8. 既有方块三分类（pinpoint 批注吸收）：草地/泥土/沙/石头/木头/树叶/圆石/苔石 = 直接采集（苔石由装饰转为矿洞自然生成）；木板/石头/玻璃/石砖/红砖块/火把/工作台/熔炉/TNT = 合成或烧炼；装甲/履带/金属/羊毛/石英/灯块 = 一期创造专属。原版补给包一期件：黏土→黏土球→红砖→红砖块整链、石砖链、剪刀（剪树叶得树叶方块）。

**交互与政策（儿童口径）**

9. 合成交互 = 点选配方书（用户拍板②）：卡片亮灰表达可否，缺失清单驱动灰显；单击合成、长按连续；成功走具体表扬话术（夸努力口径）。
10. 站点解锁 = MC 式放置解锁（用户拍板④）：工作台/熔炉作为放置型物品放入世界，4 格邻近范围内 table 级配方与烧炼才点亮；熔炉 2.5 秒/件（MC 10 秒的儿童缩短），燃料自动择优，面板关闭进度保留、退出世界材料退回背包。
11. 耐久 = 有耐久 + 语音安抚（用户拍板③）：耐久数值 ≈ MC ×2（木 120 / 石 260 / 铁 500 / 钻 1500）；槽底彩条，低于 25% 每工具每命语音提醒一次；归零消失 + 安抚话术 + 任务链自动指路。工具伤害对齐本游戏「hp≈原版×1.5」折算惯例（剑 7/9/11/13，镐 3/4/6/8，空手 3）。
12. 掉落物实体：落地弹跳一次、浮动缓旋、2.5 格内真空吸附飞向玩家、3 分钟消失；收集语音 3 秒合并播报（防刷屏）；背包满时停止吸附并提醒。
13. 死亡零惩罚：保留全部背包，回出生小屋满血复活（沿用下界冒险「回家回满血」先例）。
14. 挖掘蓄力仅是探险模式的政策：建造/TNT 密室的即点即碎口径不变，现有五模式零改动（回归约束）。
15. TNT 闭环：5 火药 + 4 沙合成、放置后点击点燃（复用现有引信/爆炸特效口径），爆炸破坏的方块 70% 掉落（MC 30% 的儿童加倍）——火药的「挖矿神器」出口。

**探险模式（第一个消费者）**

16. 模式注册表加一行：卡片/页面/出发按钮 DOM 命名由注册表派生（三重命名断言自动覆盖）；计入儿童时限共享预算，不新增账本。
17. 地图确定性生成（场景工具散布，同地图重进完全复现）：草原 + 树林约 40 棵 + 湖（湖底黏土层）+ 2 露天矿坑 + 1 条山洞 + 出生小屋（工作台熔炉不送——任务链要做出来）+ 3 个怪物巢穴（每巢 2-3 只、清空 60 秒后再刷）。
18. 矿物四条深度带（48 层世界压缩映射）：煤 y12~20（簇 4-8 常见）· 铁 y6~16（簇 3-5，需石镐）· 金 y2~10（簇 2-3，需铁镐）· 钻石 y0~5（簇 1-2 稀有，需铁镐）。铁/金掉粗矿需熔炼（MC 粗矿口径）。
19. 任务链 12 步数据表：每步 = 触发谓词 + 语音引导 + 图标提示 + 完成表扬；谓词为纯函数。钻石首获有专属仪式反馈；通关 = 称号 + 烟花。
20. 树苗计时与掉落物生命周期用模式层计时 Map，不进体素数据（世界无方块元数据约束）；生长阶段 = 换方块 id。

**观感（pinpoint 批注吸收，一期即做不后拖）**

21. 方块贴图走 TNT 贴图图集同款管线（画布 → 贴图 → 网格核心 UV）：程序化生成 16×16 像素画风图集，一期覆盖全部新方块（矿物/工作台/熔炉/火把/黏土/树苗/草丛），存量基础方块的迁移留二期。
22. 物品图标 = 像素图标工坊扩展：全量物品 16×16 手绘（镐斧剑锹四阶配色、锭/粉/球/食物），一期即替换 emoji 占位；同一 dataURL 源喂快捷栏、配方书、掉落物 Sprite。
23. 版权口径：风格参考我的世界，但全部程序自绘，不内嵌/抓取官方素材文件。

**存档与同步**

24. 三份存档走既有存档槽 + 云同步：全局背包（27 槽含耐久）、探险世界改动（场景确定性重建 + 差异重放，镜像建造模式架构）、任务进度。损坏回落安全默认值。

## Testing Decisions

**好测试的标准**：只测外部可观察行为——注册表形状（每条目必备字段齐全）、纯函数输入输出（堆叠/扣料/掷骰/谓词）、模式级集成（命名断言、任务触发），不测渲染细节与内部实现；用数据表断言当「防错网」（加物品漏字段当场红，镜像手持物注册表测试的先例）。

**缝的决策（用户已确认：全复用既有缝，不新增）**：

- **vm 共享词法加载缝**（最高缝，先例：手持物/坦克核心/怪物核心测试）：三个纯核心 + 怪物掉落掷骰 + 任务链谓词（设计为模式文件顶层纯函数）全部经同一 vm 加载器直测，精确镜像浏览器脚本加载序。
- **模式集成缝**（先例：下界模式测试）：探险模式镜像同款——fake 环境 + 模式注册断言；模式注册表测试对新卡的三重命名断言自动生效。
- **壳层注入缝**（先例：模式工具测试注入假 document）：掉落物实体库的纯函数段（掷骰、拾取距离判定）经 vm 加载直测，渲染不测。

**模块 × 测试映射**：物品核心（注册表形状 + 堆叠/工具判定）、背包核心（并堆/满拒/跨槽扣料边界/耐久归零/序列化往返）、合成核心（缺失清单计算、扣料与产物、任选材料、燃料热值、烧炼映射、破坏时间公式与封顶/门槛）、掉落掷骰（种子化保底+概率、掉落表引用的物品必须在物品注册表注册——防改表漏改注册的交叉断言）、探险模式（12 步任务谓词逐条触发、模式注册）。

**收尾门禁**：全量单测 + 启动冒烟 + 规范守门测试全绿，lint 零错误，现有五模式回归不受影响（物品系统零侵入的验证即「不接的模式一行没改」）。

## Out of Scope

**二期（已规划，另立 spec）**：农田四链（锄地/种植/生长/收获）与骨粉催熟——小麦/面包/骨粉配方一期先注册但原料不可得、卡片保持灰色；弓物品化与下界武器栏接入；下界怪物掉落与下界石英；箱子与金苹果；**世界扩容**（高 48→64、地图 128→192——距离环/内存/Worker 三笔账已论证可行，属独立低风险变更）；存量基础方块贴图从纯色迁移图集。

**三期（已规划）**：建造模式「生存建造」开关；被动生物（牛羊鸡猪）与羊毛/皮革/熟食链；末影珍珠等奇物；草地/花朵/蘑菇等更多采集物。

**明确不做**：MC 式网格拖拽合成（被点选配方书取代）；饥饿系统；死亡掉落；盔甲栏与附魔/稀有度体系；红石/铜/青金石/深板岩（无对应玩法，48 层世界养不起）；多人协作；抓取或内嵌 Mojang 官方素材。
