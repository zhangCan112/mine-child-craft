## 1. 验收画面锚（spec §1 + 票面手玩重点九项）

**验收画面**：孩子从高处跳下（或直接走出悬崖），背上的翼自动展开，缓缓左右转向飘翔，
第三人称看见自己张开的翼与身下的风景，平稳落地（或水面轻轻入水），落地安全、零惩罚
零说教，孩子说「再来一次」。**验收锚（R1-19）**：「能看到美丽风景，体验到飞翔的感觉
和快乐」。

## 2. 走查清单（UI spec v1.2 现行四组 23 条）

### 2.1 §6.7 门一：滑翔态主线（4 条，R1-19 验收锚）

**1. 第三人称滑翔展开观感**（双翼展开对称、暖红棕膜+金骨辐条清晰、翼展完整入画不裁尖）

- **自动已覆盖（T-G03）**：mob-look.test.js「玩家翼骨甲案」（三盒规格+官方 pivot+
  零 ry 过渡姿态）·「玩家翼贴图」（五色色族+金辐条+暗折线+翼尖粒）；avatar.test.js
  「setWings(spread)」（过渡首帧=收拢姿态可见）。
- **必须真机（待 PO）**：滑翔中双翼完整可见不裁尖、暖红棕膜在天空背景下清晰可辨。

**2. 三背景对比**（草原/沙漠/雪原翼色均可辨——暖红对蓝天/黄土/白雪）

- **自动已覆盖（T-G03）**：mob-look.test.js「玩家翼贴图」五色断言（照 §5.1/§6.3
  色板钉死）。
- **必须真机（待 PO）**：三种明显不同背景下翼色都看得清。

**3. 展/收动效与消失瞬间**（出现=收拢姿态可见瞬间起 0.25s 匀速展开；消失=水平收拢
0.25s，收拢到位瞬间消失、无残影帧）

- **自动已覆盖（T-G03 v1.2）**：avatar.test.js「setWings(spread)」（首帧可见+四点
  匀速采样+端点带）·「setWings(hidden) 到位瞬间隐藏」（播完前可见+半程≈半+到位瞬间
  visible=false）·「非滑翔零翼红线」（spreading 中途反向续收不跳变/spread 幂等）。
- **必须真机（待 PO）**：动画平滑无抖帧、无回弹；落地瞬间翼「收起来不见」的读感成立。

**4. 滑翔微动**（±2.5~3° 正弦、双翼反相呼吸）

- **自动已覆盖（T-G03）**：avatar.test.js「spread 滑翔微动」（双翼反相 95%+ 采样、
  主周期 1.4s 带）。
- **必须真机（待 PO）**：微动可感知但不晃眼（呼吸感）。
