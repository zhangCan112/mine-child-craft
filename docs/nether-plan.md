## 0. 先对齐:我们要做的是什么

你说："我想新做一个我的直接下界的冒险模式……这个模式下主人公平时在上界呆着，
地形暂时就和建造模式里的地下室模式一样，但是在地面上会有一个下界传送门，
进入传送门后，就会进入下界。请你先去学习和了解我的世界下界都有什么，
他的场景，风格是什么样子，都有什么怪物，然后再帮我去创建下界，
下界的怪物都具有攻击性，主人公要去下界打怪物探险。"

翻译成 demo 语境:**在"家"（上界）里待着——上界地形暂时复用建造模式精选场景
「巨大地下室」；地表入口处有一座下界传送门；踩进传送门就进入下界；下界怪物
（全 hostile）来攻击主人公，主人公要用锄头挥击去打它们。**

## 1. 先学习再做:下界是啥样的（调研结论）

- **场景**:Minecraft 下界 = 地狱。维度规则不同：没有天空/阳光/雨，
  **黑曜石（obsidian）** 是重要材料（传送门框架、防御工事）；地形是**下界岩
  （netherrack）** 荒原 + 岩浆湖（basalt deltas / crimson forest / warped forest /
  soul sand valley / nether wastes）；火热、暗红、发光。
- **传送门**:黑曜石框架**竖直矩形,最小 4 宽 × 5 高**（最大 23×23），**内口 2 宽 × 3 高**，
  最小 10 块黑曜石可激活 → 上界 ↔ 下界双向传送。
- **怪物**（本仓库怪物库已收录 37 种,下界一批全部 hostile）:
  - 猪灵（piglin) / 僵尸猪灵（zombified_piglin) / 蛮兵（piglin_brute):猪灵家族，
    会交易盔甲/金子，战士带锤；
  - 疣猪兽（hoglin) / 凋灵骷髅（zoglin):兽群，近战冲锋；
  - 远古守卫者（wither_skeleton):远程弓箭（每 3 箭强力）；
  - 烈焰人（blaze):飞行炮台，投爆裂火球；
  - 恶魂（ghast):飞行炮台，投火球；
  - 岩浆怪（magma_cube):近战跳跃的小怪。
  - 全部对玩家 hostile（原版下界没有 passive 目标）。

## 2. 玩法定案

| 项 | 定案 |
| --- | --- |
| 模式 id | `nether`(应用层 `js/modes/nether.js`,导出 `NetherMode`) |
| 上界阶段 | phase=`overworld`:建造模式场景「巨大地下室」作临时地形 + 地表下界传送门 |
| 下界阶段 | phase=`nether`：**平整下界岩地面**(顶层 y=20) + 3×3 成片熔岩池 + 回程传送门；怪物上线 |
| 传送门对 | 上界门 ↔ 下界回程门成对：落地就从下界门前走出(门在身后)，走进任一门即传送 |
| 战斗 | 主人公手持锄头挥击（近战，swingDmg 10, swingCd 0.38）→ 最近 hostile 怪物命中；击杀 → 击杀计数+碎块+表扬，波清空 → 新波 |
| 怪物 AI | 全部 hostile：索敌=主人公；地面近战逼近/攻击；飞行炮台（烈焰人/恶魂）保持射击距离+投射火球 |
| 波次 | wave0 = 2 只起步，空了再 +1（2 + wave），新波语音表扬 |
| 玩家死亡 | 下界重生（回下界出生点，hp 归零重来） |

## 3. 与既有架构的接线点

- 新增方块（config.js BLOCKS):下界岩/黑曜石/灵魂沙/下界砖/发光岩（id 30~34，TNT 为 20~29）。
- 怪物数值复用 `MOB_TYPES` 下界批（全 hostile），AI/波次/战斗全在模式层。
- 传送门逻辑纯模式层（帧生成 + 位置触发），不进引擎。
- 玩家实体复用怪物库受击状态机（MobCore）+ AI 索敌对象（pos/hp/cfg 同构）。
- 儿童时限：新模式进 `MODE_CARDS`（gated）→ 自动进 `PLAY_LIMIT_MODES`，不新增账本。
- 主菜单卡:`.modeCard.nether` + `#menuNether` + `#netherBackBtn` + `#netherEnterBtn`。
