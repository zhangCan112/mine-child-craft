# 熔炉玩法与物品体系二期 · 执行 Spec

> 状态：**已批准**（2026-10-24 四项拍板齐；实现设计定稿 `docs/furnace-design.md`，基线 master `514b736`，855 测试全绿）

## Problem Statement

一期熔炉「能用但不像我的世界」，四个孩子可感知的断层：

1. **多炉是假的**：所有放下的熔炉共享同一份炉内容——孩子搭两台炉子，打开发现两边一样；
   退出世界材料全额退背包，「炉子是基地设施」的沉浸感不成立（MC 每炉独立、随世界保存）。
2. **燃烧不可见**：方块贴图恒定、面板火焰恒亮——远处看不出哪台炉子在干活，面板里不知道
   燃料还能烧几件（MC 有 lit 贴图与随燃烧值衰减的火焰指示）。
3. **金锭是死胡同**：金矿→金锭之后没有任何配方消费金锭；设计稿 §3.5 规格化的金苹果从未落地。
4. **烤肉没有源头**：MC 熔炉最经典的儿童用法是烹饪（生肉→熟肉回血更多），但全游戏 37 种怪
   全是敌对怪、食物只有苹果/面包/腐肉——「烧炼 ↔ 食物 ↔ 打猎」的三角缺了两角。

## Solution

四个交付件（F1~F4），全部复用既有引擎资产（Mobs 实体库/掉落管线/合成核心三纯核心/贴图图集/像素图标工坊），不新造系统：

1. **F1 每炉独立 + 持久化**（拍板①）：炉状态从全局单对象改为按位置 `Map<posKey, 炉状态>`，
   随 `adventure_world_save` 持久化；退出世界不再退料，重进世界炉内物品与烧炼进度照旧；
   挖掉熔炉内容自动入包（零损失口径不变）。
2. **F2 点燃观感**（拍板③）：燃烧中的炉口升起 3D 火焰（远处可见，模式层观感、不动方块数据）；
   面板火焰图标升级为燃料余量条（显示当前燃料还能烧几件）。
3. **F3 金苹果**（拍板②）：8 金锭 + 1 苹果 → 金苹果，吃了回满血；任务链不加步，作自由玩出口。
4. **F4 被动动物 + 熟食链**（拍板④，最大件）：草原上确定性散布牛/猪/鸡/羊（不主动攻击、
   游荡吃草、受击逃窜），击杀掉生肉/皮革/羽毛/羊毛；SMELTS 增 4 条烹饪配方（生肉→熟肉，
   回血显著更多，food 值镜像 MC 饥饿值）。

## User Stories

**熔炉本体**

1. 作为小探险家，我想要我放的两台熔炉各烧各的东西，这样西边炉子烧铁锭、家门口炉子烤肉，像真的基地。
2. 作为小探险家，我想要退出游戏再回来，炉子里的东西还在原地接着烧，这样我的努力不会消失。
3. 作为小探险家，我想要炉子烧东西时炉口有真的火苗，这样隔着一座山也知道家里炉子在干活。
4. 作为小探险家，我想要炉子面板里的火苗告诉我燃料还能烧几件，这样知道什么时候该再去挖煤。
5. 作为小探险家，我想要不小心挖掉熔炉时里面的材料直接回到背包，这样永远不会丢东西。

**金链**

6. 作为小探险家，我想要用 8 块金锭和 1 个苹果做出金苹果，吃了血全满，这样挖金矿有特别的盼头。

**牧场与熟食**

7. 作为小探险家，我想要草原上有慢悠悠吃草的牛猪鸡羊，这样世界像活的、不打仗也有的逛。
8. 作为小探险家，我想要小动物不会来咬我、我打了它会跑，这样安全和危险一眼分得清。
9. 作为小探险家，我想要打倒牛拿到生牛肉、放进炉子烤成牛排，这样「打猎→烤肉→吃饱回血」整条路走得通。
10. 作为小探险家，我想要烤熟的肉比生肉回血多得多，这样熔炉对我真的有用。
11. 作为小探险家，我想要剪下/获得羊毛能盖房子，这样动物浑身都是宝。

## Implementation Decisions

**炉状态（拍板①）**

1. 炉状态形状沿用一期五元组 `{input, fuel, out, heat, prog}`，容器从模式层单对象
   `advFurnace` 改为 `Map<posKey, state>`；`posKey` 与站点缓存同口径（`'x,y,z'` 字符串）。
   纯函数 `advSmeltStep(s, dt)` 零改动（本就无状态、返回新对象）。
2. 持久化进 `adventure_world_save` 新字段 `furnaces`（mkSaveSlot defaults 只补缺失字段，
   老档无此字段 = 空炉 Map，天然迁移）；`_v` 递增。退出模式/刷新页面时与世界档同存。
3. 重进世界：炉内容、剩余热值、烧炼进度全量恢复继续烧（MC 口径 block entity 保存
   burn time / cook time，研究稿 §2）。
4. 挖掉熔炉（含 TNT 掀掉）：该炉三笔全额入包、满包余量脚下掉落（沿用 `advFurnaceRefund`
   语义），状态删除——零损失口径不变；TNT 掀掉同样退料（材料不是「玩家亲手烧」的计数对象，
   与任务账本口径无冲突）。
5. 烧炼节律 `update`：从单炉 tick 改为遍历 Map 逐炉 tick（炉数为个位数，成本可忽略）；
   TTS 完成播报只对「当前开着面板的那台」（多炉并烧不合唱，3s 节流沿用）。
6. 面板交互：点击某台熔炉 → 面板绑定该炉状态（面板接口 `setSlots/setProgress` 不变）；
   站点解锁判定 `advNearStation` 已按位置缓存，天然支持多炉。

**点燃观感（拍板③）**

7. 燃烧判定 = `heat > 0` 且有料（与烧炼推进条件一致）；炉口火焰 = THREE.Sprite
   （火焰像素画走贴图图集/程序绘制管线），挂炉方块顶面前沿，呼吸式脉动缩放；
   燃烧起止增删，不进方块数据与存档（纯模式层观感，Sprite 不受距离环 LOD 影响，远处可见）。
   不采用「燃烧换方块 id（lit furnace）」方案——那会污染 edits 存档账本（烧炼频繁起止），
   且要连带改掉落表/站点判定/贴图布局，成本高收益同。
8. 面板燃料余量条：火焰条宽 = 当前热值折算「还能烧几件」的比例（相对在烧燃料的单件热值），
   MC 口径「火焰随燃烧值衰减」（研究稿 §1/§2）；无燃料时熄灭灰显。

**金苹果（拍板②）**

9. `ITEMS.golden_apple`（食物类，特殊标记回满血——现有 `food` 字段是数值回血，金苹果
   走 `food: 'full'` 或伴生旗标，食物政策在模式层解读）；`RECIPES` 加
   `{8×gold_ingot + 1×apple, station:'table'}`；像素图标进 `ITEM_PIX`（图标守门测试
   自动覆盖）；首次获得 TTS 仪式感话术（对齐钻石首获先例）。任务链不加步。
10. 金质工具**不做**（拍板②取舍记录）：MC 金档「最快但最脆」且挖掘等级=木级——
    「金镐挖不动铁矿」对 6 岁是反直觉陷阱，破坏四档工具阶梯的教学一致性。

**被动动物 + 熟食链（拍板④）**

11. 引擎数据：`MOB_TYPES` 加 `cow / pig / chicken / sheep` 四条（hp 按「≈MC×1.5」折算惯例：
    MC 10/10/4/8 → 15/15/6/12；速度慢档 1.2~1.6；dmg 0 不攻击）；新行为原型 `grazer`
    （纯游荡吃草 + 受击闪白/踉呅/短促逃窜——受击反馈复用 Mobs 通用本能）；新种族
    `farm_line`「农场一家」（每怪必归种族的谱系红线；不进竞技场/坦克演习场的部署面板，
    spawnable 出口过滤，设计稿核实）。建模走 Mobs 四足参数化生成器（鸡=小体型两足变体），
    零新骨架代码。
12. 草原散布：`advBuildWorld` 确定性散布 2~3 群（每群 3~4 只，SceneKit.rand 同款种子口径），
    重进世界按存活记账（edits 不记实体——动物存活态进世界档新字段或轻量清单，设计稿定）；
    不重生（MC 口径动物不刷；杀光就没了——「牧场会空」本身是保护动物的隐性教育，设计稿复核）。
13. 掉落（MOB_DROPS，儿童配平「保底 1 + 50% +1」沿用）：cow→生牛肉+皮革 · pig→生猪排 ·
    chicken→生鸡肉+羽毛 · sheep→羊毛+生羊肉。
14. 新物品 11 件：`raw_beef / cooked_beef / raw_porkchop / cooked_porkchop / raw_chicken /
    cooked_chicken / raw_mutton / cooked_mutton / leather / feather / wool`；
    food 值镜像 MC 饥饿值（研究稿 §5）：生肉 2~3 / 熟肉 6~8（现有锚点：腐肉 2 · 苹果 4 · 面包 8）。
    皮革/羽毛/羊毛本期是收集品（MC 口径皮革护甲/弓羽不在范围，Out of Scope 记账）。
15. `SMELTS` 增 4 条烹饪映射（raw_beef→cooked_beef 等）；烧炼时长/燃料消耗与矿物同一套
    （MC 全配方同速 10s，我们同速 2.5s——口径自洽）。
16. 羊毛出路：新放置型物品 `wool`（白羊毛）+ 新方块 id 52（`BLOCKS` 新条目 + 贴图图集一格 +
   掉落自身）；蓝/红羊毛维持创造专属（设计稿 §3.5「羊掉毛后转入采集」的兑现口径，只开白羊毛）。
17. 击杀动物的情感口径：死亡动画（倒地沉没）与掉落照常、收集播报照常，不加特殊安抚
    （MC 儿童玩家照杀不误，死亡本身零血腥）；设计稿复核措辞。

**维持项（明确不动，防 scope 漂移）**

18. 烧炼节奏 2.5s/件（附录 B 儿童差异清单维持）；燃料热值 MC 原值（煤/木炭 8 件 · 木质 1.5 ·
    木棍 0.5）；燃料「烧多少扣多少、断档不白烧不倒退」——现状已优于 MC（研究稿 §6 建议
    「按件计费」正是现状实现），不改。
19. 自动放料（最省燃料序）、产物开/关面板自动收取、走近 4 格解锁、熔炉合成配方
    （8 圆石，无需煤——MC 正典）全部不动。
20. 任务链 15 步 + 终章不动：金苹果/烤肉/牧场都是自由玩出口，不插步（q12_smelt 谓词零改动）。
21. 死亡政策不动：背包保留回出生点满血；炉内容留在各炉里不动（持久化的自然推论）。

**分层红线**

22. 引擎层（MOB_TYPES 条目/掉落表/SMELTS/ITEMS/方块 52）只知道数据；散布位置、重生政策、
    话术、金苹果仪式感全在模式层。引擎不知道「探险模式的草原上有几群牛」。

## Out of Scope

- 高炉/烟熏炉（MC 特化双炉——引擎无对应玩法，研究稿 §6 亦建议砍）
- 烧炼经验值（儿童无意义）
- 漏斗/自动上下料（MC 自动化件）
- 金质工具（拍板②明确不做，理由见决策 10）
- 剪刀剪羊毛（shears 已有，挂点少——若 F4 实现有余量作可选件，默认不做）
- 动物繁殖（小麦喂牛——三期农田联动）
- 皮革护甲、羽毛箭（皮革/羽毛本期只作收集品，出口三期）
- smooth stone 二段烧炼（石砖链已覆盖建材循环）
