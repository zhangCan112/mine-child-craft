# 怪物合成（首例：友方铁傀儡）· 实现设计

> 需求：新增一种合成种类「怪物合成」——玩家造出**友方怪物**；首例铁傀儡。
> 正典依据：[iron-golem-research.md](iron-golem-research.md)（§1 获取 / §2 数值 / §3 AI / §4 治疗 / §5 搭建 vs 生成差异）。
> 移植伴生机制守则（conventions §1.12）执行情况：见附录 B 逐条清单。
> 用户拍板（2026-11-08）：
> 1. **形态=结构召唤**——照搬正典 T 形搭建召唤，不做工作台配方；
> 2. **材料补齐**——铁块/南瓜/雕刻南瓜三件新增；南瓜在主世界野生长几个、**定时刷新**；剪刀**雕刻交互要做**；
> 3. **死亡=销账不重生**；存活期可用**铁锭修理**；
> 4. **击飞不搬**（暂不做）；
> 5. **只做锚点巡逻**——不离锚半径，无村庄巡逻。

## 0. 闭环总览

```
野生长点采南瓜(D2) → 铁锭合铁块(D1) → T形搭建+雕刻南瓜收尾(D3/D4 召唤仪式)
  → 友方傀儡锚点巡逻护家(D5) → 受损喂铁锭修理(D5)，死亡销账留铁锭遗物(D6)
```

不搬：Village spawn / 声望愤怒 / 击飞 / 裂纹贴图 / 献花（附录 B 逐条登记）。

**无新文件**：纯函数收 adventure-core（advHerdStep/advLivestockSpots 先例），壳层接线
adventure.js（advHerdTick/advMobAI 先例）；config/atlas/items/craft 四表各加行——
加载序零改动，index.html 零改动。

## D2 · 南瓜野生长点（生态恢复同款）

- **纯清单**：`advPumpkinSpots()`（零世界读，xz 常量 + advHeightAt 派生种植面，
  advLivestockSpots 投影同款）——home 图农田东南草地 **3 处**（拍板②「生长几个」
  取下限，常量可调；避农田/水路/小径/围栏/广场，单测对矩形逐点断言）；
- **建场播撒**：`advPlantPumpkins()` 挂 **advBuildWorld 树后草丛前**（实现细化：
  占位预检让位树干，草丛/花田的顶上无物判据在其后播撒也让位南瓜——零避让代码
  白得）；拒绝式预检 `advPumpkinSpotOpen`（read 注入纯函数：位上空气+底下有支撑，
  浮空南瓜不成立）；建场播撒**不记 edits**（确定性建场件，同牧场散布口径，
  玩家挖走/覆盖由 journal 重放兜底）；
- **采集**：挖掉（挖掘/TNT 两路）经普通掉落链得南瓜物品，`advMarkEdit` 记账 +
  mined sink 记采集账（世界档 `pumpkinRegen` 桶 `{点位索引: 采集时 dayTime}`——
  实现细化：存 **dayTime** 不存日期串，账值即完整状态，无会话计数）；
- **定时刷新**：`advPumpkinRegenTick` 判据 `账值 > 当前 dayTime` = 期间跨过午夜
  回绕沿（睡醒跳零/自然过夜同判，羊毛长回同款游戏日时钟，**无离场计时**）→
  位空回填 B_PUMPKIN + `advMarkEdit` 记账；**只回填空气位**（玩家建筑不顶掉，
  被占销账）；坏账/孤儿账销；
- **结算时机**：三处装场结算（oreRegen 同拍）+ `advHerdTick` 回绕沿当帧（睡醒
  早上南瓜已回，不用重进）；
- 刷新节奏：**一个游戏日一茬**（正典是茎随机刻生长，差异登记附录 B）；
  仅 home 图结账（他图场景未装，直写会串桶）。

## D3 · 雕刻交互（shear 档复用）

- `ITEM_USES.shears` 已注册 act `'shear'`——模式层执行器扩**目标分派**：准星命中
  羊→剪毛（既有）/ 命中 B_PUMPKIN→雕刻；
- `advCarveOk(id)`：目标=B_PUMPKIN → **原地变换** B_CARVED_PUMPKIN + 扣剪刀耐久 +
  `advMarkEdit` 记账（记账钩自然触发 D4 检测——T 形齐了就地出傀儡，正典「剪一下即生成」）；
- 入口零新增：桌面右键使用链（advTryUseHeld 既有）、触屏 ✂️ 键（剪羊毛同键）；
- 音效 `pick`（正反馈叮，既有键）；雕刻出的雕刻南瓜可挖走（掉 `carved_pumpkin`）摆去别处搭。

## D4 · 召唤结构检测（advMarkEdit 单点挂钩）

- **挂钩点**：`advMarkEdit(x,y,z,id)` 内 `id===B_CARVED_PUMPKIN` → `advGolemSiteOk`（纯函数，
  read 注入，测试直驱）→ 过则壳层召唤。两条触发路（放雕刻南瓜 / 剪普通南瓜）都汇此缝；
- **红线核验**：journal 重放走 setBlockRaw 通道**不经 advMarkEdit**（站点缓存同缝先证）——
  老档重进不重复召唤，召唤只认「活体编辑」；实现票内加断言钉死；
- **结构判据** `advGolemSiteOk(x,y,z,read)`：
  - 身体：`(x,y−1,z)` 与 `(x,y−2,z)` 双 B_IRON_BLOCK；
  - 手臂（两轴向任一）：`(x±1,y−1,z)` 或 `(z±1,y−1,z)` 双铁块；
  - **四空气格**：臂位×2 + 肩上位×2 必须 id 0（草/水/任何非空气阻断，正典口径）；
  - 仅**正放直立 T**（两轴向）；横放/倒放不识别（差异 B）；
- **召唤**：`Mobs.spawn('golem', x+0.5, z+0.5)` 落身体基座格=塔锚列中心（**先消耗后
  落地**——壳先散碎屑，傀儡恰在空出的原位破壳拼装，F3；Mobs 贴地自收尾），挂
  `m.__golem = true` + `m.__golemHome = {x, z}` 家锚；**结构消耗**（2026-11-08 用户票
  改拍板：拆头重放能再召=白嫖刷傀儡——正典同，JE 搭建成功 4 铁块+南瓜随生成消失，
  36 锭一座傀儡；直写空气+`advMarkEdit` 记账，账上最后写赢=空气，重放不复活塔；
  事后拆塔不影响已召唤傀儡的语义不变——傀儡独立于塔）；**诞生仪式**：塔材逐格碎屑
  （头橙/铁灰）+ 重锤音 + `__golemBirthT` 拼装缩放 0.25→1（`ADV_GOLEM_BIRTH_T=0.9s`，
  落地金圈+叮；桶重召不带此态=不重播）；
- **上限**：`ADV_GOLEM.MAX = 3`（提案 P2）——满员时结构照常成立但**不召唤也不消耗**
  （塔留给玩家），话术「铁傀儡够多啦」。

## D5 · 友方傀儡实体与 AI（巡逻 / 索敌 / 修理）

- **数值与造型零新增**：`MOB_TYPES.golem`（hp 110 / dmg 15 / speed 2.0 / range 3.0 / cd 1.6）
  与造型档案 `js/mob-look/golem.js` 直接复用——竞技场行即底座（换算见附录 A）；
- **决策纯函数** `advGolemStep(m, env)`（adventure-core，advHerdStep 先例）+ 壳层
  `advGolemTick`（走 Mobs.move/steer 意图 API，advHerdTick 先例——**不进 advMobAI**）；
- **三态机**：
  | 态 | 触发 | 行为 |
  | --- | --- | --- |
  | 巡逻 | 无敌情 | 锚点 R_PATROL=12 内缓步游走（六成时间缓步，牧场口径） |
  | 索敌 | R_SIGHT=12 内最近敌怪 | **锁定至死**（正典单一目标口径），压上攻击（cd/range 用注册表行） |
  | 归位 | 目标死 / 出 R_LOSE=16 | 走回锚点（拍板⑤「不离锚半径」） |
- **敌怪判定**：Mobs.list() 中存活、非 `__golem`、非 passive 牧场四怪——不搬 monster 家族
  tag 体系；**苦力怕例外不搬**（提案 P1：夜怪主力是苦力怕，守护职责优先）；
- **夜怪报复**：傀儡命中夜怪挂 `m.__hurtBy='golem'`，advMobAI 侧分派改打傀儡（正典被打必
  报复）；默认夜怪只盯玩家，傀儡不打它就不结仇；
- **修理**：`ITEMS.iron_ingot` 增使用档 `[{act:'repair_golem', icon:'repair', label:'修理傀儡'}]`
  → 执行器：准星近旁友好傀儡 hp<max → 扣 1 锭 `heal(ceil(maxHp/4)=28)`（正典「1 锭=一档
  裂纹」语义）+ `pick` 音 + TTS；满血 noop+话术节流；触屏使用键按既有「选中物签名」自动出现；
- **血量可视化**：mkHpBar 名牌血条既有承担（裂纹贴图不搬，差异 B）；
- 击退抗性采纳：傀儡受击零位移（正典 100%，Mobs.hit 参数或模式侧跳过，票内定）；击飞不搬（拍板④）。

## D6 · 持久化与生命周期

- **世界档 payload 增 `golems` 桶**：按图分桶 `{图键: [{x, z, hp}]}`（键序=ADV_MAPS+ADV_DIMS
  派生，livestock/netherEdits 同源口径）；归一纯函数 `advGolemsNorm`（异形整条丢弃，
  advLivestockNormBucket 先例）；**存 hp**——修理投资跨档不丢（提案 P3）；
- **重进复现**：init 播完场景后按桶重召（家锚=存档位，游荡位置不存档——牧场同口径）；
- **死亡销账**（拍板③）：onDeath 回调出桶 + 掉 `MOB_DROPS.golem`（铁锭 3~5 既有行，正典
  净亏 36 锭成本 → 遗物 4 锭，天然无刷铁漏洞）；当天/跨档均不再复活；
- **清场免疫**：非 `__nightMob` → 黎明清场/床跳夜清场天然不误伤（既有过滤字段的负空间，
  测试钉死）；TNT 波及照常受击（中性）；
- GLOSSARY 收尾词条「铁傀儡（Iron Golem）」（T7 落地；原拟名「怪物合成（MobCraft）」——
  词条落游戏模式段按词条族命名，与牧场/生态恢复同列，取玩家可感的实体名）。

## 提案拍板记录（2026-11-08 用户确认，四条全部采纳）

| # | 拍板 | 理由 |

| P1 | **苦力怕例外不搬**——傀儡主动打苦力怕 | 正典例外源于「爆炸毁地形+先版本误伤史」；我们夜怪主力是苦力怕，守护怪无视头号威胁读不出「守护」 |
