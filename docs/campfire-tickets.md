## T-C1 tracer 竖切：合成→放置即燃→侧账→燃尽消失（最小闭环）

> 标签：`task`｜状态：☑ 已并入（f8b133b 实现 + 5f634b2 评审修）｜blocked-by：无｜blocks：T-C2, T-C3, T-C4, T-C5,

**纪律三件**：见解票须知第 5 条。

### 背景

篝火特性的最小可玩竖切（spec §11 预案）：从工作台合成出篝火，放到地上立即燃烧，
烧满 6000 刻干净消失——一轮完整生灭走通「数据→放置→侧账→时钟→移除」全链。
来源章节：spec §3.1（物品注册三件接线）、§3.2（配方，图案本 spec 定稿）、§3.3
（放置规则与四类失败）、§3.4（两态 id/物理形态/燃尽收尾）、§3.9（参数初值）、
§4（时钟——**已拍板**整数刻游戏钟：20tps 累积器、dt 注入、与昼夜钟解耦）、
§6 红线 5/6/7/10/11/12；ADR 0018（生命周期）。表现最小可过：占位贴图、零特效、
零音效——正式观感归 T-C7~T-C11，本票不做。

### 要求

1. **物品注册三件接线**（spec §3.1，漏一即守门红）：
   - ITEMS 行（js/items-core.js）：`campfire: {name: '篝火', icon: '🔥',
     block: B_CAMPFIRE}`——`block` 字段=放置路由依据（torch 同款）；无 `dur`
     （可堆叠消耗品，燃烧账在方块侧）。
   - ITEM_HINTS 行（js/item-hint-registry.js）：逐字=「放在地上，烧好久好久，
     又亮又暖」（UI 定稿 §6.1 定稿文案；全文不得出现「飞/上升/气流/翅膀」
     剧透字样——⭐R2-3）。
   - ITEM_PIX 键（js/icons.js）：本票占位（emoji fallback 形态即可过）；正式
     16×16 字符画=T-C7 照 UI 定稿 §3.2 逐字符落位。
   - 放置路由走 `block` 字段既有链（模式使用链→PlaceKit.tryPlace），**不进
     item-use-registry**（spec §6-5 红线）。
2. **合成配方一行**（spec §3.2）：`{id: 'campfire', out: {item: 'campfire', n: 2},
   station: 'table', shape: {rows: [['stick', ['coal', 'charcoal'], 'stick'],
   [null, 'stick', null], ['log', 'log', 'log']]}}`——公开配方不进
   KIT_HIDDEN_RECIPES；计数 `craft_campfire` 按件数累加零消费（配方 n:2，首次合成即 +2——件数口径，spec §3.2 勘误）。
3. **BLOCKS 两态行 + 参数块**（js/config.js，spec §3.4/§3.9）：`B_CAMPFIRE`/
   `B_CAMPFIRE_OUT`=**81/82**（定稿建议值；现号段已用至 80=B_GATE_SIGN，
   2026-11-16 核实；**落位以实现期 config.js 现状为准**，冲突经派令方回票不改
   spec）+ `campfire: 'lit'|'out'` 身份旗标 + 燃烧态 `light: 15`/熄灭态 `light: 0` +
   `thin: 0.5, solid: true`（半格实体观感、可碰撞可站立——站立面=voxel 整格
   贴齐，thin 不参与物理，见 spec §3.4 勘误）；CAMPFIRE 参数块照 §3.9
   初值（6000 刻/柱高 20/截面 3×3/升速 +3.0 等）。
4. **放置即燃**（spec §3.3）：PlaceKit.tryPlace（探险/体验馆共享缝，零场景分支）
   + onPlaced 钩挂侧账建条（满 6000 刻，树苗挂表同缝先例）；底座判据=任何实体
   方块顶面（advPlaceCheck 支承判同款）；**两态篝火顶不得作底座=thin 支承门
   机械达成零特判**（防火塔叠罗马：篝火 thin:0.5≠null 两态同拒）；四类失败
   （① 水面 solid:false ② 悬空/侧面无 wall 旗标 ③ 非 replaceable 薄块顶如
   引线 ④ 篝火顶叠放）共用温和话术「篝火要放在结实的东西上面哦」（UI 定稿
   §6.2 逐字）+ 不扣物品；replaceable 薄块（花/草丛/树苗/火把等七件白名单）
   点中=覆盖放置成功，不属失败类（spec §3.3 勘误口径）。
5. **20tps 刻账**（spec §4 拍板案）：新文件 `js/campfire-kit.js`（应用层装配，

   不喂即冻结）；内部 dt 累积器量化整刻（`pumpFluids` 的 fluidAcc 同款先例）；
   纯函数（燃尽步进/档账 clean）进 js/adventure-core.js（advFurnaceClean 同居
   先例）。**零墙钟**（禁 Date.now/performance.now，spec §6-8）。
