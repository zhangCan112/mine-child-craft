# 冒险模式 · 生态地图 手玩验收清单（T10 收尾）

> 来源：[adventure-maps-plan.md](adventure-maps-plan.md)「手玩验收清单（P9 真机）」10 项，
> 结合 T1-T9 实现记录（[adventure-maps-tickets.md](adventure-maps-tickets.md)）刷新。
> 每项分两栏：**自动已覆盖**（票据 + 单测——`npm test` 全绿即视为通过）与
> **必须真机手玩**（观感/听感/时感/性能体感——自动测试够不着的部分，T7 票据明确
> 留给本清单的站桩反悔、≤5s、无黑帧三项也在其中）。设计权威
> [adventure-maps-design.md](adventure-maps-design.md)。

## 运行方式

```
npm install --ignore-scripts   # 首次即可（运行时不依赖 node_modules）
node server.js                 # 本地起服务，端口默认 8080
```

浏览器打开 <http://localhost:8080> → 主菜单进**探险模式**。存档经服务端同步
（server 端 data/ 目录），「重进」= 关页重开浏览器；要看新档首见观感（门解锁
仪式/任务引导从零走），建议先清掉旧档。桌面 + 触屏设备各过一遍——站桩、渐晕、
雪球投掷、主动作键都是双端路径。

## 清单（10 项）

### 1. home 读图感

> 门阵广场在屋东、农田在屋南、围栏牧场在屋西；花丛草场；湖步行 30 秒可达。

- **自动已覆盖（T5）**：adventure-core.test.js「T5 门阵广场」（屋东 15×15 圆石
  满铺+三扇门位进常量）·「T5 初始农田」（屋南 4×3 耕地+熟麦+西缘水路）·
  「T5 畜牧围栏」「T5 畜牧群位进围栏」（原木柱+木板栏+两群位落栏内）·
  「T5 花丛草场」（蒲公英黄/雏菊白 ~2% 散布）·「T5 圆石小径」（门口↔广场↔
  农田三段连通）·「T5 避让联动」（树/群位避新建场件）。
- **必须真机手玩**：**读图感**——站在小屋门口环视，东广场三门、南农田、西围栏
  牲畜一眼可辨不需寻找；沿小径走到湖 30 秒内可达、沿途不被地形卡住；花丛点缀
  密度适中不喧宾夺主。

### 2. home 圈层

> 近处遇僵尸巢、远处遇苦力怕巢；山洞在北边缘深处有钻石；山坡每步可登。

- **自动已覆盖（T3/T5）**：adventure-core.test.js「T5 圈层断言」（三巢距小屋
  距离单调递增）·「T5 高度场」三件（幅度界 ±3/结构压平/地层随高度场）·
  「T5 高度场： 坡度红线」（全图相邻高差 ≤1，scene-kit.test.js 同款）；山洞
  隧道通 y<10 裸露钻石（adventure-mode.test.js「山洞隧道」）。
- **必须真机手玩**：**风险-距离梯度的体感**——从家门出发先撞近僵尸巢、深险圈
  才见苦力怕；**山坡每步可登**——不跳不卡走上丘顶再走下来；进山洞深处真挖到
  钻石（矿在沿途裸露，不用瞎猜）。

### 3. home 门阵三扇门

> 两扇熄灭（暗紫微光门面+分级锁定 TTS）、一扇随任务点亮（仪式播报）。

- **自动已覆盖（T7/T8）**：熄门立框+暗紫微光门面（B_PORTAL_DIM，id 异于
  B_PORTAL=不可触发，adventure-nether.test.js
  「T7-1 门阵建场」）·走近熄门播分级话术（链未走到=泛指任务卡、前置已是当前步=
  点名 goal）+节流（「T7-3」「T7-3b」「T8 锁门 TTS 真任务
  名」）·完成 q16 广场引导→解锁键置档落盘+点亮仪式音效/TTS/冲击波+门面运行时
  熄→亮（adventure-mode.test.js「T8 解锁链第一环」）。
- **必须真机手玩**：**门点亮仪式的听视同步**——完成 q16「去门阵广场看一看」的
  瞬间：琶音+紫色冲击波+TTS「黄沙沙漠之门亮起来啦！」+门面与光束点亮一拍到位；
  两扇熄门只有框无紫面，孩子看得出「还没开」。

### 4. 进沙漠门（四图巡游第一程）

> 渐晕 → 从回程门走出，看到沙丘+仙人掌+神殿轮廓；夜间只遇尸壳不遇白僵尸。

- **自动已覆盖（T4/T6/T7/T8）**：站满 2s→渐晕满格切图→落回程门内+TTS 播报+
  遮罩收起（「T7-2 站桩状态机」）·穿门端到端 visit_desert 记账→q17 到达型完成
  （「T8 站桩穿门端到端」）·沙漠建场三件（沙丘巢穴/神殿/绿洲，maps-core.test.js）·
  夜池替换语义 desert 无 zombie 有 husk（「注册表： 替换语义红线」）。
- **必须真机手玩**：**切图时感与渐晕观感**——紫白渐晕 400ms 淡入→切图→400ms
  淡出，全程无纯黑帧、无白屏闪烁，体感 ≤3s；落地即从回程门内侧**面朝外**走出
  （门在身后，方向感自然）；沙丘+仙人掌+神殿金字塔轮廓第一眼可辨；入夜后
  目视只遇尸壳（黄沙僵尸）不遇白僵尸。

### 5. 神殿「可疑地板」

> 踩塌滑入宝箱室，拿宝箱阶梯奖励，楼梯走上不困人。

- **自动已覆盖（T4/T8）**：神殿地下宝箱室+可疑地板中央 2×2 沙+出路楼梯
  （maps-core.test.js「沙漠建场： 神殿」）·结构宝箱记账图+坐标双判定防冒名
  （「advMapChestKey」+adventure-core.test.js q19 chest_temple）·大宝箱阶梯
  政策 advChestNext/advChestPut（adventure-core.test.js 既有）。
- **必须真机手玩**：**踩塌的惊喜与不困人**——踩上可疑地板即滑落宝箱室（无爆炸
  无致死，幼儿红线）；开箱走大宝箱奖励阶梯；沿楼梯原路走上来不卡墙不迷路
  （孩子自己能出来）。

### 6. 进雪原门（四图巡游第二程）

> 雪覆地表+云杉+雪屋；挖雪得雪球，掷雪球击退苦力怕。

- **自动已覆盖（T1/T9）**：雪原建场两件（全铺雪覆草+冰封湖+云杉+雪堆点缀/
  雪屋圆顶+地下宝箱室，maps-core.test.js）·挖雪块得 4 雪球（blocks-fields.test.js）·
  投掷链手持右键掷出+零伤害+击退+白絮+命中音（adventure-mode.test.js「T9 雪球
  投掷链」+combat-kit.test.js「mkArrows 第二实例」）·4 雪球↔雪块配方
  （craft-core.test.js）·throw_snowball 记账 q21（「T8 计数挂点四路」）。
- **必须真机手玩**：**雪球手感**——手持雪球右键（触屏主动作键）掷出的初速/
  弧线跟手、连续投掷节奏（0.6s 冷却与挥击同轨）；命中怪白絮观感+击退力度适度
  （推开苦力怕但不夸张）；雪屋圆顶+南门洞观感；冰面现状无滑动物理（半滑归
  二期），走上去等同平地不粘脚即可。

### 7. 进沼泽门（四图巡游第三程）

> 灰绿水+垂藤+女巫小屋；小屋女巫常驻；夜间水边史莱姆。

- **自动已覆盖（T4/T6）**：沼泽建场（浅水洼+垂藤橡树+女巫小屋高脚木屋+宝箱，
  maps-core.test.js）·witchHut 常驻标记仅 swamp 行+witch 不进通用夜池
  （「注册表」断言）·「T6-6 swamp 女巫常驻 + home 牲畜重播 + 夜怪池随行」·
  夜池 bogged+slime 替换语义·q23-q25 远征章（adventure-core.test.js）。
- **必须真机手玩**：**常驻与夜刷的目视区分**——白天靠近女巫小屋女巫就在
  （常驻不是夜刷）；夜间水边出现史莱姆、白天退场；灰绿水色/垂藤橡树与 home
  图观感区分明显（换图一眼「到了另一个地方」）。

### 8. 存档保留（分桶互锁）

> 每图挖/放几处 → 切图再切回：改动精确保留；重进游戏（关页重开）仍保留。

- **自动已覆盖（T6）**：adventure-nether.test.js「T6-1 分桶存档」（三桶独立
  落盘+map 键随档）·「T6-2 老档两代自动迁移」·「T6-3 切走再切回： 世界逐字节
  一致（分桶账本互锁红线）」·「T6-4 重进幂等」·「T6-5 装配清单」；建场确定性
  两次逐字节一致（maps-core.test.js/adventure-core.test.js）。
- **必须真机手玩**：**真机关页重开**——每图各挖/放几处显眼改动（如门口立柱），
  切图再切回目视核对、关页重开浏览器再核对（pagehide 兜底落盘路径）；测试已
  保证逐字节一致，手玩确认的是重开后无观感 glitch（网格/光照/门体/光束齐全）。

### 9. 远征图死亡

> 满血回家门口，话术温和；回小屋冷却不受干扰。

- **自动已覆盖（T4/T6）**：advMapDeathPlan 纯政策（满血+home 门口+背包保留+
  map 标记回 home，maps-core.test.js「政策： 死亡回家」）·「T6-8 远征图死亡/
  回家： 切回 home + 小屋出生 + 满血」·死亡即时落盘（adventure-mode.test.js）·
  回小屋 60s 冷却（adventure-mode.test.js「修复③」）。
- **必须真机手玩**：**死亡回家话术与体感**——在远征图故意阵亡：渐晕/切图回家
  门口、满血、背包还在、TTS 安抚话术听感温和不吓人；回家后立即按 H 试回小屋
  冷却是否照常计时不受切图干扰。

### 10. 切图体感与连续操作

> 全程切图体感 ≤3s，遮罩无纯黑帧；连续快速切图（含站桩中途反悔 ×5）无残留状态。

- **自动已覆盖（T7）**：站桩步进 2s 站满发令/走出门面即刻反悔归零/发令后重新
  累计（maps-core.test.js「政策： 站桩步进」+adventure-nether.test.js「T7-2」）·
  回程门对应对应门位（「T7-4」）·遮罩双段 400ms×2 时序与全程 2.8s（≤5s 红线）
  在壳装配口径内。
- **必须真机手玩**：**站桩反悔 ×5**——五次踩进地图门在 2s 内走出，确认即刻
  归零无「被吸走」；**连续快速切图**——四图快速巡游（home→desert→snow→swamp→
  home）含反悔与死亡回家穿插，无残留状态（怪物/箭/雪球/渐晕/光束/HUD 图名/
  昼夜不串图）；**性能体感**——切图瞬间掉帧可接受（渐进重建近处优先，脚下先见），
  渐晕满格峰值瞬间看不见画面的时长很短（实测切图同步成本 12-25ms）。
